## 1. 玩家结果

- 静止瞄准时，距离只决定当前可用的最小/最大散布包络，不再把当前散布从最小值直接推到最大值。
- 玩家开始移动、快速甩动准星或开火时，准星立即、连续且可区分地扩大；停止对应输入后按武器操控速度平滑收缩。
- 多种动态来源可同时生效，但使用有界合成，不能简单相加到失控，也不能被距离提前占满上限。
- 移动角色并连续移动鼠标时，准星中心保持 Direct 同帧响应，准星半径不因单帧鼠标事件稀疏、距离变化或两种显示半径切换而闪烁。
- 子弹随机方向继续由同一权威当前散布抽取；外显准星只预读领域结果，不改变命中、弹药、逻辑飞行或 HitResult。

## 2. 状态与计算合同

- `WeaponFireState` 继续是 SDL 无关的权威散布状态，分别保存 `movementBloom`、`reticleMotionBloom` 与 `shotBloom`，范围均为 `[0, 1]`。
- 距离仅计算 `contextualMinimumSpread` 与 `contextualMaximumSpread`。贴近角色时两者按 `nearDistanceSpreadScale` 收束；最大有效射程处包络达到武器正常最小/最大角散布；超有效射程继续使用既有倍率。
- 移动 Bloom 追向 `movingSpreadFraction`；移准 Bloom 由设备无关准星控制速度经过软阈值映射；射击 Bloom 每次成功击发按 `spreadPerShot / baseEnvelope` 增长。三者使用饱和并集 `1 - (1-a)(1-b)(1-c)` 合成，避免互相遮蔽和无界叠加。
- 动态 Bloom 使用有界 attack/release。移准输入的单帧速度仍是输入事实，但只作为目标，不再逐帧直接改写最终准星半径；击发恢复继续服从 recovery delay。
- 当前权威角散布为 `contextualMin + combinedBloom * (contextualMax - contextualMin)`；强制最大散布仍得到上下文最大值。
- `WeaponAccuracyProjection::worldRadius` 继续表示真实几何圆锥半径；`reticleRadius` 改为连续组合几何半径和动态可读增量，不再在两条半径之间逐帧取最大值。SDL 只做像素对齐后绘制。

## 3. 自动化与验收

- WeaponFire：距离只扩展包络、静止保持上下文最小值；移动、甩枪、单发及连续射击在近/中/有效射程均能增加当前散布；组合贡献单调有界；停止后恢复；相同 seed 保持确定性。
- 稳定性：不同帧分割下 Bloom 结果接近；一帧鼠标尖峰不会造成下一帧准星半径回落闪动；移动与鼠标同时输入时半径变化连续且有限。
- 投影：世界半径与权威角散布一致；动态可读增量在距离较远时仍可见；SDL 坐标像素对齐不回写 simulation。
- 回归：射击 cadence、ADS、换弹最大散布、后坐力手动压枪、逻辑弹道、特殊命中和 F10 会话内覆盖保持。
- Windows Debug 全目标、focused tests、全量 CTest、exact-head Windows/Ubuntu CI 后，交由用户在正常 Raid 中验收静止距离变化、走动、快速甩枪、点射/连射和移动加甩枪。开发代理不启动游戏。

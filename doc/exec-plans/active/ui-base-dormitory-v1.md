## 页面怎么调整

标题保留当前实际中文 **“宿舍与休息”**，拆成“居民与扩建”“休息”两个标签。采用已验收的深色面板、灰绿强调色；标题约22、正文14、辅助12逻辑像素。沿用1280×720逻辑布局和三档窗口，不增加长篇说明。

### 居民与扩建

顶部短摘要显示居民人数、健康／受伤、床位容量与缺口、可用劳动力。正文左右分栏，口粮信息收进可展开摘要。

| 区域 | 内容和操作 |
| --- | --- |
| 居民与岗位 | 四类职业的总人数与受伤人数；工坊、医疗岗位现状；“自动补岗”及本次实际结果。 |
| 宿舍扩建 | 当前等级、当前与扩建后床位；现有建材／所需建材、所需劳动力和耗时。 |
| 建设状态 | 准备扩建、进行中、已完成、被其他建设占用分别显示。进行中使用实际剩余时间。 |
| 操作区 | 开始扩建；进行中的“取消并返还建材”作为独立次要按钮。 |
| 口粮摘要 | 公共食物库存、每日需求、距下次每日结算的时间。仅展示已有数据。 |

“自动补岗”沿用原有优先级与资格，只填可用的空岗位，保留已占岗位和任务占用。结果如实显示填入了哪些岗位；部分补齐不能显示成全部补齐，无合适人员则显示原因。

可用劳动力直接使用现有投影，包含建设与区域任务的占用。床位不足继续只提示，不新增游玩限制。口粮摘要不按公共库存推算“还能撑几天”，也不自行判定缺粮；实际每日结算仍可能使用原来已授权的补给。

扩建继续占用全基地原有建设槽。别的设施正在建设时只提示被占用，不能误取消对方项目。取消只针对当前宿舍项目，公共建材池必须能完整接收返还；空间不足时保留全部状态并显示原因。

### 休息

保留 **1／6／12小时**，改成“选择时长 → 看预览 → 开始休息”。进入页面不默认执行或选中可提交方案。

预览展示当前日期与时间、休息后的日期与时间／昼夜，以及将跨越几次每日结算。提示采用短句：“推进时间与每日需求，不治疗玩家。”每日结算继续沿用原授权补给规则，不承诺随机事件、士气变化或具体最终扣料。

选时长只更新预览。只有点击固定操作区的“开始休息”才调用原命令；成功后清除本次选择，反馈以实际回执为准。切标签或关闭时丢弃未确认选择，不会执行休息。

休息仍可按原规则完成到期建设、制造、居民治疗和其他既有时间任务。玩家不会因为休息自动治疗或恢复新增精力。基地时钟自然运行、模态页暂停及活动限制保持原政策。

## 点击与显示

沿用约120毫秒的悬停／按压反馈，动画不移动命中范围。操作必须在同一按钮内按下、松开后才执行一次；移出、滚动、切标签、关闭、失焦、切语言或窗口变化清除旧按压。

执行前重新查询。若按压期间休息到达时间、扩建项目或补岗结果变化，刷新后要求重新点击，不能把“开始”变成“取消”，也不能取消刚替换的项目。每个操作按自身原查询决定可用性，不能因同页某项设施不可用而禁用其他合法操作。

长失败原因在限定区域换行，必要时滚动；不隐藏关键条件。空人口、无合适人员、床位不足、无后续扩建等状态都有短说明。中英文采用同一布局与数据，数字、按钮和结果信息不得相互遮盖。

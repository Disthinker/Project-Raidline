## 玩家结果与依赖

厨房/净水站的首次建设不再只增加一个隐藏等级并直接视为已安装。项目完成后，设施进入储备并产生完成通知；玩家在基地按 `B`，从“已有”页选择厨房/净水站，以绿/红虚像放置到基地板块的合法位置。放置后它成为可碰撞、可在地图和建设界面定位、可右键管理的真实世界设施，并可打开现有物资分配与基地需求功能。

本切片依赖 PR #132 的站点独立布局和 PR #133 的 Reserve 原子部署。仓库、医疗所、宿舍、工坊及既有建设、迁徙、供应、Raid 生命周期保持原规则。

## 领域、存档与客户端合同

- `base_construction.kitchen_water.level_1` 完成时写入等级 1、设施所有权和 Reserve 起始世界分钟，并补齐每个已发布基地站点的稳定默认布局；不直接安装。
- Reserve 状态不参与世界绘制、碰撞、战术地图或近距交互。`InstallBaseFacilityAtCommand` 继续作为恢复 Installed 与提交当前站点位置的唯一事务。
- `BaseFacilityKind::KitchenWater` 成为第五种可空间部署核心设施，拥有独立占地、世界标签、管理投影和建设面板卡片。其功能入口复用现有 Allocation/Needs 页面，不创建第二套物资所有权或需求系统。
- schema v41 继续使用 v40 的布局 JSON 结构，但显式迁移 v40：若旧档已经拥有厨房/净水站而没有空间位置，为每个站点补齐确定性默认位置并保持原 Installed/Reserve 状态，不重排资产、不推进时间。
- 当前内容定义与 ID 不变，不修改 content 版本、美术资源或 Manifest。所有新增文本提供中英文。

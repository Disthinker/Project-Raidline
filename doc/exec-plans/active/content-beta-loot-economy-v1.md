# Content Beta Loot 来源、经济与补给可持续性 v1

## 产品结果、基线与范围

本切片让玩家能够根据当前缺口选择基础补给、通用武器/防护升级或高危重型装备目标。成功带回的内容继续由现有 AssetRegistry、装备、制造、回收、失物和寻回闭环消费；基础供给能够解除死档，但不能成为高级装备的最佳来源。

依赖基线为已经用户验收并合入的 PR #118，`origin/main@e24da4c`。分支为 `codex/content-beta-loot-economy-v1`。PR #118 的一次性完整目录补齐属于用户明确要求的开发期可检查入口，本切片保留它且不重复发放；正式成长验证以 Loot、固定供应和制造的真实来源为准。

明确排除：新地图主题、动态价格、专业商人网络、第二货币、任务直接奖励、随机词条、组件改枪、特殊弹、正式美术、资源 Manifest 和额外音频。现有地图宏观生成、失物/寻回、装备槽、移动和射击手感不改写。

## 来源梯度与内容合同

不新增一套会与运行时漂移的 Source 标签。发布来源直接由三个现有权威消费者组成：

1. `market_buy_price > 0`：进入固定基础供应；客户端从 ContentRegistry 查询，不再维护硬编码列表。
2. `base_manufacturing.recipes`：进入基地制造；活动订单继续冻结配方、输入、输出和完成时间。
3. Loot 表引用：进入固定地图、Frontier 资源点、地点专属资源点或高危危机来源；Deploy 时继续冻结结果，不刷新、不在加载时重抽。

来源梯度固定为：

- 低风险：9×19 标准弹、基础医疗/维修、轻型装备与手枪/冲锋枪机会。
- 普通/工业：5.45×39 标准弹、通用武器、均衡防具和容器升级。
- 高危/地点专属：7.62×51、高级普通弹、精确射手/轻机枪和重型装备。

每件当前发布物必须至少具备一个真实来源和一个现有消费者或去向。基础生活/建设材料由 Base 需求、自动供给、制造、建设加工或回收消费；武器、弹药、防具和容器由配装、耐久、维修、出售、失败及寻回消费。没有消费者的填充定义不得加入 Loot。

## 地图与高危产出

- Greyline 使用基础补给表，稳定提供 9×19、医疗、生活物资及少量轻型装备。
- Riverside 使用低至中风险表，在基础补给上增加少量 5.45、轻型防护和短卡宾机会。
- Ashworks 使用工业补给表，主要提供维修材料、5.45、通用武器和均衡装备。
- Frontier Exchange 继续由六类语义资源点决定产出；普通维护/路边资源承担补给，高价值货物与地点专属资源承担升级。
- 三类 Frontier 高危危机分别使用独立高级表，不再复用普通地点表：服务车队偏医疗/轻型与高级 9×19，工业突破偏 5.45/通用重装，货运封锁偏 7.62×51/精确或持续火力装备。

所有表继续使用稳定 DefinitionId 和独立命名随机流。旧 pending Raid 读取已经冻结的 Loot 与 rules，不因 content 更新重抽。

## 固定供应、制造与防套利

- 固定供应只枚举 `market_buy_price > 0` 的定义。高级普通弹、精确射手/轻机枪、重型防具与最大容器保持无无限购买来源。
- 工坊在现有维修包配方之外增加三种有限基础弹药批次：9×19 标准弹、5.45×39 标准弹、7.62×51 标准弹。配方只消费现有工业材料，不新增资产所有权或队列系统。
- 工坊页面改为鼠标选择配方；开始、完成、取消和跨进程恢复继续走现有 ManufacturingDomain。
- 内容加载验证每项制造输出的总回收价值不高于输入总回收价值；固定供应继续保持 25% 回收关系。拒绝购买/制造必须零修改。
- 基础供应和制造只是恢复渠道。高级普通弹与高级装备仍主要来自 Loot；不得通过拆装、制造、回收或购买形成稳定套利。

## 版本、迁移与不变量

- content 升至 `content-beta-loot-economy-content-55`，rules 升至 `content-beta-loot-economy-29`，schema 保持 v38。
- content v54 与 rules v28 显式兼容；现有物品 DefinitionId、实例 ID、位置和目录补齐事务不变。
- 旧 pending Raid 继续使用冻结的 content/rules/布局/Loot；新 Frontier Raid 才写入 rules v29。
- Settlement、回收、制造和寻回继续幂等。任何失败都保持 Profile 指纹、revision、货币、稳定 ID 高水位和资产数量不变。

## 自动化与正常游玩门禁

- 所有 50 个发布定义至少存在一个真实来源和一个消费者/去向；所有 Loot 引用可解析。
- 固定供应集合与 `market_buy_price` 完全一致；高级弹、重型武器/防具和最大容器不泄漏进入无限供应。
- 三张固定地图、六类 Frontier 资源点和三类危机在多 seed 下产出层级符合角色，关键表非空且可达。
- 三种基础弹药配方的指定选择、输入消耗、输出数量、等待完成、跨进程恢复、取消与空间不足零修改。
- 购买、制造和回收组合不存在正收益循环；错误兼容、资金不足或材料不足保持状态不变。
- content v54/schema v38、rules v28 pending Raid、失物/寻回和重复 Settlement 回归。
- 工坊配方、来源提示及固定供应的中英文文本可读。

用户最终正常游玩：分别从 Greyline、Ashworks 和 Frontier 高危目标带回不同层级内容；在 Base 购买基础补给、用鼠标选择并制造三种标准弹药中的任意两种；用带回装备完成下一次配装；经历一次失败后确认失物/寻回仍保持唯一所有权。验收不依赖专用单步按钮。

## 提交、PR、风险与回滚

本分支只交付 Content Beta Macro 3。提交按计划、来源/内容、制造与客户端、测试/状态收尾组织，最终形成一个 Draft PR；未经用户授权不合并。

主要风险是来源数据重复、完整目录开发补齐掩盖成长、旧 pending Raid 被新表重抽、多个配方仍被客户端 `.front()` 假设锁死，以及制造/回收套利。通过直接查询权威来源、保留补齐事务但不重复发放、冻结快照兼容、定义驱动配方选择和内容加载防套利门禁控制。回滚使用普通 revert；已持久化的稳定 ID 和旧 content/rules 兼容不得删除，不重写历史或强推。

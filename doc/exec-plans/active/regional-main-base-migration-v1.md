# Regional Main Base Migration v1

## 产品结果与范围

本宏切片让已清剿并建立前哨的基地候选点真正成为可迁入的唯一主基地。玩家先完成厨房与净水站建设，在区域页预览迁徙耗时、基础设施和旧基地结果，再以一次原子事务把科技核心、人口、Stash 与可移动设施迁往 Ashworks Logistics Yard；Greyline Yard 同时降级为没有仓储或服务的标准轻量哨所。玩家可以把迁徙后进入设施储备的工坊免费重新安装，并从新主基地路线继续出击。

产品事实来自只读 GDD 的 `systems/23_基地设施与建设.md` 与 `systems/24_区域交通基地迁徙与哨所.md`。本切片选择 12 小时作为开发期迁徙耗时；它是普通平衡参数，不冻结长期策划数值。

明确排除：第二套 Stash、逐格搬运、随机损失、专用燃油/包装费、完整基地布局编辑、设施耐久/攻城损伤、独特设施修复与实际效果、夜战、迁徙动画、新美术、新音频和 manifest 修改。当前尚无尸潮预警状态，因此“预警期间禁迁徙”保留为未来出现真实消费者时必须接入的门禁，不为此创建空攻城框架。

## 基线与交付边界

- PR #106 已经用户正常游玩验收，并以普通 merge commit `e6721e4` 进入 main。
- 分支：`codex/regional-main-base-migration`；基线 `origin/main@e6721e4`。
- 同一 PR 连续交付设施准备、原子迁徙和新基地可玩投影；内部使用可独立回滚的领域/客户端提交。
- Codex 只运行自动化、构建与 CI，不自行启动游戏。人工验收统一留给用户。

## 状态所有权与不变量

- `BaseFacilityDefinitionId` 是设施稳定身份；ContentRegistry 定义仓储区、宿舍、厨房与净水站、医疗所和工坊，以及是否为迁徙必需设施。
- `BaseConstructionState` 唯一保存当前已拥有设施的 `Installed` / `Reserve` 位置和入库世界分钟；设施储备不占 Stash，不复制物品资产。重装按入库时间整体平移相关队列，保证等待多久都保留精确剩余进度。现有三类设施等级继续由同一状态保存，作为消费者安全迁移的过渡结构。
- `TechnologyCoreState` 保存唯一不可丢失核心的稳定实例 ID 与当前基地地点；它必须与 `activeBaseNodeId` 指向同一地点。
- 迁徙预览是纯查询。拒绝迁徙时 Profile 指纹、revision、世界时间、日结、设施位置、前哨驻守与队列完成时间全部不变。
- 迁徙提交在一个候选 Profile 中完成：推进世界时间和正常日结；将设施队列完成时间整体后移以冻结其精确剩余进度；迁移核心；切换唯一 active Base；把目标地点关联前哨关闭并释放驻守；把旧基地关联前哨建立为离线状态；全部验证、保存成功后才交换内存。
- Stash、装备、容器和人口不复制、不改位置。迁徙只改变它们所属的唯一主基地上下文。
- schema v30 保存科技核心、设施位置和迁徙后的区域状态；v29 及更早档案迁移为 Greyline 核心，已有仓储/宿舍/医疗/工坊，厨房与净水站尚未建设。

## Step 1：设施与科技核心准备

- content v39 发布五个稳定设施定义、厨房与净水站 0→1 建设项目、每个基地地点的四个合法核心设施位和 12 小时迁徙耗时。
- 区域页显示四项迁徙基础设施状态；厨房未拥有时允许使用现有建设材料、劳动力和世界时间正常建设，而不是验收专用按钮。
- 新档和旧档都持有唯一科技核心；缺失、重复/坏设施 ID、核心地点与 active Base 不一致均拒绝。

## Step 2：原子迁徙与旧基地转前哨

- 目标地点必须已解锁、关联前哨已建立、不是当前基地，并拥有合法核心设施位；四项必需设施必须已拥有。
- 迁徙期间建设、制造和居民治疗精确暂停；NPC 寻回等不依赖基地设施的世界日程按迁徙世界时间正常推进。
- 完成后仓储、宿舍、厨房/净水和医疗所自动 Installed；工坊进入 Reserve。目标地点不再同时作为前哨，旧基地成为已建立但无人驻守的离线标准前哨。
- 重复 transaction ID 幂等，保存失败保持内存旧状态。

## Step 3：新基地运行与免费重装

- 区域页从 active Base 动态计算路线，并显示科技核心、迁徙预览、设施储备及地点优缺点。
- 玩家可从区域页把储备中的工坊免费重新安装；安装不推进时间、不消耗材料，并恢复其暂停队列。
- Base 工坊入口只在设施 Installed 时运行；在储备中时给出明确双语提示，不允许其生产或升级消费者继续假装可用。
- Ashworks 主基地发布直达 Greyline/Riverside/Industrial/Frontier 的固定路线；回迁 Greyline 使用同一查询与事务，不增加一次性限制。

## 验证与统一验收

人工验收：在 Greyline 区域页确认厨房缺失会阻止迁徙；投入建材并完成厨房/净水建设；迁往 Ashworks 后确认世界时间推进、当前基地改变、Greyline 变成离线前哨、工坊进入储备且暂不可用；免费重装工坊后确认原队列/功能继续；进入一次 Raid 确认路线来自 Ashworks；退出重开确认全部状态保持。开发代理不自行启动游戏。

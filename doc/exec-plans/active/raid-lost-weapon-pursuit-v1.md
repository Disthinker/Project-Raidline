# 河畔检查站失物追踪与原枪夺回 v1

**用户已授权交付 · RL-RAID-LOST-WEAPON-PURSUIT-v1**

在「河畔检查站」阵亡并丢失长枪后，玩家可以再次出击，找到带着原枪巡游的感染者，夺回这把枪并撤离。回到基地后，用现有「武器维护」和补弹功能整备，再把它带进下一局。本阶段一次交付从失物选择到再次实战的完整流程。

## 玩家规则

| 环节 | 拟实施行为 |
| --- | --- |
| 选寻回方式 | 从基地「行动失物记录与寻回」选择河畔检查站的一条记录。阵亡后还没结算过其他对局，仍找原来的静态缓存。随后已结算 **1～3 局**且记录里还有长枪时，自行寻回默认进入追踪。取一把，先选原主武器槽的枪，再选原副武器槽的枪。没有合格长枪、原局是主动放弃或本局找不到合法巡游点时，沿用静态缓存。也可依旧以 **90 货币、540 游戏分钟**委托寻回。同一条记录只能走一种途径。 |
| 找感染者 | 出击时从本局已有的普通感染者中选一名载体，冻结两个可通行的巡游点。它仍用原来的追击和攻击行为。按 `M` 可看搜索区，发现目标时才显示携枪提示。追出搜索区后，地图仍只显示原搜索区。可带现有声响诱饵把目标引开。 |
| 搜尸取枪 | 击倒目标后，靠近可见尸体，按 `F` 搜索。拖到合法空长枪槽或有足够空间的随身背包，才从旧记录取走原枪。枪上的部件、弹匣内的混装顺序、枪膛弹和耐久一起保留。背包满或槽位不合法时，可调整空间后重试。旧记录中剩余物品继续保留并按原规则老化。 |
| 带回再出击 | 使用原有撤离点。成功撤离时，仍由玩家携带的原枪随人回营。用现有服务维护、补弹、配装，带进下一局实战。载体携带期间保留原枪状态，基地整备沿用现有成本。 |

## 对局结束时，枪归谁

- **还没取枪。** 看见、击倒或打开尸体均只是发现。撤离、阵亡或主动放弃后，原枪仍在旧记录里，并随本次正常结算老化。进入追踪时若已结算 **3 局**，这是旧记录的最后一次机会。
- **已取枪并撤离。** 结算时仍随身携带才带回基地。
- **已取枪后阵亡或主动放弃。** 枪仍属于当时随身装备时，按现行规则随装备进入本局新失物记录。若之后把它留在地面、尸体或卸下的背包里，按对应位置的原结算处理。
- **异常退出。** 按出击前快照恢复原枪、附件、弹药和旧失物记录的年龄。若已取走的是该记录最后一件物品，恢复时也要重建该记录。重复取枪或重复结算只生效一次。

## 实施顺序

1. **冻结选枪与部署条件。** 复用 `raid_lifecycle.cpp` 的自行寻回部署、结算和回退。按原装备槽、物品定义和稳定实例 ID 选枪。河畔现有三组出生与撤离配对、三组敌人部署都纳入验证。复用已有巡游和碰撞净空查询，验证两点、追击可能经过的可搜尸区域、普通撤离与高危信号撤离。选择独立随机流。若条件不足，从未修改的原候选走原缓存流程，保留它原有的选点和掉落规则。
2. **接入单一尸体与原枪转移。** 在 `self_recovery_domain.*` 和 `inventory_domain.cpp` 接旧失物记录到实际库存移动的事务。用部署身份绑定运行时 `CombatTargetId`，由 `gameplay_world.cpp` 和 `game_session.cpp` 消费一次死亡事实。追踪尸体复用现有搜尸面板、距离和视线门槛，界面以只读引用投影原枪。取枪时重新验证尸体、视线、目标槽和容量，一次更新原枪位置及旧记录。若击倒点贴墙，用本局已验证的可达近旁位置投影搜尸；几何检查同时覆盖预备落点。河畔这名载体单独接入，原护甲守卫的搜尸绑定和掉落校验继续使用。
3. **接入提示、诱饵和再出击。** 复用 `game_session_player_transition.cpp` 的世界配置，`raid_tactical_map.*` 的地图标记，以及 `app_ui_lost_recovery.cpp` 的基地入口。新追踪局启用既有声响诱饵，普通局和静态寻回沿用各自的道具资格。简短任务状态放在地图现有提示区，搜索区用轮廓标记，世界内提示走已有观察和可读标签。通过现有补弹、武器维护和装备入口完成回营循环。
4. **兼容、验证与交付。** 当前内容 88／存档格式 70。若为冻结的追踪状态升级格式，明确维持 70／88、69／87 及历史读取规则。旧冻结局按原路线恢复，兼容检查特别覆盖边境封路、河畔情报和库存物品身份。从通过 CI 的主线开隔离工作树，交付一个待游玩验收的 Windows 候选。

范围限于河畔的一名现有感染者、一把真实失物和一条搜尸取回路径。正式地图、怪物数量与战斗数值、普通出击掉落与交易、委托价格以及既有基地服务继续沿用。只增加玩法所需的短提示和标记，阶段范围排除新的敌对枪手 AI、新地图、新美术音频、新管理页面和免成本补偿。

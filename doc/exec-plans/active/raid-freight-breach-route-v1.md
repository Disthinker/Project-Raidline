# 货运装卸间破拆捷径 v1

**已验收 · RL-RAID-FREIGHT-BREACH-ROUTE-v1**

把外勤带回的工业材料做成破拆楔组。下一次进入「边境交换站」的「货运装卸间」，可以省下绕路，也要承担开门动静引来感染者的风险。这次一次交付材料搜集、制作、局内路线取舍和撤离结算。

## 玩家规则

| 环节 | 拟定规则 |
| --- | --- |
| 搜集与整备 | 在「边境交换站」现有「路旁回收点」和「维修物资点」搜材料，正常撤离带回。在「工坊与生产」用废旧零件 ×2、工业紧固件 ×1 制作破拆楔组 ×1，占 1×1 格。基础耗时 90 游戏分钟，沿用现有工坊等级、人员和士气等耗时修正。楔组从工坊制作获得。 |
| 选路 | 新开的「边境交换站」普通对局，把「货运装卸间」中央隔断的一段设为「检修门」。门关闭时可以绕隔断两端；门打开后可沿中间双向通行。原出入口和物资点仍可从绕行路线到达。 |
| 破拆 | 楔组放在随身容器里，面向可见的近侧门面，在 72 世界单位以内按住 F 1.5 秒。起手、持续和完成均核对相同门与同一件工具。松键、走远、失去视线、工具移走、受伤受控、切换空间、打开面板或开始冲突动作会清空进度，工具留在包里。一次按住只对应一次交互。 |
| 通过和撤离 | 完成时扣一组楔、打开通道，并在门口产生一次拟定半径 300 世界单位的同空间声响。符合感知条件的感染者会前去调查，已有追击或攻击继续。门本局保持打开，出楼再回也一样；新局重新关闭。封存器材箱仍按原钥匙开启，带着燃油或其他物资走原撤离点。 |

## 实施方案

1. **制作和材料预留。** 在 `assets/content/v1/core.json` 配置物品和配方，沿用工坊的在制、完成、领取和取消流程。废旧零件单件不可堆叠，工业紧固件一叠最多三件。当前 `content_registry.cpp` 和 `base_manufacturing_domain.cpp` 的工坊输入合同只接受独立单件，拟对该配方增加按数量预留。取两个独立废旧零件，紧固件从现有堆里准确取一件，剩余留在原处。采用库存的数量和资产事务，取消退回预留数量，容量不足按现有取消拒绝处理。订单验证按该配方实际总数、归属及产物校验，沿用现有存档的预留资产与订单格式。原配方继续按既有单件合同处理。只扩充原工坊配方列表和中文名。
2. **冻结位置和几何。** 在 `raid_lifecycle.cpp` 生成新普通局时按版本冻结可破拆资格，采用「货运装卸间」室内固定中央隔断 `freight_cargo_divider`，保留隔断两段，仅使中间可开。拟定门洞 x=700–780、y=210–310，高 100。现有玩家为 32×32，该处感染者为 50×50；计入其导航留边后，中心线仍可通行。两侧对照点 (640,260) 与 (840,260) 直穿 200 单位，闭门绕行的几何估算约 360 单位。现有四个掉落点与三个敌人出生框均在门洞外。实现后用真实移动查询验证两端绕行、双向过门和路程差，再交付试玩。
3. **一次提交开门。** `game_session.cpp` 可参考封存器材箱已有的长按、取消与输入占用，给门独立目标和提示。距离与观察针对面向玩家的门面，门本体不造成自遮挡误拒绝。复核有效后在同一提交中消费指定楔组并切换门状态，重复、打断和拒绝均按一次交互结算。声响使用现有局部调查机制，保留声源空间、有效听众与已追击或攻击优先级；已有枪声广播会直接改变追击目标，因此该动作走一次性调查入口。界面沿用现有情境文字和进度条，靠近门时才提示。
4. **同步所有几何查询。** `gameplay_world.cpp` 中移动与视线读取空间索引，弹道和室内图还有挡板投影，当前敌人导航缓存按空间与体型缓存。为这一个小室内空间在出击准备时构建开、闭两态的索引和导航字段，门状态切换后用同一份几何驱动玩家和敌人碰撞、视线、照明、弹道及地图投影。更新该空间的几何修订并使旧路径与观察、照明缓存失效。战术地图继续按已发现与已知布局权限展示；路线选择可从实际场景看到。现有几何和文本占位即可。
5. **旧档、入口和结算。** 门的打开状态仅活在本局，重进同一室内保留。旧冻结局默认原隔断，出击时资格按实际存档合同记录，优先沿用格式 66；内容拟升级到 84，并把 83 的图纸和画线接入后继版本支持链。通过已有资产位置、出击前恢复与结算处理工具和战利品。正常撤离带回原物资，死亡、主动放弃及异常退出沿用原规则。以已验收提交 `6c0df90` 作为下一独立候选分支的明确依赖，它已包含 `7206b3f`。两阶段目前仍分别在远端分支。固定桌面入口在候选验证后更新，原程序和升级前主档、备档留存，回退时配合兼容档案副本。

## 联合验收

1. 正常撤离带回材料，或使用已有仓库材料，在「工坊与生产」制作一组楔。若紧固件原来成堆，核对只预留一件，其余留在原处。
2. 带楔进入「边境交换站」的「货运装卸间」。先走原绕行路线，靠门按住 F 后中途松开一次，确认门仍关着、工具仍在。再按住完成，核对只扣一组，门可双向走，附近符合条件的感染者会来调查。
3. 从打开的门折返，带一件原有物资正常撤离。核对封存器材箱仍认原钥匙。再次开新局，检修门恢复关闭，库存和带回物资与结算一致。

自动化核对材料预留与取消、库存不足和重复输入、两侧交互与受伤中断、视野与声响权限、开闭两态的移动／视线／照明／弹道／导航、重进房间、失败与正常结算、81／65、82／66 和 83／66 存档副本。测量破拆提交帧与开闭查询耗时，原有 **14 项 3 ms** 负载和门槛全部沿用。真实移动未形成更短路线，或任何几何查询在开门后不同步时，继续修正后再交验。

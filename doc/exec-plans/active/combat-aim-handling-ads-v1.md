## 1. 玩家结果

- 实际准星保存世界位置和速度，不瞬移到鼠标；突然转向时从当前 P 向新目标 B 运动。最大速度是隐藏参数，人机工效控制玩家瞄准与后坐力恢复的加速度。
- 成功击发把准星中心大致沿“枪口到实际准星”的射线方向推开，并加入少量确定性横向偏转。再次击发刷新后坐力速度而非累加；反向减速度只让后坐力速度逐渐归零，不把准星位置拉回击发前瞄点。玩家必须用反向鼠标位移压枪。
- 实际准星中心决定总体方向；每发再在当前散布内抽取确定性随机偏移。精准度控制最小散布，稳定性控制最大散布，操控速度控制停火后的收缩速度。
- 逻辑弹道从枪口沿冻结方向推进到武器最大距离；准星距离不再成为地面终点。最先接触的敌人或阻挡物产生唯一命中，否则最大距离产生地面命中。
- 腰射、机械瞄具和低倍镜显示短、快、弱且只覆盖已飞区段的曳光；高倍镜不显示。当前基础 ADS 作为机械瞄具，因此仍显示弱曳光。
- `F10` 打开开发者调参面板。面板可暂停战斗输入、查看当前武器原始属性和派生手感参数，并用键盘即时调整；覆盖只在当前进程/当前武器实例生效，不修改内容定义、Profile、存档或 manifest。

## 2. 状态与属性合同

`WeaponAimState` 位于 SDL 无关 simulation，保存：

- 当前世界位置、鼠标输入位置与可被后坐力推移的控制目标；
- 玩家控制速度与后坐力速度；
- ADS 进度和初始化状态；
- 武器射程与确定性后坐力随机状态。

后坐力只有 `Stable` 与 `Active` 两个逻辑阶段。击发时直接替换 `recoilVelocity`；推进时以人机工效派生的反向加速度把速度减到零，不使用无限累加的角偏移。鼠标输入以相邻帧位移推动控制目标，后坐力位移同步推动当前准星与控制目标，因此鼠标静止不会形成自动回正弹簧。

五项属性固定职责：

- `recoilControl`：后坐力初速度，越高越小；
- `stability`：最大散布，越高越小；
- `handlingSpeed`：拔枪/切换与散布收缩，越高越快；
- `ergonomics`：准星控制加速度、后坐力减速度与 ADS 进入速度；
- `accuracy`：最小散布，越高越小。

隐藏最大准星速度、单发扩散量、横向偏转比例和移动/ADS 修正属于 SDL 无关 `WeaponHandlingParameters`，不作为新的玩家显示属性。

## 3. 弹道、碰撞与表现边界

- `ShotCommand -> ShotResolution -> LogicalBallisticFlight -> HitResult` 保持稳定。WeaponAmmo、耐久、故障和存档不依赖场景 Projectile。
- `ShotResolution::maximumDistance` 来自当前武器定义和世界边界，不读取准星距离。`impactPosition` 是最大距离终点，不是鼠标或准星点。
- 每帧只扫描逻辑弹道已飞线段。敌人和窄 `BallisticBlocker` 候选使用相同首次接触比例，稳定选择最近候选；一次 ShotId 只形成一个命中。
- 当前 Alpha 地图以数据值提供实际可见的阻挡矩形，不建立通用物理系统。障碍命中伤害为零并形成明确 `Obstacle` 结果；最大距离形成 `Ground` 结果。
- 曳光策略是 `None/Weak` 只读投影元数据，与逻辑飞行和伤害权威分离。App 只能使用 origin、current position 和 distance travelled。

## 4. 开发者调参面板

- `F10` 在 Raid 中切换面板；面板打开时拦截移动、射击、换弹、动作和世界交互，逻辑弹道/敌人仍按正常时间推进，不创建新的暂停系统。
- `Up/Down` 选择参数，`Left/Right` 调整，`Shift` 使用较大步长，`R` 重置当前武器覆盖，`F10/Esc` 关闭。
- 第一组可调原始定义：后坐力控制、稳定性、操控速度、人机工效、精准度、射击间隔、基础伤害、有效射程、最大射程。
- 第二组可调隐藏手感：最大准星速度、单发扩散量、后坐力横向偏转比例、移动散布比例、ADS 精准度/稳定性倍率和弱曳光长度/透明度。
- App 只调用窄 `adjustDeveloperWeaponTuning(parameter, direction, coarseStep)`；GameSession 校验范围并保存按当前武器实例区分的运行时覆盖，再要求 GameplayWorld 重配置该武器的射击瞬态。无效调整零修改。
- 调参覆盖不保存、不参与结算、不改变 ProfileRevision。面板明确显示 `RUNTIME ONLY / NOT SAVED`，正式内容数值仍需之后回写 JSON 并走内容审查。

## 5. 明确排除

- 正式瞄具附件、导轨和高倍率圆形视野；高倍无曳光只建立有自动化消费者的策略合同。
- 穿透、特殊弹、压制、断肢、血液、击退、尸体与正式枪声。
- 通用物理引擎、ECS、事件总线、通用相机框架或公开 Mod/控制台系统。
- 新正式图像/音频生产、资源发布及美术 manifest 修改。

## 6. 自动化与人工门槛

- 准星：P 到 B 而非 A 到 B、径向不瞬移、速度/加速度上限、鼠标位移驱动目标、分帧稳定、ADS 与边界钳制。
- 后坐力：射线外推、横向有界、属性影响、反向减速、新枪刷新不累加、连续射击不产生无限速度、鼠标静止不自动回正、反向鼠标输入才能压回。
- 散布：精准度只控制最小值、稳定性只控制最大值、操控速度控制恢复、连续射击保持高位、PCG32 序列确定。
- 弹道：近准星不截断、敌人/障碍最近优先、高速大帧不穿透、最大距离只产生一次 Ground 命中。
- 表现：曳光不超过已飞区段；腰射/机械/低倍为 Weak，高倍为 None；App 投影不携带伤害权威。
- 面板：输入仲裁、范围钳制、无效命令不变、按武器实例隔离、重置、切换后恢复覆盖、Profile/存档指纹不变。
- 回归：WeaponAmmo、耐久、故障、多武器、敌人攻击、医疗、库存、Settlement 和完整 CTest。
- 交付：Windows Debug 全目标、全量 CTest、exact-head Windows/Ubuntu CI。开发代理不启动游戏；最后由用户正常游玩并使用开发者面板调参。

## 7. 风险与回滚

- 输入过慢：默认最大准星速度由 720 提高为 1400 像素/秒，并提高基础武器人机工效；小修正继续使用到达控制，开发面板允许即时微调。
- 连射失控：后坐力速度替换而非相加，位置/速度有界，随机横向比例受限。
- 帧率差异：准星运动使用有限子步；弹道继续分段连续扫掠。
- 反馈错位：伤害、粒子和命中语义只在逻辑弹道接触时产生，曳光只消费已飞进度。
- 整个 PR 可回滚到 `origin/main@7877d71`；不需要存档反向迁移。开发者覆盖没有持久状态，关闭进程即可完全清除。

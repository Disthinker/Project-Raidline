# 医院夜间行动与供电整备 v1

**已验收，正在交付 · RL-RAID-HOSPITAL-NIGHT-OPERATIONS-v1**

第一趟去医院找夜视仪，撤离后装到头盔上、备好电池。第二趟看准抵达时间，用夜视走过暗处，把医疗物资带回来。四项一起开发，只交付一个联合验收候选。

## 玩家会用到什么

| 环节 | 拟定规则 |
| --- | --- |
| 医院搜获 | 新开普通对局，在「医院片区 → 区医院内部 → 后勤走廊」现有物资位固定投放一件夜视仪，昼夜均可取得，电池另备。它替换该点一次临床随机掉落，原池为绷带、急救包、止血带、止痛药、纸巾或瓶装水。其余四个院内点、室外点与高危奖励保持原规则。夜视仪仅从此点取得，首版无市场买入或回收价。 |
| 基地整备 | 首版支持基础头盔的一个夜视安装位。沿用检视和装拆入口，装入现有通用电池。头盔、夜视仪和电池各自保有实例。拆卸先检查落位，空位不足时原状态保留。出击前通过「宿舍与休息」和既有抵达预览安排时间。 |
| 夜间观察 | 夜间室外和弱光室内生效。首轮验收目标为夜间室外 150°／850 世界单位、弱光室内 140°／750，现状分别为 100°／600 和 110°／500。观察随准星方向，仍受墙体、所在空间和交互距离限制。白天室外待机，进暗处恢复，保留瞄镜的视野限制、遮罩和开收镜手感。 |
| 设备与续航 | 短按 **U** 切换当前选定设备，默认手电，仅有一件可用设备时直接切换。双设备时长按 **U**（沿用 0.35 秒）呼出轮盘，松开选中设备并切换该设备，取消则保持原状态。两件可同时开，各用各的电。切枪只改变武器手电；满电夜视约可输出 180 秒，低电提示、中断和换电有明确反馈。仅有效输出扣电，暂停、待机、菜单冻结及未接入活动不耗夜视电量。 |

照明规则接入现有支持光照扇形的对局空间。医院是投放和联合验收地点。维持已验收的准星、HUD、地图权限、搜尸、武器、手电和结算。沿用现有轮盘、物品表现和程序绘制。范围限定在一款头戴设备、一个掉落点和相应交互，既有敌人感知、基地规则、地图和美术资产沿用。

## 开发顺序与验收门槛

1. **先锁定物资和资产关系。** 后勤走廊继续消耗原随机抽取，再替换该位置结果。保持槽数、槽序和其他随机结果。对局生成时冻结物资，校验地图、室内与稳定槽位。头盔 → 夜视仪 → 电池使用唯一资产树。头盔挂载位置和新的设备资格须验证宿主类型，换电复用现有容量预检及原子提交。
2. **再接供电与观察。** 共用玩家输入、输出投影和存储合同。保留手电的原输入、耗电和故障恢复。将夜视的暗处观察参数送入现有视野查询，同帧共享遮挡结果给显示与交互，组合双设备时避免重复构造观察。验证跨昼夜和建筑边界、开收镜、换枪、取消轮盘、低电和归零。
3. **最后做一次联合回归。** 从内容 76／schema 60 的存档副本开始，覆盖旧冻结对局、既有头盔／电池和档案回读。新增挂载位置需要版本化读写。覆盖装拆失败、落地、丢失、寻回、异常恢复和重复结算。保留原 12 项 3ms 检查的负载和门槛，另测双设备同时输出的密集遮挡场景。全量通过后冻结一个候选，沿用桌面 **Project Raidline Debug**。开发验证期间保全原档和原候选；若新档已写入，回退使用保留的新档读取能力或隔离归档，避免旧程序丢失已取得的设备。

## 一次联合验收

1. 普通医院出击，进后勤走廊拾取夜视仪，正常撤离。
2. 在基地装到基础头盔、装入通用电池，根据抵达预览安排夜间出击。
3. 在医院室外和区医院内部对比夜视开关。确认墙后目标仍被遮挡，手电与夜视可以分别开关，同时开启也各自耗电。带回一件原有医疗物资。
4. 正常关闭并重开。检查头盔、夜视仪、电池的位置和剩余电量。

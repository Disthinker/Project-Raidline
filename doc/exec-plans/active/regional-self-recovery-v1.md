# Regional Self-Recovery v1

## 产品结果与范围

玩家可在基地选择一条仍待处理的失物记录，将下一局目标切换到该记录的原地图。Raid 中会生成一个代码图形占位的失物缓存；玩家持续交互打开后，整条记录中的装备才从失物所有权原子迁移到 Raid 地面。玩家需要在本局携带并成功撤离，才能真正找回物品。

唯一产品事实来源为只读 GDD 的 `systems/07_Loot撤离与结算.md`。本切片不实现尸体、敌对幸存者携带、保险、载具、自动拾取、新美术、新音频或资源 manifest 变更。

## 状态所有权与领域合同

- 部署前及缓存未开启时，`LostRaidRecord` 继续唯一拥有失物根；Pending Raid 只保存稳定 ID、原槽位和冻结位置引用，绝不复制所有权。
- 只能选择与出击地图一致、未进入 NPC 任务且仍存在的记录；无效或过期选择必须零修改拒绝。
- 缓存位置由稳定随机流从本局未占用的普通 Loot 槽位中冻结，写入 Raid 快照并参与地图连通验证。
- 持续交互完成时，整条记录的根资产原子迁移到 `RaidGroundAssetLocation`，原记录删除；其容器内容和已安装弹匣继续跟随父项。
- 恢复物可拾取到随身容器；合法且为空的装备槽支持直接穿戴。容量不足只拒绝本次拾取，不丢失地面资产。
- 缓存未开启即结算：原记录按现有规则老化。缓存开启后未拾取的资产在结算时删除；已拾取资产成功撤离则保留当前位置，失败则进入本局的新失物记录。
- 异常退出恢复进入 Raid 前的精确 Profile；即使缓存已开启，也必须恢复原记录、原根槽及全部子项，不复制、不吞掉。
- NPC 任务可与另一条记录的 Raid 自行寻回并存；同一记录不能同时被两条路径拥有。
- 所有拒绝操作保持 Profile fingerprint、revision、货币、ID 高水位与资产总量不变。

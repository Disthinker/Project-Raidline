# Raid World 空间战术可靠性 v1

## 目标

让 `Frontier Exchange` 的程序化室外空间和固定室内空间具备可信的阻挡战术：未被声音暴露的敌人不能隔墙获得玩家位置；已经获得线索的敌人会沿当前空间的合法阻挡边缘调查或追击，不再长期直线贴墙；Scratch/Grab/Bite 不能穿过墙体提交命中。

本切片只为当前玩家、敌人、近战和逻辑弹道消费者建立一组 SDL-free 空间查询，不引入大型 NavMesh、行为树、ECS 或通用物理框架。

## 基线与依赖

- 基线：用户验收并合入的 PR #97，`origin/main@a7b3cc2`。
- 分支：`codex/raid-world-spatial-tactical-reliability-v1`，直接从上述主线创建。
- PR #70 是不相干的 Draft 治理分支，不是本切片依赖。
- 当前空间的权威阻挡仍来自 Pending Raid 冻结的 `BallisticBlocker`；室外与室内分别消费自己的 blocker 集合。

## 产品与领域合同

- 视觉感知必须同时满足距离阈值与敌人中心到玩家中心的无遮挡线段。失去视线后，敌人只调查最后已知位置；渲染层不能补充或猜测可见性。
- 枪声、受伤叫声等既有显式听觉刺激继续按半径提供最后已知位置。本轮不实现墙体声学衰减；被声音提示的敌人调查声源，但看不见玩家时不能发起攻击。
- 一次有效线索的调查窗口由 2 秒调整为 8 秒，使现有最大代表性固定 blocker 具备真实绕行时间；到达最后已知位置或超时仍恢复未警觉。
- 追击和调查使用当前空间 blocker 扩张后的确定性可见图，返回一个最小下一路径点。无合法路径时敌人停止，不以持续推墙或穿模作为回退。
- 路径点只影响移动方向；攻击距离、方向和命中仍以真实玩家位置与明确视线为准。Support/Engage、Scratch、Grab→Bite 和 OffBalance 状态机保持唯一权威。
- 玩家移动、敌人移动、视觉查询、近战阻断与逻辑弹道读取同一 `activeBallisticBlockers()` 集合。一次只查询当前空间，不建立跨空间视线、追击或弹道。
- 敌人攻击命中提交前再次验证当前视线。墙体遮挡导致本次命中机会失效，但不反向修改攻击阶段或生成第二套伤害事实。
- 本切片不改变 Profile、ContentRegistry、Pending Raid、schema v23、content v32、资产、货币、Raid 结算或随机流。

## 实现边界

1. 新增 SDL-free `raid_space_query`：有限数值校验、线段—阻挡查询、按角色体积扩张阻挡、确定性最短可见图和下一路径点。
2. `EnemyAiInput` 增加明确的 `targetVisible` 与可选移动路径点。旧调用默认目标可见，历史纯 AI 测试和无障碍行为保持兼容。
3. `GameplayWorld` 在每个敌人有界子步中从当前空间计算视线和路径点，再交给 `Enemy`/`EnemyAiState`；App 不保存路径或可见性状态。
4. 近战接触只在当前空间视线清晰时提交伤害或 Grab 接触。
5. 玩家靠近世界边缘时，寻路终点只收敛到敌人中心可达的世界边界；感知和攻击仍引用真实玩家位置。

## 明确排除

- 视锥、光照、潜行值、蹲伏、遮蔽物高度和动态门。
- 墙体声学遮挡、声音传播图、分材质衰减和跨空间听觉。
- 完整 NavMesh、A* 网格、路径缓存服务、群体寻路、门锁和破门。
- 跨空间 AI 追踪、室内高危增援、程序化室内和第二代表性地点。
- 新美术、音频、攻击动画及资源 manifest 修改。

## 自动化门槛

- `RaidSpaceQueryTest`：无遮挡/遮挡视线、切角不误判、单墙/多墙稳定绕行、无路径安全停止、同输入确定性。
- `EnemyAiTest`：不可见目标不被获取、失去视线转为搜索、听觉线索可调查但不可隔墙攻击、移动路径点不污染最后已知玩家位置。
- `GameplayWorldTest`：室外与室内均不隔墙发现；声音暴露后能够绕过阻挡靠近最后已知位置；整个过程中不与 blocker 重叠；近战不能穿墙提交伤害；现有玩家/弹道碰撞回归保持。
- Windows Debug 全目标、完整 CTest 和 exact-head Windows/Ubuntu CI 通过后交付。开发代理不启动游戏，人工正常游玩验收由用户执行。

## 人工正常游玩验收

1. 在 `Frontier Exchange` 室外利用掩体遮挡未警觉敌人，确认敌人不会仅因距离接近而隔墙锁定。
2. 开枪或制造既有声音后绕到掩体另一侧，确认敌人会绕行调查，不穿墙、不长期原地推墙；重新看见玩家后恢复追击。
3. 进入办公室，重复墙后隐藏、声音暴露和绕行，确认室内外规则一致。
4. 靠近薄墙观察敌人攻击，确认 Scratch/Grab/Bite 不会隔墙造成伤害；正常无遮挡近战仍工作。

## 风险与回滚

- 风险：每敌人每子步重建小型可见图。当前活动敌人上限和 blocker 数量较小；自动化增加有界运行与确定性检查。出现性能压力时只能在保持查询结果不变的前提下按当前空间版本缓存图，不扩大为全局服务。
- 风险：听觉刺激不做墙体衰减可能让敌人知道声源位置。这是明确延期项；本轮保证其只能调查，不能凭声音隔墙攻击。
- 合入前关闭 Draft PR 并弃用本分支即可回滚；合入后普通 revert 对应 merge commit。没有存档或内容版本变化。

# Home Region 基地运营完成通知与设施标记 v1 ExecPlan

状态：已通过 exact-head Windows/Ubuntu CI 与用户正常游玩验收，并以 merge commit `e7590d9` 进入 main。

## 玩家结果与依赖

玩家无需持续打开建设总览等待任务。设施升级、工坊生产或居民治疗完成后，Base 会显示短时、非阻塞的双语通知；建设面板打开时，对应固定设施以脉冲边框突出，玩家仍可通过现有运营总览定位并处理产物或后续操作。

本切片复用 PR #130 的只读运营总览、设施选择和建设镜头，不建立第二任务队列、不增加离线推进，也不改变升级、制造、治疗的领域命令。

## 提交与表现合同

- `GameSession` 只在候选 Profile 验证并成功保存后发布类型化完成事实；保存失败不提示。
- Base 实时推进和“休息”跳时都消费领域返回的 `BaseConstructionAdvanceResult`、`BaseManufacturingAdvanceResult` 与 `ResidentTreatmentAdvanceResult`，App 不比较显示文本或猜测状态变化。
- Raid 内世界时间可能让 Base 任务到期，但提示延迟到唯一 Settlement 成功后发布；异常退出恢复出击前 Profile 时不会出现虚假完成通知。
- 完成事实不进入存档。App 最多保留四条短时通知，重复同类完成刷新时长；通知不暂停、不抢输入、不改变 Profile。
- 建设世界标记只读取活动通知和固定设施位置。通知结束后标记消失；正式美术和 Manifest 均不变。

# 医院救援与公共医疗储备 v1

**已验收 · RL-HOSPITAL-RESCUE-AND-MEDICAL-RESERVE-v1**

去医院安全转移一名受伤的医疗专业居民，再带一份急救物资回基地。可以把物资交给医疗所，让居民康复后上岗，也可以留作随身药品。救援、搜药、治疗、复岗和下一趟整备作为一个版本交付。

## 玩家规则

| 环节 | 拟定行为 |
| --- | --- |
| 医院救援 | 新开的「医院片区」普通出击在「救护车停车区」附近提供一次安全转移。靠近后长按 **F 2 秒**，沿用现有松键、离开及受控中断规则。保存成功后，**1 名受伤的医疗专业居民**立即计入基地人口、床位需求和口粮，康复前不能上岗。沿用原接纳上限和床位短缺规则。 |
| 药房搜药 | 「区医院内部」的「药房 / 医疗储备」用现有一个掉落位固定提供 **1 件急救物资**。每个新开的普通出击可搜一次，留在局内的物资走原有结算与异常退出规则。 |
| 公共药柜 | 在「医疗所 → 居民医疗」打开 **4×4 药柜**。从仓库主动转入或取回急救物资、基础医疗包、绷带、绷带卷、止血带，保留原实例和剩余次数。满柜或满仓时显示原因并整笔拒绝。取回仓库后可按原规则配装、分装和使用。 |
| 接诊与复岗 | 新疗程只用药柜，**先扣 1 件急救物资**，缺少时改用**合计 2 次剩余用量**。优先用余量较少的药品，余量相同按稳定实例 ID 排序。仍是一条队列，每次治疗 1 人，基础 **360 游戏分钟**，沿用人员和设施效率。可手动接诊，也可开启自动接诊并调整四类专业的顺序。燃油仍只加速绑定的当前疗程。 |
| 再次整备 | 康复居民重新进入可上岗人数，可在医疗所安排岗位。仓库里保留的急救物资仍可按原配方分装基础医疗包或绷带卷，带进下一趟出击。 |

新旧档默认手动接诊，专业顺序为 **医疗 → 工程 → 战斗 → 通用**。自动接诊仅在可操作的基地安全核心启用，开关提交、转药入柜、安排医务人员、恢复基地操作或上个疗程结束时按当前条件尝试开始下一单。休息或其他跳时完成后最多开一单，从回到基地的当前时间起算。存档失败保留原状态并可重试。对局、防守、迁徙途中、设施储备及离线期间不自动扣药。切换顺序或关闭自动接诊不改变已开始的疗程。

## 实施范围

1. **固定医院触发位置。** 在 `assets/content/v1/core.json` 和 `content_registry` 增加医院专用救援定义。在 `raid_lifecycle` 生成时沿用救援锚点与通路检查，用精确分区 ID `district.hospital.parking` 匹配停车区。没有合法停车区位置时，用已核对连通性的院区备用位置。单独选位以保留已有锚点的随机序列，避免改变已有撤离与建筑落点。药房只改 `hospital_pharmacy`，保留原掉落随机流位置、接诊区图纸、后勤走廊夜视仪及其他掉落。特殊区域任务沿用各自规则。
2. **复用安全转移。** 用 `raid_rescue_domain` 和 `GameSession::requestOrdinarySurvivorRescue` 接纳居民。图纸与救援都在最新的出击前恢复档上写入各自事实，保存成功才同步到本局。全档最多接纳该居民一次。转移后死亡、主动退出或异常退出均保留居民。药房物资和其他局内资产仍按原路径处理。其余地图的救援规则沿用现状。
3. **药柜与扣药。** 在 `ProfileState`／`AssetRegistry` 拟新增独立的药柜根容器，使用稳定 ID、占格和精确实例。通过专用 `ProfileUiCommand` 处理仓库与药柜之间的双向转移，重验原位置、设施、容量和事务。药柜排除在日结、回收、工坊、玩家自疗及 Raid 配装的候选范围。药品按真实剩余次数扣除，耗尽时移除原实例。扣药和建单同一事务，手动与自动共用合法性检查。医疗岗位、设施等级、治疗完成及供电沿用现有 `base_resident_medical_domain`、`base_emergency_power_domain`。停止供电后仍按现有规则推进，批次不自动绑定下一位。
4. **最小界面与持久化。** 在 `app_ui_base_medical` 和现有医疗页面投影内并列显示 4×4 药柜与疗程摘要。使用现有库存格、布局列线、状态色和保存反馈。小窗优先滚动说明与药品列表，扣除预览和确认键保持可见。存档拟升级到内容 **86**、格式 **68**，明确支持 85／67 的运行及暂停供电、已累计加速、既有治疗与工坊订单。旧档药柜默认空，仓库药品位置和日结分类原样读取，已付费的居民疗程照常完成。旧冻结 Raid 保留当时的救援和掉落。药柜随主基地迁徙，医疗所收起时内容保留。玩家付费医疗仍按现有货币结算，随身用药仍消耗选中的个人药品。

本阶段复用已有地图、救援、医疗、工坊和供电。范围限于上述流程，沿用现有战斗、视野、撤离、失败与存档恢复规则。界面使用已有素材和组件，无新增跟随 AI、护送、任务面板、正式美术或音频。

## 联合验收

1. 通过固定桌面入口 **Project Raidline Debug**，进「医院片区」安全转移居民，在「区医院内部」药房搜急救物资并撤离。
2. 回到基地，从仓库转一份物资到公共药柜，仓库保留一份同类药品。手动开始居民治疗，核对只扣柜内指定物品或次数。推进世界时间，确认居民康复并能安排到医疗岗位。
3. 用留在仓库的急救物资分装随身药，带去下一趟普通出击。再次进医院时，药房仍可搜索，本档已转移的居民不再出现。

**自动化覆盖**停车区定位与回退、多种子通路、救援和图纸先后写入、失败重试、异常退出、重复接纳、满柜与满仓、两件药各扣一次、日结与玩家医疗隔离、自动接诊边界、专业优先序、供电和疗程交接。以 85／67 和历史主备档副本验证升级和重开。执行 Windows Debug 全量及原 **14 项 3 ms** 检查，保留原负载与阈值，并检查中文、英文与三档窗口的新增医疗控件。

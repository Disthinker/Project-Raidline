## 玩家怎么玩

| 环节 | 行为与结果 |
| --- | --- |
| 搜文件 | 新开的「河畔检查站」普通出击固定有一份 1×1「原始情报文件」。它占用一个原有资源路线掉落位，照常放进随身包。成功带回基地可在现有供应与回收入口卖 **35**。文件本身只用于出售。 |
| 找联络点 | 每局从两个候选位置选一个，招牌和近距提示帮助发现，发现后在本局 `M` 地图留标。距点位 **72 世界单位**内且有视线时可交易。本局联络点只收一份文件，报价 **72**。 |
| 买当局情报 | 河畔检查站「交通图」卖 **36**，另外随机供应一份「物资清单」（**48**）或「敌情档案」（**42**）。买下即按原权限在本局生效，已经启用的同类情报不再扣款。 |
| 为下一趟准备 | 「边境交换站」交通图卖 **58**，成功撤离后增加一次可用情报。若卖一份文件后只买这张图，基地增加 **14** 交易结余。可以只卖文件并带回全部 **72**。 |
| 用图撤离 | 从基地「对局出击」页的「情报」选择边境交换站交通图，正式出发时消耗一次。用 `M` 查看当前撤离点位置、开放状态和使用条件，决定走普通出口，或携带燃油等待高危备用出口。原撤离资格、燃油消耗和地图迷雾规则照常。 |

交易期间世界继续运行。受击、走远、失去与联络点的视线，或 **180 世界单位**内出现与玩家有直通视线的活敌时立即关闭交易。确认前重新检查条件。已完成的局内交易继续有效。未确认的报价不会扣钱、扣文件或减库存。出售和购买分别确认，卖一份的钱不足以同时购买两张交通图。

死亡或主动放弃时，局内结余及未带回的跨图情报作废。尚未出售的文件沿用普通战利品和失物规则。异常退出恢复到出击前，已保存的医院救援与内部图知识沿用既有规则。基地出击购买仍使用基地资金。

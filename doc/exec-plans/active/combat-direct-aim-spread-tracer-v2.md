## 1. 玩家结果

- 腰射和按住鼠标右键的当前瞄准状态直接消费鼠标相对位移，不再经过速度/加速度追赶；当前尚无瞄具倍率内容，因此不把右键输入误称为独立的“基础 ADS”功能。相对鼠标捕获和手动压枪保持。
- 高倍率瞄具未来通过显式 `HighMagnificationInertial` 模式使用速度/加速度限制；当前没有合法高倍瞄具消费者，不伪造圆形镜片或附件系统。
- 准星中心与散布继续分离。玩家移动或快速甩动准星时立即出现一段可读扩散，再连续增长；慢速微调影响很小，停止或放慢后按操控速度收缩。
- simulation 同时输出真实几何散布半径和单调可读的准星半径；后者放大低角度状态差异但不改变子弹随机结果。默认准星改为三像素粗、15 像素长的四臂表现，曳光改为五像素分层线体并提高默认长度、亮度与寿命。
- 精准度和稳定性定义的最小/最大散布都随射击距离平滑增长：贴近角色时接近零，静止散布目标在最大有效射程处达到当前状态最大包络；Pistol 有效/最大射程调为 400/620px，Rifle 调为 700/950px，使常见屏幕距离不再过早进入强扩散或超射程；超过有效射程时准星变红并平滑降低伤害质量。
- 逻辑弹道仍是无场景实体的短生命值记录，但弹速改为武器内容定义。弱曳光只显示已经飞过的区段；验收后的默认长度为 30px，可通过 F10 临时调参，并由等宽五像素的亮黄外沿与白亮核心连续线构成。投影以 24Hz 亮度脉冲闪烁，命中时按领域 HitResult 截止，不能穿过障碍物；不绘制发光弹头、光球或余烬。
- 爆头/弱点必须同时满足击发时实际准星覆盖对应目标部位，以及逻辑弹道真实扫掠命中同一目标的同一部位；准星放在目标前方或后方时，即使共线射线穿过头部也只能按普通物理命中处理。
- Raid 内装备根允许在装备槽与合法随身容器之间移动，仍不得离开随身所有权树。Base/Raid 空闲时 Esc 打开冻结世界的统一菜单；库存、情境菜单、设施、医疗轮盘和 F10 面板仍先消费 Esc。菜单提供继续、设置、回主菜单与退出桌面，Raid 回主菜单不结算并由 Continue 恢复出击前存档。

## 2. 状态与边界

- `WeaponAimState` 新增显式 `AimControlMode`。Direct 模式把本帧设备无关位移直接提交到实际准星和控制锚点；HighMagnificationInertial 模式保留现有有界追赶运动。后坐力在两种模式中都同步推移实际准星和锚点，不自动回正。
- `WeaponAimState` 输出玩家控制准星速度、距离包络因子和超有效射程因子。玩家控制速度不包含后坐力，避免一枪同时被计算成甩枪扩散。
- `WeaponFireState` 拥有当前散布。上下文显式传入距离包络、超有效射程、准星控制速度、移动和 ADS；稳定性同时限制最大包络以及射击/甩枪增长，操控速度负责收缩。
- simulation 输出 `WeaponAccuracyProjection`：实际中心、距离、当前/最小/最大散布、真实世界半径、可读准星半径和超有效射程状态。App 只渲染该投影，不重新解释散布、射程或伤害。
- `ShotCommand -> ShotResolution -> LogicalBallisticFlight -> HitResult` 保持权威。`ShotAimIntent` 冻结可选的 Raid 局部 `CombatTargetId`、部位和弱点意图；`HitResolution` 将它与真实碰撞目标/部位交叉验证。`TracerPresentationSegment` 是独立、短时只读表现记录，只能由 `LogicalBallisticAdvance.start/end` 创建，不能参与碰撞、伤害、资产或存档。
- `WeaponUseDefinition::logicalBallisticSpeed` 是不可变内容值；内容加载拒绝非正、非有限弹速。内容版本升级但不改变 Profile schema，并显式接受上一内容版本存档。

## 3. 实施与退出条件

1. 建立 Direct/HighMagnificationInertial 模式并迁移常规瞄准。退出条件：腰射/当前右键瞄准同帧直跟；高倍测试仍受速度与加速度约束；后坐力不自动回正。
2. 重构散布上下文与距离曲线。退出条件：慢移几乎不增长、快移与玩家移动均有明显且有界的投影增长、停止可恢复；近距离包络接近零、最大有效射程处当前目标达到最大包络、超有效射程连续降效并由投影标红。
3. 数据化弹速和短线曳光投影。退出条件：手枪/步枪约 0.1 秒到达各自最大射程；连续扫掠不穿透；同帧命中仍保留短时表现；曳光不超过已飞区段、不存在弹头矩形，并在默认参数下具有可读的多像素亮线体。
4. 增加击发准星意图与真实碰撞的双重验证。退出条件：只有同一 Raid 目标、同一部位的意图和物理落点匹配时才形成爆头/弱点；准星前后共线均不能获得特殊命中。
5. 更新 F10 调参、内容/存档兼容、项目状态和自动化。退出条件：参数有真实消费者，运行时覆盖仍不保存，旧 content-7 存档可加载。
6. 加固正常游玩交互。退出条件：Raid 装备/卸装事务保持资产随身且原子提交；Esc 菜单冻结 Base/Raid、释放 Raid 鼠标捕获，并能安全返回主菜单或桌面。
7. Windows Debug 全目标、全量 CTest、exact-head Windows/Ubuntu CI 后交由用户正常游玩验收。开发代理不自行启动游戏。

## 4. 自动化、风险与回滚

- 自动化覆盖 Direct/高倍模式、相对位移、后坐力手动恢复、帧分割、准星控制速度、距离曲线连续性、移动/甩枪扩散、恢复、确定性 PCG、超射程伤害、击发意图与物理部位双重验证、内容校验、高速扫掠、同帧曳光保留、表现过期和已飞区段限制。
- 风险：甩枪惩罚过强会让命中不可信，因此使用软阈值、连续增长和稳定性缩放；距离曲线使用 smoothstep，避免中距离断崖；高速飞行可能一帧完成，表现缓存与逻辑飞行生命周期分离。
- 远程桌面音频延迟和 P0 小瑕疵不在本切片处理；正式美术、P1 音频、高倍镜内容、穿透和特殊弹继续延期。
- 整个 PR 可回滚到 `origin/main@ba3375e`；Profile schema、资产所有权和 manifest 均不变化。

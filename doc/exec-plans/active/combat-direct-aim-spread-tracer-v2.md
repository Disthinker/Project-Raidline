# Combat：直接瞄准、距离散布与高速曳光 v2 ExecPlan

状态：实施中

基线：`origin/main@ba3375e`（PR #68 已通过 exact-head CI 与用户正常游玩验收并合入）

分支：`codex/combat-direct-aim-spread-tracer-v2`

产品输入：用户于 2026-08-21 确认的常规瞄准直跟、仅高倍镜保留惯性、快速移动准星扩大散布、近距离散布接近零、超过有效射程降效，以及高速短线段曳光合同。外部 GDD 保持只读。

## 1. 玩家结果

- 腰射、机械瞄具和现有基础 ADS 直接消费鼠标相对位移，不再经过速度/加速度追赶；相对鼠标捕获和手动压枪保持。
- 高倍率瞄具未来通过显式 `HighMagnificationInertial` 模式使用速度/加速度限制；当前没有合法高倍瞄具消费者，不伪造圆形镜片或附件系统。
- 准星中心与散布继续分离。快速甩动准星增加瞬态散布，慢速微调影响很小；停止或放慢后按操控速度收缩。
- 精准度和稳定性定义的最小/最大散布都随射击距离平滑增长：贴近角色时接近零，有效射程处达到武器正常包络；超过有效射程时准星变红并平滑降低伤害质量。
- 逻辑弹道仍是无场景实体的短生命值记录，但弹速改为武器内容定义。弱曳光只显示已经飞过的区段，并由两到三条短、亮、有间隔的线组成，不再绘制发光弹头、光球或余烬。

## 2. 状态与边界

- `WeaponAimState` 新增显式 `AimControlMode`。Direct 模式把本帧设备无关位移直接提交到实际准星和控制锚点；HighMagnificationInertial 模式保留现有有界追赶运动。后坐力在两种模式中都同步推移实际准星和锚点，不自动回正。
- `WeaponAimState` 输出玩家控制准星速度、距离包络因子和超有效射程因子。玩家控制速度不包含后坐力，避免一枪同时被计算成甩枪扩散。
- `WeaponFireState` 拥有当前散布。上下文显式传入距离包络、超有效射程、准星控制速度、移动和 ADS；稳定性同时限制最大包络以及射击/甩枪增长，操控速度负责收缩。
- simulation 输出 `WeaponAccuracyProjection`：实际中心、距离、当前/最小/最大散布、世界半径和超有效射程状态。App 只渲染该投影，不重新解释射程或伤害。
- `ShotCommand -> ShotResolution -> LogicalBallisticFlight -> HitResult` 保持权威。`TracerPresentationSegment` 是独立、短时只读表现记录，只能由 `LogicalBallisticAdvance.start/end` 创建，不能参与碰撞、伤害、资产或存档。
- `WeaponUseDefinition::logicalBallisticSpeed` 是不可变内容值；内容加载拒绝非正、非有限弹速。内容版本升级但不改变 Profile schema，并显式接受上一内容版本存档。

## 3. 实施与退出条件

1. 建立 Direct/HighMagnificationInertial 模式并迁移常规瞄准。退出条件：腰射/基础 ADS 同帧直跟；高倍测试仍受速度与加速度约束；后坐力不自动回正。
2. 重构散布上下文与距离曲线。退出条件：慢移几乎不增长、快移有界增长、停止可恢复；近距离包络接近零、有效射程达到正常值、超有效射程连续降效并由投影标红。
3. 数据化弹速和短线曳光投影。退出条件：手枪/步枪约 0.1 秒到达各自最大射程；连续扫掠不穿透；同帧命中仍保留短时表现；曳光不超过已飞区段且不存在弹头矩形。
4. 更新 F10 调参、内容/存档兼容、项目状态和自动化。退出条件：参数有真实消费者，运行时覆盖仍不保存，旧 content-7 存档可加载。
5. Windows Debug 全目标、全量 CTest、exact-head Windows/Ubuntu CI 后交由用户正常游玩验收。开发代理不自行启动游戏。

## 4. 自动化、风险与回滚

- 自动化覆盖 Direct/高倍模式、相对位移、后坐力手动恢复、帧分割、准星控制速度、距离曲线连续性、甩枪扩散、恢复、确定性 PCG、超射程伤害、内容校验、高速扫掠、同帧曳光保留、表现过期和已飞区段限制。
- 风险：甩枪惩罚过强会让命中不可信，因此使用软阈值、连续增长和稳定性缩放；距离曲线使用 smoothstep，避免中距离断崖；高速飞行可能一帧完成，表现缓存与逻辑飞行生命周期分离。
- 远程桌面音频延迟和 P0 小瑕疵不在本切片处理；正式美术、P1 音频、高倍镜内容、穿透和特殊弹继续延期。
- 整个 PR 可回滚到 `origin/main@ba3375e`；Profile schema、资产所有权和 manifest 均不变化。

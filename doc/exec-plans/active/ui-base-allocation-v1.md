## 哪些规则保持

**概览是估算，不代替结算。** 复用现有供给准备查询，只把公共库存和已授权、可访问的个人物品计入单次需求估算。“运营支持”资源与“居民士气”分别显示；日结记录、士气原因、周期事件和生产耗时影响仍可查看，不改分数、数值或世界时间。

**自动供给按物品类型授权。** 点击列表只选择条目，明确按键才保存授权。保存时不扣物、不移动物品；同类型后续获得的物品继续遵循原政策。当前数量为零但仍有授权的条目保留，允许取消。已有其他类别归属时显示清楚，变更合法性仍由原查询决定。

**愿望沿用当前的分组选择能力。** 按物品类型选择当时的合法整件／整堆，选中清单固定具体实例及数量；刷新不能自动加入新获得的同类物品。提交前显示本次消耗、贡献／需求和“超额一并消耗，不返还”。不增加拆堆滑块、自动选物、最省材料算法或新奖励。

**加工一次只处理一个实例。** 同类型存在多堆时明确选择哪一堆，并显示所在位置。沿用现有基地可访问判定和加工查询，保留容量不足时完整拒绝、非空容器不可加工等规则。没有批量加工、部分截取或额外返还。

容量不足等失败结果不携带产出时，可按现有物品价值与所选整堆数量显示候选产出，并明确标为当前不可加工；不能把它显示成已入库或部分加工。执行仍须通过原查询。

愿望关注、周期身份、来源提示、区域相关性、出击提示和地图情报权限保持。切换标签会清除旧按压和临时投入选择；授权与关注仍按原命令保存。分页和选物状态不写入存档。

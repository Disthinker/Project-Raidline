增加一种付费消耗的破片手雷，让玩家能处理密集感染者，同时承担重量、花费、爆炸暴露和自伤风险。沿用现有胸挂与八分区轮盘，不继续UI专项。

## 玩家如何使用

在基地“供应与回收”的购买页取得手雷，放入已装备胸挂的通用空间。进入普通对局后，按住4选择，松开进入瞄准，再新按一次左键投出；右键或Esc取消。

成功投掷才扣一枚。同类多堆在轮盘合并显示总量，仍从选中的合法物品堆扣除；用完一堆后，下一次可选择剩余同类堆。背包或仓库里的手雷不能直接从轮盘使用。

| 项目 | 本次方案 |
| --- | --- |
| 物品 | 基础破片手雷，仅一种；详情使用全名，格内短名“破片”。 |
| 携带 | 1×1格，450克，每堆最多2枚。 |
| 价格 | 买入160，回收40，沿用现有普通货币。 |
| 投掷 | 最远450世界单位，飞行0.5秒；二维直线路径在第一处实体障碍前截停，不穿墙、不反弹。 |
| 引信 | 落地后1.5秒引爆；没有蓄力、提前拉环或拾回。 |
| 同时使用 | 最多一枚在途或待爆；爆炸前不能再次投掷，已落地诱饵的原有发声不会被取消。 |
| 伤害半径 | 160世界单位，按爆点至目标中心的距离计算。 |
| 伤害 | 距离≤60为24；60＜距离≤160时为`ceil(24 - 20 × (距离 - 60) / 100)`；范围外为0。 |
| 防具 | 穿甲3、甲伤6；统一为躯干普通伤害，玩家与敌人使用相同衰减及既有护甲规则。 |
| 爆炸声 | 在爆点产生一次半径1200的听觉刺激，保留同遭遇组传播；不会自动报告玩家坐标。 |

以当前内容举例：普通感染者生命12，核心爆炸可将其击杀；满状态护甲感染者会将24点降至11点，并损失6点护甲耐久，仍能存活。玩家未穿护甲时核心自伤24，低生命时可以致死。它不是无风险的清场道具。

不新增搜获条目、制造配方、免费发放或专门商人。获取闭环为“搜集变现→购买并放入胸挂→局内使用→带回收益及剩余手雷”。

## 进出建筑、撤离与时间

飞行的0.5秒沿用现有投掷动作限制。落地后可移动、冲刺、射击、近战、治疗及使用手电；受伤或受控不会收回已投手雷。待爆期间不能再次开启投掷使用，避免并发投掷。

手雷从投出至引爆的约2秒内，暂不能切换室内外或开始任何撤离。确认投掷会中断本人的撤离读条；拒绝再次撤离不会扣费或消费凭证，已经触发的信号和高危压力继续。门口或出口给出简短中文原因，引爆后立即恢复原有交互。

真正的暂停菜单冻结引信；原本不暂停对局的背包、地图和轮盘继续按原规则计时，不提供暂停引信的漏洞。死亡、超时及合法主动放弃仍按原规则终结并清理手雷，不会被待爆状态锁住，也不退回已经使用的物品。

## 爆炸与活动范围

仅支持现有诱饵可用的普通对局室外及独立室内，包含高危阶段。保持现有排除项：自力寻回、据点恢复、基地地块清剿、外围清剿，以及基地日常、亲自防守和隔离测试场。这里不改变地图解锁、访问权限或各类活动的损失规则。

爆伤只作用于同一空间内的存活战斗敌人和玩家。使用实体墙体索引判断爆点至目标中心是否受阻；有墙则无伤害，不依赖玩家朝向、光照或画面的可见性。首版采用一次径向结算，不模拟实体碎片或越墙高抛。

按既有穿甲、减伤和护甲耐久规则结算后更新生命；不产生爆头、弱点、额外流血、断肢、击退、眩晕或环境破坏。容器、战利品、救援点、建筑和设施不受爆伤。

声音只按爆点距离及既有同组传播政策处理，不新增声音穿墙模拟。尚未发现玩家的合格敌人调查爆点；已追击玩家及高危敌人的既有职责不被覆盖。同组成员可能在半径外响应，不能把1200理解为所有敌人的绝对响应边界。

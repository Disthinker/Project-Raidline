## 范围与实现边界

1. **部署。** 已核对主线的河畔地图有三组出生／撤离配对、三组敌人部署及十个物资格，并有救援和交易。改动落在 assets/content/v1/core.json 与 src/raid_lifecycle.cpp：只为新版新开的普通局生成并冻结两名枪手及其装备身份；数量替换而非额外刷怪。按种子检查三组配对、绕行可达性与物资预算，无法满足约束的布局不能交付。寻回（含原枪追踪）、据点恢复、清理及外围清剿不变。河畔不开放带火力队友。
2. **交火。** 已核对 src/enemy_attack.h 现有感染者攻击是近接类型；src/logical_ballistics.h、src/hit_resolution.h 和 src/raid_fire_support_runtime.cpp 有逻辑弹道、遮挡和友军射击，但不能当作敌方射击已经实现。新增本遭遇的远程行为与玩家／感染者受击判定，沿用现有武器伤害、弹速、护甲和噪音。用稳定身份选择同空间的有效目标，确保同一发只结算一次，已死亡者不能继续行动。不增加可碰撞的子弹实体、离屏模拟或新的队友职业。
3. **资产和兼容。** src/raid_corpse_search.cpp 当前的敌尸流程针对特定守卫；src/profile_state.h、src/weapon_ammo_domain.cpp 和存取、撤离逻辑可承接原件与弹药记录。显式区分枪手与感染者/队友的来源；部署时确定原枪和弹匣，射击和换匣消耗同一份库存，死亡只转移一次。恢复或重放不得重置弹数或复制借装。以当前存档 74／内容 92 为兼容基线，新遭遇数据按需版本化，旧冻结局默认无新遭遇。实测旧主备档副本、写入失败和重复结算。
4. **交付。** 复用既有角色占位、P0 声音、库存及既有提示区，枪手须在开火前可与救援角色区分。不新增地图、美术音效生产、UI 专项或交易货币。批准后从已验收主线独立开发，使用独立候选包和隔离测试档；回退时停用新包。工业郊区候选 d705218dd4c4、固定桌面入口和隔离档均不改，不依赖开放 PR #158、#70。

## 一次联合验收

1. 从普通出击页进入河畔，走外围搜物、办事并撤离；不需要消灭枪手。自动化另遍历多种种子和三组配对。
2. 下一局观察枪手的开火前动作、墙体阻隔、换匣停顿，以及附近感染者对枪声和枪手的反应；不能隔墙命中或知晓目标位置。
3. 让枪手消耗部分弹药后搜取原装备，核对余弹；背包满时不能吞物，整理后可取，反复打开不会再领一次。
4. 成功撤离、重开，再把同一把枪补弹带入下一局。自动化另测打空、同时死亡、主角失败、旧冻结局和异常退出。保留原 14 项 3 ms、基地存档及室内队友性能门槛；新增混合敌群密集遮挡下的射击、索敌与噪音回归。完成后只交一份候选待人工验收。

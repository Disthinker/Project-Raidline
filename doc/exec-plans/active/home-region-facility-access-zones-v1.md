# Home Region 设施入口与作业区 v1 ExecPlan

状态：已完成。PR #136 已通过 Windows Debug 全目标构建、97/97 定向回归、1414/1414 完整 CTest、exact-head Windows/Ubuntu CI 与用户正常游玩验收，并以 merge commit `d1c9b35` 进入 main。

## 玩家结果与依赖

基地设施不再从整块建筑四周任意位置触发功能。每座活动设施拥有明确的南向入口、近距交互区和更大的作业净空区；玩家走到入口附近按 `E` 才能进入功能页。世界和 Home Region 地图显示入口标记，建设模式显示作业区。新设施放置或移动时必须同时保证建筑占地与作业区位于基地板块内、且不被其他建筑、设施入口、地面物或环境阻挡。

本切片依赖 PR #132～#134 的权威设施位置与 Reserve/Installed 生命周期，以及 PR #135 的统一建设目录。入口和作业区由稳定设施几何确定，不新增存档字段；未来正式建筑资源、独立室内入口和 NPC 作业位置可以消费同一投影。

## 领域与运行时合同

- 新增 SDL 无关的 `BaseFacilityAccessGeometry`：入口点、玩家交互区和作业净空区都由设施中心与占地确定。当前固定朝向为南，不增加旋转。
- `BaseFacility` 通过纯投影暴露该几何；位置覆盖、迁徙恢复和首次部署后均得到同一结果。世界 `E` 交互只读取交互区，建设界面的远程管理仍可点击建筑本体。
- 核心设施移动/部署查询同时验证建筑占地与作业净空区。其他活动设施的建筑和作业区都进入放置阻挡投影，因此储物箱、设施或环境物不能堵住入口。
- 作业区本身保持可步行，不成为碰撞墙；它只保护未来玩家/NPC 可达空间。现有建筑碰撞、弹道阻挡、资产所有权和功能页不变。
- 世界视图始终提供轻量入口标记；建设模式额外显示作业区。Home Region 地图绘制入口点，不显示 NPC、室内或虚构生产范围。
- 不改变 schema、content、设施数值、建设队列、Raid 生命周期或基地仓库连接。新增文本提供中英文。

## 验证与人工验收

自动化覆盖几何确定性、有限值、交互区包含入口、作业区包围交互区、建筑与作业区越界/重叠拒绝、失败零修改、Reserve 不投影、迁徙站点位置重建、Raid Gate 出生可交互，以及现有设施移动/安装、碰撞、建设目录和跨进程回归。完成 Windows Debug 全目标、定向测试、完整 CTest 与 exact-head Windows/Ubuntu CI 后交给用户正常游玩验收；Codex 不启动游戏。

人工验收：在基地接近仓库、医疗所、宿舍、厨房/净水和工坊的侧面，确认不会提前出现 `E` 功能提示；移动到标记入口后可正常打开原功能。按 `B` 查看作业区，尝试把设施或储物箱堵在另一个入口，确认虚像为红色；换到净空合法位置后可放置。移动设施、退出重开和迁徙往返后，入口仍跟随设施位置且功能不变。按 `M` 确认设施入口有轻量标记。

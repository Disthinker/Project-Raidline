# 野战照明弹与暗区搜索 v1

**已验收 · RL-RAID-THROWN-ILLUMINATION-v1**

搜回电料，在工坊制作照明弹。下一趟出击时，先把照明弹投到暗处，借短暂光照判断要不要推进、搜刮或绕行。制备、投掷、观察和撤离一次交付，沿用同一个固定入口联合验收。

## 玩家规则

| 环节 | 拟定规则 |
| --- | --- |
| 搜集与制作 | 铜线卷和损坏电子元件各一件，在「工坊与生产」制作两枚照明弹，基础耗时 90 游戏分钟。材料可用现有库存，也可去边境交换站的「制造厂库存点」等原物资点搜集。配方复用已部署工坊、健康指派人员、单生产槽和满仓领取规则。每堆占 1×1 格，最多两枚。照明弹仅由制造提供。 |
| 投掷与落地 | 放入胸挂后，按住 4 打开现有投掷轮盘，选中后松开 4，再用左键投出，右键或 Esc 取消。最大投掷距离 450 世界单位，遇墙按既有投掷规则截停。合法落地后照亮半径 300 世界单位，持续 20 秒有效模拟时间。同一次活动最多一枚在途或点亮，投出成功才扣一枚。 |
| 观察与搜索 | 在已有暗区观察的场景，目标所在位置须同时被照明弹照到、被玩家无遮挡地看见，才可突破暗区距离限制。继续沿用当前观察方向、高倍镜圆形区域和交互距离。照明弹提供的观察距离上限取现有日间基础上限 1000 世界单位，手电、夜视原本能看到的区域照常生效。灯灭即撤销该光源提供的观察和交互资格。 |
| 夜视取舍 | 夜视仪正在输出时，玩家首次直接看到 120 世界单位内的这枚光源，触发约 0.35 秒的轻微局部眩光，每枚最多一次。眩光只改变局部画面表现，设备继续开启，观察权限、物理和伤害判定照常。 |

投掷在普通对局和基地外围使用同一规则。医院片区、边境交换站和基地外围可在已有的暗区观察中借光看清目标。其余普通地图可用照明弹照亮环境，继续沿用各自的观察规则。基地安全核心沿用投掷限制，外围也不能把照明弹投进核心。既有特殊任务入口继续沿用各自的投掷限制。

照明弹没有伤害、燃烧或引敌效果。游戏内用现有提示样式和程序绘制说明选择、占用与熄灭，不增加正式美术、音效、新地图或新面板。

## 实施与存档

- 制造沿用 `base_manufacturing_domain` 和现有工坊面板，新增一种可堆叠投掷物定义和一个配方。价格保持零，排除购买、回收、开局目录和普通掉落。投掷从 `GameSession::throwThrowable` 统一分发，复用现有胸挂实例校验、首墙截停和投掷输入互斥。
- 新增短时光源运行状态，按一次活动和所属空间管理。在活动模拟时间推进时持续计时。换房时立即取消上一空间的观察增益，原光源可继续计时，20 秒内回到原空间仍可见。暂停和已有冻结画面的菜单沿用现行计时规则。
- `GameplayWorld` 与 `BaseWorld` 复用固定光源遮挡和观察查询。落地或几何变化才重算光源覆盖。玩家与光源分别对目标的同一有效位置做遮挡校验。渲染、镜内、敌人、尸体、拾取及可搜索容器读取同一结果。原权限、发现记录和交互距离继续校验，旧观察结果在空间、镜头或光源变化后立即失效。
- 拒绝、取消和非法落点保留库存。重复提交同一事务沿用第一次结果，库存只扣一次。普通撤离、死亡和主动放弃沿用现有携带及结算规则，合法投出的照明弹不退。终局保存失败重试不重复扣除。对局内临时光源不跨局，异常退出恢复出击前存档。基地外围沿用现有短时效果检查点，读档回到同一基地时恢复剩余时间和扣除结果，防止保存重试重复消耗。出击和基地迁徙时清理临时光源。
- 拟升级到内容 81／存档格式 65。旧档可读取，默认没有照明弹和活动光源，旧冻结对局保留原有生成结果。升级前归档实际主档与备档。回退使用上一候选和原兼容存档副本。

## 联合验收

1. **备装。** 在工坊制作两枚，放进胸挂。到「区医院内部」，先关闭手电与夜视，选中照明弹后取消一次，确认库存不变。
2. **照暗区。** 投向昏暗通道，核对只扣一枚。朝向受照区域时能看清落点周围，墙后或高倍镜圆外的目标保持隐藏。到达原交互距离内后可搜取可见物资。
3. **等熄灭。** 换房时确认光效留在原空间，回到原处能核对余时。开启夜视近看只触发一次短暂局部眩光。灯灭后原先靠它看到的目标重新隐藏，成功撤离并重开后光源消失。
4. **核对共用规则。** 在基地外围使用同样操作，确认安全核心仍按原规则拒绝投掷。检查成功保存、保存失败重试和断点恢复时物品数量一致。

自动化覆盖成功／拒绝、空间切换、遮挡两段校验、镜内裁切、敌人及物资权限、旧档迁移和真实存盘重试。保留原 13 项 3ms 检查和既有全量用例，新增手电、夜视和照明弹同时启用的密集场景 3ms 检查。新检查保留 32／100 目标、220 遮挡和 150 个有效样本，另核对落地、熄灭时的缓存重建成本。Windows 全量通过后交付一个候选。

## 玩家会得到什么

新增一个独立的**快速近战槽**和一款**通用工具刀**。空仓、枪械故障或敌人贴身时，玩家可以按 **V** 应急攻击，同时保留当前手持枪械。这是一种有接触风险的自卫手段，不提供无敌、解抓或连续硬直。

刀具从基地**供应与回收**购买，在现有背包页装备。详情页显示耐久及用途；不出现枪械改装、弹匣或装电选项。三个枪械槽及1/2/3切枪保持原样。

首版只做快速挥刀。**长按正式持刀、连招、格挡、徒手和枪托攻击暂不实施**，长期近战持用设定仍保留。

72单位按中心测距，不额外叠加目标半径。已核对普通感染者的接敌距离初值为76单位，因此不把刀具做成明显更长的安全攻击圈；最终仍需正常游玩验收。

## 与现有操作怎样配合

| 当时状态 | 按V后的行为 |
| --- | --- |
| 正常或冲刺 | 结束冲刺并挥刀；恢复期可普通移动，不能冲刺或启动新的战斗、换弹和使用物品动作。 |
| 同帧射击与V | 优先处理近战，不能同时扣弹、出枪声或抽取枪械故障。未装刀只给提示，不误射。 |
| 换弹、逐发压弹或卸弹、切枪中 | 取消未完成动作，再按近战合法性执行；已提交的装弹等阶段保留，不退还、不重复。 |
| 治疗或维修中 | 这次V只中断原动作，不挥刀。必须释放再按；已完成的连续治疗保留，维修未完成则不消耗资源。 |
| 搜尸或其他持续世界交互中 | 作为战斗输入中断该交互，按既有规则保留已完成结果；不会边搜边攻击或自动续搜。 |
| 背包、详情、菜单或失焦 | 不发起近战；不重置鼠标或准星，取消尚未提交的输入。 |
| 受控或死亡 | 服从既有Grab、OffBalance及死亡限制，不提供挥刀解控。 |

恢复期属于玩家当前活动的近战运行状态，不绑定某一把刀。切枪、换刀、开关背包和穿门都不能清零；正式暂停时停止计时，未暂停的库存界面按正常模拟时间推进。恢复期内的战斗输入不缓存；连续按住的射击须释放后重按，不能在恢复结束时突然补射。

保留“敌人推进与合法接触先发生，再处理玩家攻击和死亡清理”的现有时序。同帧挥刀击杀不能撤销已经接受的敌方接触；玩家已死亡或受控时也不能抢先补刀。

刀具接入现有基地枪匠的**全面维护**，需先放进仓库，按当前实现立即恢复至出厂耐久。本片不新增等待队列，也不改变枪械费用或维修行为。

刀具报价拟为：**20 + 向上取整（缺损耐久×0.5）**普通货币。满耐久不接受维护；从零恢复100点收费70，低于另买一把再回收旧刀的90。报价、扣款与恢复原子完成；资金不足或保存失败保持原样。刀具不使用局内维修包，不抽取枪械故障。

刀具贯通购买、装备/卸下、原子交换、负重、回收、成功撤离、死亡/主动退出失物以及NPC与自行寻回。异常退出继续恢复出击前状态，不另给近战保底。所有权始终属于同一个原实例。

拟将保存格式升为**schema54**，内容版本升为**66**，用于新槽位、刀具能力和守城恢复期检查点。沿用资产现有定点耐久字段，刀具使用独立近战能力，不伪装成有弹匣的枪械。

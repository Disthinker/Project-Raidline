## 客户端合同

- 建设镜头只属于 SDL 客户端瞬态，不进入 Profile、HomeRegionLayout、设施事务或存档。
- 打开建设模式时以玩家中心初始化镜头；建设面板与设施放置状态共享同一镜头，购买、移动或取消放置不会无故跳回玩家。
- WASD 在建设面板和放置状态中控制镜头，不控制角色；移动速度按屏幕单位定义，并按当前缩放换算为世界距离，斜向输入归一化。
- 鼠标右键按下后移动至少 4 像素才进入拖拽；拖拽让世界随鼠标移动。低于阈值的右键点击仍用于已放置设施菜单，避免破坏 PR #126 的操作。
- 镜头始终限制在 Home Region 世界边界。改变缩放后立即重新约束，不允许看到地图外空白，也不允许镜头丢失。
- 建设栏区域不启动右键拖拽；开始拖拽或键盘平移时关闭旧设施菜单，选中的设施身份仍可保留。
- 关闭建设模式、打开设施功能页、失去窗口焦点、进入基地危机强制界面、返回主菜单或离开 Base 时销毁镜头瞬态。
- 世界绘制、放置虚像和设施命中共用同一世界—屏幕投影；SDL viewport 原点保持逻辑坐标，不再在调用前重复乘以 RenderScale。0.60/0.75/1.00/1.25/1.50 五档缩放均可准确选择设施。
- 建设界面可选择七类既有固定设施，并通过右键“打开功能页面”进入原有 Storage、Supply、Allocation、Medical、Dormitory、Workshop 或 RaidGate 页面。固定设施不显示移动/回收；可放置储物箱仍保留打开/移动/回收三项，并继续执行既有近距离容器访问规则。

## 验证与人工验收

自动化覆盖镜头激活/销毁、WASD 恒定屏幕速度、斜向归一化、不同缩放投影往返、右键点击/拖拽阈值、四边约束和七类固定设施管理入口；本地化覆盖新的操作提示。完成 Windows Debug 全目标构建、全量 CTest 与 exact-head Windows/Ubuntu CI 后交给用户正常游玩验收，Codex 不启动游戏。

人工验收：进入基地板块按 `B`，分别以 WASD 和按住右键拖动跨越基地范围；在五个滚轮缩放档位下确认移动方向、速度、边界和设施点击位置准确。依次右键固定仓库、供应、分配、医疗、宿舍、工坊和出击口，确认都能打开原有功能页且菜单不提供移动/回收；储物箱继续显示打开/移动/回收。短按右键应打开菜单，轻微抖动不应误触拖拽；明显拖动不应误开菜单。放置或移动设施时平移到另一位置并完成绿/红虚像放置，确认角色仍留在原处；关闭建设模式后镜头恢复玩家跟随。

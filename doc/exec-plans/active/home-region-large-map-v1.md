# Home Region 大地图与基地板块 v1

## 交付目标

把当前 1280×720 单屏 Base 院落迁移为一个可连续步行的 Home Region 室外大地图。安全基地不再等同于整张地图，而是作为一个固定内部结构的 `Base Parcel` 放置在大地图中；周边使用与程序化 Raid 相同的地表、道路、分区、建筑、车辆、集装箱、工程设备和碎屑表达。

本切片只建立空间、表现、摄像机和碰撞闭环。Home Region 仍是安全活动：不生成敌人、Loot、撤离点、高危、Raid 计时或 Settlement，也不让外围探索推进世界时间。

## 产品范围

- Home Region 世界尺寸为 12800×7200，是旧 Base 长宽各 10 倍、面积 100 倍。
- 地图包含一个约 1600×1120 的安全基地板块，以及工业、物流、公路、空地、绿地和路边服务等外围分区。
- Base Parcel 内保留现有仓储、供应、分配、医疗、宿舍、工坊和 Raid Gate 七个设施及全部既有交互。
- 设施内部结构固定；基地板块位置由当前主基地地点稳定决定。相同地点跨进程得到相同布局，迁徙后切换到另一份稳定 Home Region 布局。
- 道路连通基地板块与周边分区。外围提供真实尺度的代码几何建筑、车辆、集装箱、设备和障碍，并支持玩家碰撞与绕行。
- 使用现有批准角色资源；其他内容使用 SDL 图形和中英文文字占位。不生成或接入新美术，不修改 Manifest。

## 架构与不变量

- `HomeRegionLayout` 是纯 Simulation 数据：稳定 seed、世界边界、基地板块、分区、地表段、道路和环境物件。
- `BaseWorld` 唯一拥有 Home Region 的瞬态空间状态和玩家位置；Profile、资产、人口、设施等级与世界时间继续由 `GameSession/ProfileState` 权威持有。
- `BaseWorld` 暴露只读可见区投影，SDL Client 不读取或修改生成器内部状态。
- 环境阻挡使用静态空间索引；移动只查询玩家附近候选，不逐帧扫描整张地图。
- Base 与 Raid 生命周期继续互斥。Home Region 不消费 `RaidGeneratedMapLayout` 的玩法锚点，也不创建 pending Raid。
- 布局由当前 `RegionalBaseSiteDefinitionId` 派生稳定 seed；本切片不增加存档 schema。旧档进入 Base 时按当前主基地地点确定性生成。

## 实施步骤

1. 新增 Home Region 稳定布局与生成测试：分区、基地板块、道路、地表、物件、无重叠、确定性和不同地点差异。
2. 扩展 BaseWorld：大世界尺寸、按地点配置、设施平移、环境空间索引、玩家碰撞、重生点和可见区投影。
3. GameFlow 在新档、读档、回到基地和基地迁徙后的下一次 Base 更新中同步当前主基地地点。
4. SDL Base 渲染加入摄像机、分块可见投影、地表/道路/物件/分区与基地板块标签；所有模态 UI 保持屏幕坐标。
5. 更新自动化、Windows Debug、全量 CTest 和双平台精确提交 CI；最后交由用户正常游玩验收。

## 自动化门禁

- 同一地点多次生成的布局和哈希完全一致；不同基地地点生成不同布局。
- 世界尺寸固定为 12800×7200，基地板块完整位于边界内且占世界面积低于 3%。
- 七个设施全部位于基地板块内，Raid Gate/医疗重生点可行走且可交互。
- 道路至少连接基地板块与每个外围分区；可碰撞物件不与基地板块、道路或彼此重叠。
- 玩家不能穿越设施或环境阻挡，贴墙斜向移动仍能沿自由轴滑动。
- 可见区投影只返回摄像机附近内容，查询成本不随整张地图面积线性增长。
- 新档、旧档、基地迁徙、Raid 成功/失败返回 Base、库存与设施交互全量回归。

## 用户正常游玩验收

1. 新档进入 Base，确认角色出现在可辨认的安全基地板块，七个设施仍可正常使用。
2. 从基地沿道路向外持续步行/奔跑，确认摄像机稳定跟随，周边能看到不同分区、地表、建筑、车辆和环境标签。
3. 尝试穿过设施、厂房、车辆和集装箱，确认被阻挡；沿边缘斜向移动可以滑行。
4. 打开库存、设施页、Esc 菜单和 F10，确认这些 UI 仍固定在屏幕上且功能正常。
5. 从 Raid 成功或失败返回，确认分别出现在 Raid Gate 或医疗点；重启存档后 Home Region 布局不变化。

## 回滚

该切片不迁移持久化数据。若表现或性能不满足门禁，可以整体回滚 Home Region 生成器、BaseWorld 大世界适配和 SDL 渲染；Profile、资产、设施、Raid 和存档 schema 均不需要反向迁移。

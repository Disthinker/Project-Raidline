**RL-UI-BASE-DEPLOYMENT-v1｜用户已批准，实施中。**

下一步整理基地的“对局出击”页面，让玩家出发前看清地图、到达时间、所带情报和装备状态。策划已提出本任务，主控已核查真实调用链；用户已明确批准本方案，现开始实现和本地验证。

## 页面怎么调整

不增加必须逐页完成的向导。玩家仍可直接选择地图并出击。

| 区域 | 内容与操作 |
| --- | --- |
| 左侧地图列表 | 按现有顺序显示已发布地图，短名和选中状态；过长时分页，选中后显示完整名称。 |
| 中间“行动简报” | 地图名称、现有难度／警告、出发与抵达时间、昼夜和路程；往返、失败整备耗时及愿望相关性按需展开。 |

| 右侧准备摘要 | 实际开火能力优先；配装参考、随身弹药、自力寻回目标和到期提醒分别显示，详细内容可展开。 |
| 固定底栏与次要入口 | “出击／再次确认出击”、完整失败原因和关闭；保留“区域路线”“失物记录”入口及原有子页。 |

沿用已验收深色面板、灰绿强调和22／14／12逻辑像素字号层级。常态只显示短标签与关键数字，长说明展开或在所属区域滚动；不把所有警告常驻堆满页面。悬停、按压、选中反馈约120毫秒，动效不改变实际命中区域。兼容1280×720、1600×900、1920×1080与中英文，物品图片沿用现有资源并等比绘制。

## 购买、准备和出击分清楚

**浏览不花钱，也不创建对局。** 切地图、翻页、切标签和查看准备详情，只更新客户端选择。地图列表保持原范围和顺序；不增加免费地图预览、随机入口位置、敌人布置或战利品坐标，不预生成本局地图。

**一次性情报保留原操作语义。** 无库存时，明确按“购买并选用 ¥价格”；有库存时按“选用／取消选用”。只点条目查看不付款，不增加批量购买。购买成功立即按原服务扣款并保存，之后关闭页面不自动退款；选用本身不再次付款。永久内部图另列“购买 ¥价格／已永久掌握”，不与本局选用共用开关，不重复购买。可购买性和价格以原查询为准；不可用项显示原原因，不能把失败结果的0误写成免费。

**配装参考是建议，开火能力是事实。** 沿用`projectAllLoadoutReadiness`与`weaponSupply(false)`，分别显示推荐缺项、当前枪械能否开火及已有随身弹药事实；不把仓库弹药计入随身准备。选择参考方案不会自动换装、购买、装弹或切换地图，缺防具、药品等建议不增加出击门槛。Tab仍使用现有背包，返回后根据真实装备重新查询。

**保留原二次确认。** 普通出击仍一次明确操作；当前不能开火，或存在本次结算后到期的失物，才沿用再次确认。确认区域列出真实原因，不把失物到期统称“配装不安全”。按住按键、键盘重复、失焦后松开或鼠标／Enter同帧碰撞，不能自动完成两次确认或重复出击。不增加第三层确认。

**地图和目标必须对应。** 换地图后，清除旧地图的本次情报、自力寻回目标和风险确认；从失物页回来，地图列表与目标保持一致。修改情报、目标或关键风险后须重新确认；切标签、进入子页会取消旧按压。

**沿用原出击规则。** 准备摘要提供行前信息，最终能否出发仍由原流程检查。价格、路线、情报消耗、保存失败、世界时间、异常退出恢复及失败损失均保持。

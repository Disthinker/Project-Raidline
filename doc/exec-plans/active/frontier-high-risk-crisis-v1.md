# Frontier Exchange 高危危机生态 v1

## 产品结果与范围

本切片让 `Frontier Exchange` 的持续高危不再只是统一计时、固定增援和一个固定高级资源区。每次 Deploy 在现有随机布局中确定性冻结一种地图危机、一个受影响分区/资源点和一组压力来源；进入高危后，玩家会面对不同的增援节奏、方向和主题高级物资机会。敌情资料可以在常规阶段预告危机，未携带敌情时则在高危真正开始后揭示。

基线为 `origin/main@6ab1724`，分支为 `codex/frontier-high-risk-crisis-v1`。继续使用现有敌人、Loot、代码几何和双语文字；不生成或接入新美术，不修改 Manifest。

明确排除：实时尸潮、阶段终局倒计时、动态封死道路、运行时生成新建筑/集装箱、停电、火灾、新敌人类型、新撤离合同、程序化室内和 AI 小队。

## 领域合同与兼容

- `HighRiskCrisisDefinition` 数据化危机 ID、双语可投影文本、允许分区、波次节奏、活动敌人上限、压力来源数量和高级 Loot 表。Frontier 首批提供道路汇流、厂区破口和货运争夺三种危机。
- 新 Deploy 使用独立稳定随机流选择危机，并从冻结资源点中选择合法目标。最终危机快照保存目标分区、聚焦区域、精确压力来源、波次参数和高级 Loot 表；高危切换只消费快照，不重抽内容。
- 两件既有高危 Loot 改为在危机目标资源点内生成，物品定义来自该危机的主题表。常规阶段仍锁定，进入高危才开放；不增加无限刷新。
- 新规则版本为 `procedural-frontier-high-risk-crisis-28`，content v51，schema v38。schema v37/content v50 与旧 rules 27 pending Raid 显式兼容，继续使用旧固定高危参数和高级资源锚点。
- 危机详情只有在敌情资料已冻结或高危已开始时投影；资源聚焦区域继续遵守现有物资情报/探索/开发迷雾规则。

## 验证、交付与回滚

- 自动化覆盖内容校验、同 seed 同危机、跨 seed 多样性、合法分区/资源点、压力来源唯一且来自冻结锚点、主题高级 Loot、旧 rules 27 读取、新 rules 28 篡改拒绝和 schema v38 往返。
- Gameplay 集成覆盖敌情预告、无情报隐藏、高危后揭示、实际波次参数与高级 Loot 开放。
- F10 运行时开发面板显示本局冻结危机、目标资源点和压力参数，并提供只作用于本次运行的强制 HUD 揭示与立即进入高危按钮；调试操作不修改 Profile、情报或存档。

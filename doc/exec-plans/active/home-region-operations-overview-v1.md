## 投影与客户端合同

- SDL-free `BaseOperationsOverviewProjection` 只读取现有 Profile 和内容定义，按“待领取、升级、治疗、制造、缺员”的稳定优先级输出类型化条目。
- 条目包含设施类型、剩余分钟和暂停标记；储备设施的既有任务继续显示但明确标为暂停。空闲且人员完整时显示“无进行中事项”。
- App 只把类型化条目映射为双语文本和屏幕按钮；点击后使用 `BaseWorld::facilities()` 的权威位置重置瞬态建设镜头，不写 Profile、不推进世界时间、不执行任务。
- 总览区域独立参与左键命中和右键拖拽仲裁，不允许点击 UI 时误拖动地图或选中其后的世界设施。
- 不增加通知队列、第二套设施状态、第二任务槽、离线推进或存档字段。

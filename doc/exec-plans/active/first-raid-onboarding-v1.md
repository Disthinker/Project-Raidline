## 权威边界与迁移

- 当前可击发状态只读现有供弹/故障领域查询；余弹、胸挂可 R 换弹和背包备用分别显示。医疗/护甲是推荐而非 Deploy 门禁。
- UI 只画投影和发送现有命令，不根据名称/颜色推断兼容。纯投影不分配 ID、不推进 revision、随机流或世界时间。
- 提示优先复用 v45 已保存的可关闭位、真实 lastRaidResult 与流程状态。旧档默认关闭；新档未建家不提前播首局提示；真实结算后回营或用户关闭结束指导。若现有字段足以表达，不升级 schema/content/rules。
- Raid 提示读取当前冻结 rules 和剩余时间、真实撤离资格；不硬编码 180 秒、不泄露未知坐标/敌人/Loot。归零持续高危，不判失败。
- 成功说明所有合法随身物保留精确位置，包含原携带物，不等同净新增Loot；失败只指向已提交失物与既有恢复渠道，不生成丢失物列表。重复结算、保存失败、重开不产生新奖励或错误结束。

## 玩家会遇到什么

| 环节 | 本次方案 |
| --- | --- |
| 取得资料 | 在边境交换站的交易所办公室设置一处独立资料点。持续按 F **2 秒**完成调查。 |
| 本局结果 | 资料只记为本局已取得，不占背包、不生成物品。首次调查当局仍须使用原有出口。 |
| 登记许可 | 只有成功撤离，才随同一次结算登记边境交换站永久通行许可。 |
| 后续使用 | 下次出击时冻结许可资格。进入高危后，在独立凭证出口连续等待 **6 秒**撤离。 |
| 使用成本 | 不限重、不收费、不消耗许可，也不主动触发信号噪声；现场敌人继续正常行动。 |
| 中断与失败 | 离开出口或受到控制会清空读条。未成功带回资料不解锁；已登记许可不因后续死亡而丢失。 |

## 必须保持的规则

**三个事实分别拥有。** Profile 保存类型化、稳定 ID 的永久权限；本局快照记录正确地图、空间和资料点的调查结果；Deploy 冻结出发时权限以及调查点、出口和时长。调查进度只属于本局世界，不进入长期档案。

**调查不能由界面授予。** 仅活动 Raid、正确办公室空间、合法距离、可观察且无遮挡、存活未受控时接受。距离采用现有控制点类交互规则；持键2秒，离开、松键、菜单或受控中断清零。资料点避开原箱子、Loot和门口，同一 F 只处理一个交互；门户和已选场景交互的既有优先级保留。进办公室、开箱或买内部图都不等于取得资料。

**许可只在成功结算登记。** 同一候选中确认成功与资料事实，登记权限，再形成结果摘要和保存。保存成功后才替换正式 Profile；失败保留原状态重试，重复结算不重复登记。已有许可重复调查不发奖励。不借用幸存者救援的即时持久化例外，不把调查事实写进干净恢复档案。

**出口独立。** 正规阶段不可使用；高危且出发时有许可才开放。首次调查本局不能提前使用。出口不与出生、其他出口、控制点、救援及障碍重叠；具体坐标随本局生成时一次冻结，不在进入高危或打开地图时重抽。正常、免费信号和22kg轻装撤离的既有规则全部保留。无信号刺激不等于敌人停止追击。

**权限与可见性分开。** 没有交通情报时仍需按原规则探索出口；拥有许可不会自动显示未知坐标。交通情报只提供出口信息，不授予通行许可。资料点仅在当前空间可观察范围内呈现，不提供全图目标箭头或完整办公室地图。

**保持已验收内容。** 保留窗口准星、菜单、独立仓库页与同页配装、搜尸、室内外扇形视野、手电电池、快速近战、诱饵、地图权限、携物结算与原失败损失政策。无新物品实例、钱、经验或装备奖励。

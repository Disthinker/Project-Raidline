# Home Region 地面资产 v1 ExecPlan

状态：已通过自动化、exact-head Windows/Ubuntu CI 与用户正常游玩验收，并由 PR #124 以 merge commit `17a3514` 进入 main。后续近距容器打开与内容整理由 `home-region-world-containers-v1.md` 承接。

## 目标与基线

依赖基线为用户已验收并合入的 PR #123，`origin/main@9106126`。开发分支为 `codex/home-region-ground-assets-v1`。

本切片让 Home Region 从仅承载设施入口的空间变成可持久承载玩家资产的场景：玩家可以在基地个人页把完整物品或部分堆叠拖到地面，关闭界面后在世界中看见它，离开、返回或跨进程重开后仍留在原基地位置，并可在近距离重新拾取。基地地面、Stash、装备、容器、安装点、Raid 地面和服务流程继续共享唯一 `AssetRegistry` 所有权。

代码审计确认 Base 已经具备即时压弹、卸弹、装匣并上膛、医疗、维修及共享库存拖拽。它们是本切片的已接受基线，不重复重写；旧活动计划中把这些列为延期的记录同步修正。

## 领域合同

- 新增 `BaseGroundAssetLocation`，保存稳定 `RegionalBaseSiteDefinitionId` 与世界坐标。它只表示权威资产根的位置，不把物品复制到 `BaseWorld`。
- 丢弃只允许当前玩家携带树中的资产，或玩家位于基地范围、仓库连接有效时的 Stash 根资产。已安装弹匣必须先卸下；服务中、失物、寻回中、Raid 地面和 pending Raid 资产不能丢弃。
- 完整容器可作为一个所有权根放到地面，内部物品继续跟随容器分区；部分数量只适用于可堆叠物品，并产生单调新实例 ID。
- 拾取只接受当前主基地站点、玩家交互距离内的地面根。优先完整合并到随身同定义堆叠，其次放入胸挂或背包合法空位，最后在兼容且空置的装备槽快速装备；空间不足时零修改。
- 查询与提交使用同一规则。拒绝、过期 revision、重复事务或保存失败均保持 Profile 指纹、货币和 ID 高水位不变。
- `GameFlow` 组合 BaseWorld 的当前站点、玩家位置、仓库访问权和 GameSession 命令；App 只发送拖放/拾取意图并消费只读投影。

## 持久化与兼容

- Save schema 从 v38 升至 v39，content version 不变。
- v39 保存 `base_ground` 的站点 ID 与坐标；v1-v38 原样迁移，不生成地面资产。
- 加载拒绝未知/非基地站点、非有限坐标、非当前已解锁基地站点以及破坏资产树所有权的数据。
- 基地迁徙不会移动旧基地地面物品；物品继续属于原站点，重新迁回后仍可见和拾取。

## 客户端结果

- Base 个人页增加明确的 `拖到基地地面 / DROP TO BASE GROUND` 目标区；Raid 个人页不显示该目标。
- 合法地面丢弃使用蓝色特殊动作反馈，非法目标显示红色并保持原物不动。
- Home Region 只绘制当前站点地面资产，使用已批准现有 Sprite 或代码色块/文字 fallback，并显示数量。
- 玩家靠近地面资产时显示拾取提示；`E` 优先拾取近处物品，没有近处物品时才触发设施交互。
- 战术地图显示当前站点地面资产的小型标记，不显示其他基地的资产。

## 自动化、验收与回滚

自动化覆盖完整/部分丢弃、仓库距离门禁、容器子树、拾取合并/入包/快速装备、容量不足、错误站点、交互距离、事务幂等、失败零修改、schema v39 往返、v38 兼容和篡改位置拒绝。完成 Windows Debug 增量构建、定向测试、全量 CTest 和精确提交 Windows/Ubuntu CI。

当前本地证据：Visual Studio Developer Shell 下 Windows Debug 完整构建通过；`BaseGroundDomainTest` 5/5 通过；存档 v39 定向回归通过；全量 CTest 1354/1354 通过。精确提交 Windows/Ubuntu CI 与用户正常游玩验收仍作为合并门禁，不把自动化等同于实际游玩验收。

用户正常游玩验收：在基地范围内从仓库与随身容器各拖一个物品到地面；走出基地确认仓库物品不能远程丢弃；关闭个人页后看见地面物品并拾回；重启确认未拾取物品仍在原位置；迁徙相关只验证旧站点资产不被复制或转移。Codex 不自行启动游戏。

回滚使用普通 revert；v39 已写入的 `base_ground` 数据在回滚前必须先通过迁移工具收回 Stash，不能通过降低 schema 或删除位置分支静默吞失。

## 明确排除

本轮不做 Raid 任意地面丢弃、物品物理模拟、堆叠模型、容器世界开箱、盗窃/NPC 拾取、基地防守损坏地面资产、载具货舱、正式美术或 Manifest 修改。

## 玩家结果和范围上限

玩家为个人医疗、居民治疗、卫生或愿望需求选择医院区域，通过随机外围抵达固定医院，
在药品、其他物资、战斗和撤离风险之间取舍，带回后实际改善下一局或基地状态。

- 一个新增可选择 Raid 主题；一份固定单层医院内部，合法室外入口随机放置。
- 外围包括医院园区、停车/救护通道、少量沿街服务区、居住外围与荒废绿地；道路连接全部
  关键 Socket。初始规模建议 12800×7200，实施前以现有生成约束和密度检查校准，不能用
  把 Frontier 改名的方式交付。地图尺寸是调参，不承诺一轮新增多种城市生成体系。
- 医院内包含接诊候诊、病房、药房/医疗库、急救区域、后勤走廊和出口；固定布局建议
  不超过 2560×1440，保持宽通道与明确房间标签，不做多层/门锁/电力/程序化室内。
- 优先使用现有医疗品、卫生用品、食物与杂物；本片默认不新增物品，更不新增伤势机制。
- 普通医疗补给、医院功能区资源、高危医疗目标使用各自 Loot 表；高价值不能保证每局必得，
  也不以全局售价倍率冒充风险收益。保持正常非医疗物资和基础补给地图的价值。
- 交通/物资/固定内部图复用当前情报权限，不显示实际 Loot 或无权获知的敌人。
- 复用当前有限遭遇、高危、普通/条件/信号撤离、世界时间、失物/两条寻回及结算。
- 仅文字、程序几何与已批准 fallback；不接入正式资源、动画、音频或 Manifest。

明确排除：NPC 队友/守军、新敌种/Boss、导航功能/箭头/追踪线、敌人导航架构扩建、
第三地图主题、更多守城/工事、复杂医疗、组件改枪、剧情任务和新经济体系。

## 自动化门槛

- 至少 128 固定 seed：医院恰好一个且合法可达；出生、出口/撤离、资源、敌人和室内入口
  不非法重叠；坏 seed 回退确定；不同 seed 有路线与资源分布差异，不只有颜色变化。
- 医院室内在不同 seed 下相同；室内外 Enemy/弹道/库存状态隔离，往返不刷 Loot/复活。
- 所有新 ID 引用、来源/消费者完整；标准补给与高级医疗来源覆盖、数量有界、无稳定套利。
- 新旧布局/规则/内容往返；旧 pending 不重抽；未知 ID/篡改哈希拒绝；失败/寻回/重复
  Settlement 不复制或吞物；异常退出保持现有回滚合同。
- 交通/资源/内部图权限分别测试；未授权精确信息不泄露；不新增导航 UI。
- 保留全部 1795 项基线及性能阈值；新主题验证生成时间、快照体积、区块查询和100敌人
  压力，不把仅无 SDL 的性能数字当作发行硬件/真实帧率保证。
- Windows Debug 完整构建、全 CTest、Windows/Ubuntu exact-head CI；代理不启动游戏。

## 一次正常游玩验收

1. 从基地按医疗/卫生缺口选择医院区域；看懂往返耗时/风险，分别尝试有无情报出击。
2. 至少三次不同 seed，沿不同道路搜索医院，进入内部；内部结构相同，外部相对位置变化。
3. 搜索普通与高风险医疗区，战斗、取舍容量，普通或特殊撤离；不能靠出生点无风险稳定刷高级药。
4. 带回物资仍在携带处，可自行使用或转入仓库按现有规则供给；基地付费医疗不吞个人药品。
5. 正常经历失败并通过 NPC 或自力寻回，重开游戏；失物/消耗不复制，其他旧地图仍可游玩。

## 风险、回滚与下一门禁

- 最大风险是地图生成器内的工业假设和旧快照兼容；以不变黄金 seed 测试约束迁移，发现
  必须改核心空间/保存架构时先缩小主题填充方案，不借机全局重构。
- 医疗产出过量可能抹平基地压力；数量/概率/路程按实际试玩校准，不新增硬门槛或永久损失。
- 占位医院只证明空间与玩法，不是正式美术、真实型号或叙事设定批准。
- 实现内部提交可逆序普通 revert；若已产生新主题存档，不降级/覆盖用户档，保留必要 ID
  与读取合同，优先关闭新 Deploy 入口而非删除定义。无强推或退款刷取路径。

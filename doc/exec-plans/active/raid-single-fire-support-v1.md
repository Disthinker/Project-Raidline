# 单名火力队友出击 v1

**候选已通过用户游玩验收 · RL-RAID-SINGLE-FIRE-SUPPORT-v1**

从边境交换站接纳战斗居民，在基地为他借装，到灰线仓库指挥掩护，再回营核对人员和装备。单独出击节省准备弹，带队提供火力并承担人员和借装损失。本阶段交付一个候选，集中验收整条流程。

## 玩家会遇到什么

| 环节 | 拟定规则 |
| --- | --- |
| 招募与选人 | 复用「边境交换站」现有救援，接纳 1 名健康战斗专业居民。「灰线仓库」普通出击可选择带 **1 名健康且空闲的战斗居民**。已派驻、施工或受伤者按共享劳动力规则参与资格判断。出击页同时保留单人方案。 |
| 借装与准备弹 | 从仓库选一把可用、空膛、未装匣的 **制式5.45步枪**。出击提交时一次扣 **30 发标准 5.45 弹**。可额外借出 **1 个兼容弹匣**，内装最多 **30 发标准弹**，留给玩家取用。准备弹与借出的弹匣分开列明。局内队友按冻结的制式枪参数射击，装备和配件沿用原实例。本阶段用准备弹和伤亡作为主要成本，队友不逐发扣弹或磨损借枪。 |
| 指挥与取用 | 初始「跟随＋停火」。**F2** 打开现有操作样式的短面板，分别选择「跟随／原地掩护」和「停火／自由射击」。队友只向同空间、确实可见、火线上没有主角的目标开火。建议有效射程 **320 世界单位**、两枪至少间隔 **1.2 秒**。枪声会引敌，感染者可以攻击队友，初始生命建议 **100**。靠近后用 **F** 取出原备用弹匣，背包装不下时保留在队友身上。该位置只提供取用。 |
| 成功撤离 | 仍按主角的现有撤离规则。存活队友归队，原枪和未取补给回仓，准备弹已消耗。已取补给随主角实际携带的位置结算。队友可在户外掩护，玩家进室内时留在室外。队友距撤离点的距离不增加撤离条件。 |
| 阵亡、失败与异常退出 | 队友生命归零即阵亡。玩家可搜其尸体取回原装备。留在队友尸体内的借装在现有「失物记录」中单列为「队友阵亡失物」，沿用后续 3 次结算仍可找回、第四次到期的规则。成功撤离仍显示成功。主角死亡或主动放弃时，**仍存活的队友自行撤回，带回未领取的借装**。主角身上的已领取补给与其余物品按原失败规则结算。异常关闭则恢复出击前的装备、弹药和人员，保留原有允许独立提交的救援等事实。 |
| 补员与下一趟 | 队友阵亡的正式结算减少 1 名战斗居民。若因此归零，**72 游戏小时**后可在边境交换站接纳 1 名替补。旧的一次性救援独立保留。只有一次有效的归零阵亡能开启一份替补机会，受实际人口和已提交记录约束。 |

界面使用对局出击的现有准备栏和对局状态区。借装、准备弹和可取补给放在相邻行，异常按原反馈显示。局内只保留队友状态和命令反馈，沿用准星和菜单的窗口锚定。使用现有占位与枪声。首版场景是「灰线仓库」户外普通局，对应区域地图上的「灰线西区」。其余职业、多人小队、室内跟随和基地守军留待各自阶段。

## 实施安排

1. **完成基地装配与出击事务。** 在 `base_workforce_domain` 使用现有各专业可用人数和扣除施工的总空闲人数。地图和枪械以稳定定义 ID 判定，分别为 `map.v0.test`、`item.weapon.rifle_5_45_service`。在 `raid_lifecycle` 复核真实枪、弹匣、标准准备弹、人口和活动资格。在一次原子提交内扣准备弹、冻结出战人员及其借装原仓位，赋予队友借装独占位置。落盘失败保持全部原状。准备弹从仓库的真实散弹扣除，补给通过平时装填准备，出击时保留实装弹序。
2. **接入一个可攻击、可受击的临时队友。** 在 `gameplay_world` 拟新增同空间的队友运行状态。复用 `raid_space_navigation_field`、`raid_space_blocker_index` 和活动碰撞，低频转向、复用寻路，掩护命令最多维持一个站位。站位碰撞不把既有门口变成新阻挡。感染者选择合法目标，并在起手时锁定目标身份。接触使用 `resolveEnemyAttackContact` 同一合法性规则，分别扣主角或队友生命，队友受击和声音不改变主角的枪、准星或受伤提示。
3. **复用弹道、取用和尸体交互。** 队友射击走既有逻辑弹道与命中结算，由独立射手事实触发枪声、声响和击杀。火线检查复用真实遮挡，队友枪声从实际位置发出。队友提供掩护火力，地图和观察信息范围按主角原规则。通过现有交互保留唯一实例，使用容量检查完成取用。阵亡才创建队友尸体入口，尸体只包含此前实际借出的原资产。复用尸体搜索的展示及访问检查，队友归属与敌人随机掉落各自校验。
4. **把回营、失物和下次补员打通。** `raid_lifecycle` 和 `profile_state` 附加队友结算，玩家既有撤离结果与队友状态可同时显示。存活返还使用出击时冻结并保留的仓位。仅仍属于队友尸体的借装以独立原因及稳定记录键进入现有寻回入口，能和同局主角失物并存。恢复沿用现有付费/普通寻回规则，原枪特别追踪仍按既有资格。阵亡、装备归还、准备弹扣除和替补资格分别防止重复提交。替补用明确的归零记录与到期时间，复用边境交换站的正常可达位置。奖励成功保存后按现有救援规则提交。
5. **兼容存档并验证。** 夜间接应功能合入后从主线实施，预计在格式 73、内容 91 上新增队友快照、借装归属和替补事实，拟为 **74／92**，开工时按实际主线校准。旧档默认单人，旧冻结对局及其失物按原规则回读。兼容已验收的夜间接应、工坊带教、骨折和医院救援。用副本核对原字节保存与迁移回读，候选保留固定桌面入口和上一版可运行程序。回退用匹配版本的存档副本。

## 一次联合验收

1. 用固定入口的隔离档，在边境交换站完成现有救援。回营选火力队友，借出一把可辨认的原枪和一个已装好补给的弹匣。核对参与人手、准备弹和补给数量。
2. 进「灰线仓库」后分别用 F2 体验停火、自由射击和原地掩护。确认队友能跟上，掩体挡住火线。靠近按 F 取原弹匣。
3. 共同撤离并重开，核对原枪归还、已取弹匣的实例和库存。用隔离档的另一局验证阵亡失物，确认主角撤离成功时仍能搜索和寻回队友的原装备。

自动化覆盖资格与空膛检查、满包无损、保存失败、同空间视线与友军挡线、跟随和不卡撤离、主角失败时存活队友归队、同时失物、异常恢复、重复提交和替补时钟。保留全部 **14 项 3 ms** 及原负载，另测 32／100 敌和密集遮挡下启用队友的寻路、命中与观察。检查新增提示在三档窗口和中英文下的可读性。

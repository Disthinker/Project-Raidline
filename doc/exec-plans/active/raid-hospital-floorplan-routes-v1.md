# 区医院图纸搜获与粉笔路线 v1

**已验收 · RL-RAID-HOSPITAL-FLOORPLAN-ROUTES-v1**

第一次进医院找图纸，拾起后马上能看医院内部结构。撤离可带回实体图纸。下一趟可以用战术地图画自己的搜索和撤离路线，接着用照明弹判断眼前的暗区是否能安全通过。

## 玩家规则

| 环节 | 拟定规则 |
| --- | --- |
| 搜到图纸 | 在新开的「医院片区」普通对局中，「区医院内部」的「接诊 / 候诊区」固定出现一份 1×1 图纸。接诊点原有的随机医疗品槽改放图纸，其余地点沿用原掉落。按现有视野、距离和背包容量规则拾取。 |
| 当场记下布局 | 首次成功拾取即永久解锁「区医院内部」的固定结构。留在医院时按 M 可立即查看。满包或保存失败时，图纸留在地面，知识仍未解锁。已买过内部图的玩家可以按普通战利品拾取实体图纸。 |
| 带回基地 | 正常撤离后，可把图纸入库或回收，拟定基础回收价 35。死亡、主动放弃或异常退出时，实体走既有携带和恢复规则，已保存的知识保留。下一局仍要寻找医院入口，进入建筑后才显示其固定布局。 |
| 画本局路线 | 在「医院片区」普通对局打开 M，室外地图和已掌握的医院内部图支持按住右键拖画。室内外各自保留笔画，共用 4,000 世界单位的长度上限。可撤销本区最后一笔或清除本区路线，释放相应长度。迷雾上可以留下粉笔线，地图仍只显示原权限允许的信息。路线随本局结束清空。 |

交通图和物资清单沿用现有购买与使用规则。粉笔线不参与移动、寻路或撤离资格。已发布的照明、手电和夜视仍由现场观察规则决定。使用现有文本、颜色和线段绘制，沿用固定测试入口。

## 实施与存档

1. **冻结本局投放。** 在 `core.json` 增加实体图纸定义，拟复用 `hospital_reception` 槽。生成时沿用现有固定夜视掉落保留随机抽样的做法，保留其他室内掉落和夜视仪的确定性。旧存档中的冻结对局维持已经生成的内容。基地现有情报购买与回收各自处理知识和实体。
2. **先存知识，再发布拾取。** 在现有拾取的地图、距离、视野、容量和来源核验后，准备局内拾取结果。复用 `GameSession` 现有异步写入和居民营救的双候选流程。出击前恢复档只增加对应的永久知识，保留此前已存的持久事实。写入成功后，一次发布实体入包、永久档案和本局对应房间的 `layoutKnown`，同步更新世界里的室内图投影。失败沿用现有保存重试，玩家看不到提前入包或解锁，重复请求最多提交一次。
3. **复用 M 地图。** 用现有逻辑视口与地图矩形完成坐标转换、绘制和命中。地图底部沿同一对齐线摆放短操作提示、撤销和清除，长度耗尽时简短提示。笔画按对局和空间隔离，用长度和有限采样点限制绘制成本。关图、切空间和失焦时结束当前笔画，右键松开后才恢复原瞄准输入。地图闭合时沿用原战斗显示。
4. **兼容验收版本。** 主线 `302901a` 已通过双平台 CI。图纸与粉笔玩法独立于卸包分支。交付新候选前核对能读写已验收的负重存档（内容 82／格式 66），并用同一候选回归卸包取回；具体集成路径在实施时按授权确定。优先复用既有永久档案、冻结掉落和已知布局字段，按实际实施基线分配内容版本。笔画只保存在本局内存。升级前保留主档、备档和原候选入口。

## 联合验收

1. 用 **Project Raidline Debug** 进「医院片区」。到「区医院内部」的「接诊 / 候诊区」拾取图纸，在楼内按 M，确认能看到固定结构。
2. 撤离后在基地回收实体图纸，重开后再出击。确认重新进入医院仍能查看内部图，室外入口沿用本局发现规则。
3. 在室外地图画一笔穿过迷雾的线，确认只出现线条。用撤销和清除检查编辑，再去已知室内图确认两处笔画独立。结束对局后确认路线清空。

自动化覆盖旧档、旧冻结对局、首次拾取、重复图纸、满包、保存失败重试、死亡和异常恢复、室内外权限、右键与开镜互斥、三种窗口尺寸和长度上限。全量 Windows Debug 保留 **14 项 3 ms** 检查的负载和门槛。已购买内部图的玩家可以直接验收实体拾取和画线，首次解锁由独立测试覆盖。

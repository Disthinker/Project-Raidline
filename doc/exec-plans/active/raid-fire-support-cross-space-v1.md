# 火力队友跨地图与室内协同 v1

**已通过用户联合验收。** 把一名火力队友从灰线仓库户外扩展到医院片区和边境交换站的普通出击。玩家在门口决定独自进去安静搜索，还是带队友进去掩护。

## 一次交付哪些玩法

- 出击时仍可单走。带队沿用健康空闲战斗居民、制式 5.45 步枪、30 发普通准备弹及一只备用弹匣。灰线仓库原有出击保留，寻回和清剿不开放带队。
- 沿用 F2 的移动和开火命令。跟随时，队友到同一入口 96 世界单位内且两侧都有合法落脚点才一起过门；掩护、距离过远或入口被堵时，玩家仍可自己过门，队友留在原处。返回同一空间可汇合。室内互相可见且靠近时才可取备用弹匣一次，不可跨墙取用。
- 保持同一名队友的生命、命令、射击冷却、借装和已领状态。只模拟玩家当前空间：分开时没有隔楼枪声、敌情或后台交战。保留 100 生命、320 射程及 1.2 秒射击间隔；不增加友伤、队员职业、多人编队、消耗品或新按键。
- 撤离条件仍只看主角，队友距离不拦撤离。主角失败而队友存活时，队友带回未领取借装；已领取物品随主角原规则结算。队友阵亡，遗体定位到实际建筑、实际位置；可现场搜取，未带回的原装备按既有失物规则进入寻回。不得在户外另造一份。沿用现有 72 小时替补规则。

## 实施与验证

1. 扩展普通出击资格。已查主线 raid_fire_support_domain.h/.cpp 的地图限制、借装与尸体校验；沿用原准备成本、资产实例和结算所有权。核对地图权限、单走、特殊活动和旧档；仅在确有新持久字段时做兼容迁移。
2. 接通进出建筑。已查 gameplay_world.cpp 的户外专用更新、可见性、互动和死亡位置，以及 raid_fire_support_runtime.h/.cpp 的生命、命令与攻击状态。让角色属于明确空间；换空间时清理过期目标与飞行状态，用该空间的既有遮挡和移动查询，禁止跨门攻击、复制或重置冷却。
3. 接通交互和归队。已查 app_ui_raid_fire_support.cpp、game_session.cpp、raid_corpse_search.cpp。沿用已有 F2 和搜取界面，只修正地图资格和异空间提示。对接失物/寻回时验证原件唯一、保存失败回滚和重复结算，旧冻结局不变。
4. 正常游玩验收：① 医院让队友留门外，独自进出，原地汇合；② 一起进屋，切换停火和掩护，绕墙交战并领一次备用弹匣；③ 撤离并重开核对装备，下次去边境交换站分别进办公室和货运装卸间；④ 用隔离档在室内阵亡点搜回队友原装备。自动化另测不同门、无落点、同坐标不同空间、存档失败、死亡/主动退出/异常退出及重复结算。
5. 交付前运行专项与 Windows Debug 全量，保持原 14 项 3 ms 和基地存档等现有门槛，加入室内密集遮挡与过门负载。未获授权前不提交或推送；进入 PR 阶段再验证双平台 CI。

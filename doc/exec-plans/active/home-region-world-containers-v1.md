# Home Region 世界容器交互 v1 ExecPlan

## 目标与基线

依赖基线为用户已验收并合入的 PR #124，`origin/main@17a3514`。开发分支为 `codex/home-region-world-containers-v1`。

本切片让放置在 Home Region 地面的背包、胸挂等真实容器成为可近距离打开的空间资产。玩家靠近后按 `E` 打开统一个人页：左侧仍是角色、装备与随身容器，右侧显示该地面容器的真实分区；双方使用已有拖拽、旋转、交换、堆叠和数量锁定交互。容器根及内容继续由唯一 `AssetRegistry` 持有，不创建第二份世界库存。

## 领域与访问合同

- 只有位于当前主基地站点、在交互距离内且内容定义实际声明容器分区的 `BaseGroundAssetLocation` 根才能打开。
- 容器会话中的普通库存命令只允许随身资产与当前地面容器直接分区内资产作为来源；目标只允许随身容器、当前地面容器分区或合法装备槽。Stash、BaseIntake、其他基地和其他地面容器均不可借此远程访问。
- 查询和提交使用相同访问作用域；过期 revision、越界、错误站点、错误参与者、容量不足、非法嵌套、保存失败和重复事务保持原有零修改及幂等合同。
- 当前地面容器根可通过界面中的正常“拾取容器”操作调用既有 BaseGround 拾取事务；非空容器整体移动时子资产仍跟随根，空间或装备槽不足则不改变状态。
- 本切片不增加存档字段或 schema；PR #124 的 schema v39 已能保存根位置与全部子资产关系。

## 客户端结果

- 靠近普通地面物品时继续显示 `E - 拾取`；靠近容器时改为 `E - 打开容器`。
- 打开后右侧按内容定义显示全部分区及现有物品，支持与胸挂、背包和装备槽双向拖拽。
- `Ctrl+左键` 快速转移在地面容器与随身空间之间工作；若物品可穿戴且对应槽位为空，继续优先快速装备。
- 界面提供正常的鼠标“拾取容器”操作；成功后关闭容器页。`Tab`、`Esc`、基地警报和流程切换统一清理容器会话。
- 地面容器页不连接 Stash，不允许直接压弹、装匣、维修或使用地面容器中的物品；先把物品转入随身区域后再执行特殊动作。

## 自动化、人工验收与回滚

自动化覆盖正确站点/距离、错误根、远距离、其他地面容器、Stash 越权、地面容器到随身、随身到地面容器、交换、快速装备、非空嵌套拒绝、事务幂等、保存失败和 schema v39 往返回归。完成 Windows Debug 构建、定向测试、全量 CTest 和 exact-head Windows/Ubuntu CI 后，再交给用户正常游玩验收；Codex 不自行启动游戏。

人工验收将使用一个放在基地地面的背包或胸挂：按 `E` 打开，在两侧双向拖动物品并测试 `Ctrl+左键`，关闭和重启后确认内容与位置不变，再用“拾取容器”把整个非空容器收回。

回滚使用普通 revert。由于不增加 schema，回滚不会令 v39 存档不可读；回滚后地面容器仍可作为 PR #124 的完整根资产拾取，只失去就地打开界面。

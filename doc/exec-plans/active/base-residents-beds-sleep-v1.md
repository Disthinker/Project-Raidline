# Base 居民、床位与睡眠 v1 ExecPlan

最后核对：2026-08-25。

## 产品结果与范围来源

Base 新增可交互宿舍。玩家可以查看普通居民聚合人数、床位容量、拥挤缺口和下一次每日口粮需求，并在 Base 主动休息 1、6 或 12 小时。休息推进唯一 WorldClock、结算跨越的 00:00 每日需求并原子保存；它不治疗玩家，也不推进离线时间。

只读 GDD `systems/17_剧情路线与基地人口.md` 已确认：普通居民使用聚合池，第一阶段人口日常需求只管理口粮和床位，短缺不阻止接纳，单次睡眠最多 12 小时。当前切片不实现幸存者接纳、具名 NPC、岗位/专业、居民医疗、正式三档士气、建设升级、精力、公共医疗储备、新美术或新音频。

## 状态、命令与不变量

- `ProfileState::basePopulation` 只保存普通居民总数和床位容量。玩家、具名 NPC 与未来专业资格不计入这两个占位字段。
- 每名普通居民每天消耗 1 单位口粮；卫生、运营支持和安全仍暂用既有固定需求。床位不足只形成只读拥挤投影，本轮不直接扣资源或修改士气。
- `queryBaseRest` 只读预览时钟、跨日数、口粮需求和床位缺口；`executeBaseRest` 接受 1～12 小时、expected revision 与 transaction ID。
- 休息在 Profile 候选上推进时间、结算每日需求、同步五日愿望并递增 revision；保存失败、过期版本、重复事务、Raid pending 或非法时长均保持内存状态不变。
- Base 实时流逝和 Raid 旅行继续使用同一人口口粮需求；休息不建立第二套时间或结算规则。

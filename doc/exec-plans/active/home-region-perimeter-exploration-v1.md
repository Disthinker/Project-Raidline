## 产品结果

玩家可以不经过 Deploy 或加载画面，直接从基地安全核心步行进入同一 Home Region 地图的外围；外围存在少量有限感染者和低阶物资。玩家返回安全核心时保留所得并支付一次本地行动时间；外围死亡会被救回安全核心，保留个人资产与本次所得，但承受有界伤势和更高时间代价。

本计划唯一范围来源是 2026-09-02 策划线程裁决及用户已确认的统一 Home Region 方向。正常游玩验收由用户完成，Codex 不启动游戏。

## 当前差距与复用边界

### 可复用

- `BaseWorld` 已拥有 Home Region 大地图、基地地块、道路、碰撞、镜头投影、射击和玩家移动。
- `AssetRegistry`、`BaseGroundAssetLocation` 和 Base 地面拾取提供唯一物品所有权。
- `WorldClockState` 及每日系统同步是唯一时间权威。
- 现有 Enemy、命中结果、碰撞与空间索引可以服务有限外围敌人。

### 需要重构

- 将 Base 从“全图安全”改为明确的 `SafeCore / TransitionBuffer / Perimeter` 区域查询。
- Base 射击从无目标表现升级为只对外围敌人生效，并禁止敌人跨越安全边界。
- Base 更新需要把外围杀敌、拾取、返回和救援事实提交到 Profile，而不是让 App 猜测。

### 需要新建

- `HomePerimeterState`：按基地地点及世界时间周期保存确定性敌人、Loot、清除/拾取状态和活动行动。
- `HomePerimeterRuntime`：只拥有当前地点外围敌人的瞬态移动、警觉、攻击与表现映射。
- 返回/救援的幂等结果 ID、一次性时间结算和跨进程恢复合同。

### 停止扩展

- 不把 `GameplayWorld`、`RaidSession`、`PendingRaid`、`RaidResult` 或 `Settlement` 嵌入 Base。
- 不建立第二套背包、地面资产、伤害或时钟系统。

## 状态所有权与领域合同

`ProfileState::homePerimeter` 是长期权威状态。每个已访问基地地点最多保存一个当前刷新周期快照：

- 稳定地点 ID、周期索引、确定性 seed；
- 有限敌人的稳定本地 ID、生成点、当前点、生命和清除状态；
- 已实例化为 `BaseGroundAssetLocation` 的 Loot 资产 ID；
- 当前行动及已提交结果 ID。

刷新周期只由权威世界时间跨越固定周期边界触发；打开界面、离开/重进区域或重启进程不得重抽。活动行动开始、敌人死亡、Loot 拾取、返回与救援均先在候选 Profile 中验证，再原子保存并交换内存状态。

区域查询完全 SDL-independent：

```text
SafeCore        基地地块及软边界内；设施与 Stash 可用，敌人不得进入或攻击。
TransitionBuffer 核心外的缓冲带；用于稳定进入/退出和敌人脱战。
Perimeter       可发生有限战斗、拾取与本地行动。
```

返回安全核心提交一次本地行动时间并结束行动。外围死亡提交更高时间代价、将 HP 恢复到安全但受伤的下限，并把玩家放回医疗点；不创建 `PendingRaid`、`RaidResult`、`LostRaidRecord` 或任何 Settlement。两条路径都保留装备、随身物品和已拾取 Loot，也不自动消费医疗物。

1. **领域与保存骨架**

2. **外围运行时与战斗边界**
   - BaseWorld 配置快照敌人，外围有限追击/攻击，射击命中回写生命。
   - 敌人不能进入 TransitionBuffer/SafeCore，越界后确定性脱战并返回生成区域。
   - 退出条件：敌人边界、多人攻击保护、阻挡碰撞和同局死亡不刷新测试通过。

3. **Loot、返回与救援闭环**
   - 每周期生成 2～3 个低阶 Loot 资产，复用 Base 地面拾取和唯一所有权。
   - 跨出核心启动行动；返回或死亡各只结算一次时间，且保留资产。
   - 退出条件：返回、救援、异常关闭、重复结果和跨进程序列通过。

4. **客户端可读性与交付**
   - 以现有代码图形、文字和已批准敌人/物品 fallback 显示安全边界、外围状态、敌人与 Loot。
   - 新文本提供中英文；Tab 在核心外仍仅显示个人库存。
   - 退出条件：定向测试、全量 CTest、Windows/Ubuntu exact-head CI 通过，Draft PR 等待用户正常游玩验收。

## 自动化与人工验收

自动化至少覆盖：

- 同地点、同周期、跨进程产生相同敌人/Loot 快照；换周期才刷新。
- 敌人和攻击均不能穿越安全边界；返回出生区稳定。
- 每个 Loot 实例只有一个合法位置，拾取、保存、重载不复制。
- 返回与救援分别只推进一次时间；重复命令、过期 revision 和保存失败零修改。
- 外围死亡不创建 RaidResult、PendingRaid、LostRaidRecord 或 Settlement，且不吞装备/战利品。
- active outing 拒绝迁徙、建设、休息等不兼容操作；安全核心内原功能不回归。
- 旧档迁移、不同基地地点、中英文与长序列回归。

用户正常游玩验收：从安全核心步行进入外围，拾取低阶物资、与有限感染者战斗并返回；再次出入确认本周期不刷新；再测试一次外围死亡救回、重启存档和另一个基地地点。无需调试按钮或单步验收操作。

## 风险

- Base 与 Raid 生命周期污染：通过窄 `HomePerimeterState/Runtime` 和禁止 Raid 类型的测试约束。
- 频繁持久化卡顿：只有行动开始、敌人死亡、拾取和结果这些离散事实写盘；逐帧位置不写盘。
- 跨边界反复触发：使用 TransitionBuffer 和显式 active outing 状态去抖。
- 死亡保留物品削弱 Raid 风险：该规则只适用于 Home Region 本地外围，不能被 Raid Settlement 复用。

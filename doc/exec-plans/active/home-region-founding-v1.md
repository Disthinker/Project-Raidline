## 玩家结果与范围

普通新档从安全临时物资点出发，在同一个 Greyline Home Region 的开阔空地、民用院落、仓储院落之间实地选择。三个合法落点内部障碍不同，均有道路接入。激活唯一科技核心后建立基础基地，接通已有 B 建设、Tab 库存、设施和首次 Raid。起步提示可关闭，不强制建设、射击、受伤或成功撤离。

只做一个区域、三个固定候选、一份有限起始预算和一个完整 PR。不增加区域路线节点、导航、任务板、剧情人物、AI 队友、实时守城、任意位置建家、新物品/配方、美术/音频/manifest。

## 差距与架构合同

- 复用 AssetRegistry、普通 starter、GameSession 候选保存、BaseWorld、设施归一化布局、HomePerimeter、WorldClock、已有建设和 Raid。
- 新建窄 HomeFoundingState：尚未建立/已建立、按区域保存稳定局部 PlotId、布局版本和可关闭提示。默认旧档已建立/布局 v1；新档明确尚未建立/布局 v2，不把一个后台运转的基地隐藏起来。v2 已发布后不得静默重写固定地块结构。
- 建立前没有人口、工作岗位、设施或经营压力；临时物资点只是访问同一 Stash 的空间入口，不复制库存。科技核心已授予但未部署。考察阶段安全，不运行外围敌人；唯一时钟不补扣不存在的基地经营需求。
- 成立使用 query/execute + revision/TransactionId，验证当前区域、合法落点和实际接近，再一次初始化基础设施/居民/运营储备并部署核心。起始物资保持原 AssetInstanceId 和位置，不再次发放；BaseGround 不迁移。
- 安全核心、设施布局、Stash 访问、外围排除区与道路消费同一 Plot 几何。未选点无隐形安全区；迁出再回保持该区域落点。旧档使用 legacy 布局且不移动设施/地面资产。
- schema v45 显式保存新状态，v44 及更早迁移为已建立/已处理引导，不改变旧 pending Raid 的 rules/content 或资产。新增状态参与校验和指纹，未知 ID、未建家与经营状态冲突拒绝加载。
- BaseWorld 只接收选择后的空间配置和 survey 模式；App 只读投影、提交交互，不决定合法性。普通新游戏进入新流程；现有 makeNewAlphaProfile 保留为已建立领域基线/旧测试适配器。

## 实施、门禁与回滚

1. 新建家领域、状态、schema/指纹与原子事务；拒绝、重复、旧档不变测试。
2. 三候选布局与统一空间配置；道路/入口/设施净空、外围安全、迁徙往返测试。
3. 新档、继续、近距建立交互、地图候选、非强制提示与真实建设/首次 Raid 衔接；中英文和输入回归。
4. Windows Debug 全目标、focused tests、全量 CTest、exact-head Windows/Ubuntu CI；代理不启动游戏。

自动化涵盖三落点、合法性/互斥、保存失败、重复建立不发资源、关程序恢复、旧档与 pending Raid、地面物保留、外围不进核心、首次失败/成功、迁出再回、既有性能门禁。

人工使用隔离验收档，不覆盖原档：查看三个候选并理解空间差异；在一处建立；整理配装并做已有建设；正常出击及返回；途中重启保持选择；旧档原地继续。三候选空间由自动化覆盖，不要求手工删档反复测试。

回滚保留升级前 v44 备份，v45 不承诺旧程序读取；只回滚本片提交，不改玩家文件。新 PR 保持 Draft，用户验收前不合并。主要风险是起始预算重复、未建家隐性日结、核心/设施/外围坐标漂移和旧档迁移；以共享几何及资产指纹断言阻断。

# 重伤撤离与野战夹板 v1

**已验收 · RL-RAID-FRACTURE-AND-FIELD-STABILIZATION-v1**

在「医院片区」搜物资时，玩家能识别并躲开感染者的低位扑击。腿部骨折后，可以现场上夹板、靠止痛药撑到撤离点，或带伤回营治疗。医院搜获和基地制造都能补上下一局需要的夹板。整个流程交付一个候选，集中做一次游玩验收。

## 玩家会遇到什么

| 环节 | 建议规则 |
| --- | --- |
| 医院遭遇 | 「区医院内部 → 急救治疗区」的一名现有感染者使用低位扑击。起手约 **0.7 秒**，方向在起手时锁定。玩家能侧移或借墙躲避。扑击使用腿部倍率，建议基础伤害 22，按现有 0.75 倍和向上取整结算为 17 HP。单次实际伤害达到 **16 HP** 且玩家存活，才以 **65%** 概率检定骨折。只有这一种攻击触发新伤势。 |
| 局内取舍 | 未止痛时，骨折将步速限制在基础步速的 **70%**，并禁冲刺。止痛药沿用 **2 秒服用、180 秒药效**，暂时解除这两项骨折限制。药效结束后，如伤势还在，限制恢复。夹板可治愈骨折。局内通过胸挂的 **5 医疗轮盘**使用，沿用 **4 秒慢行医疗动作**，完成后消耗 1 件。夹板效果限于骨折，流血和生命值由原药品处理。 |
| 搜获与撤离 | 「急救治疗区」将现有一处普通医疗掉落换成 **1 个夹板**，沿用原掉落位与拾取规则。负伤仍可使用同一撤离点。成功撤离保留骨折、剩余药效及实际携带的夹板。 |
| 回营与下次准备 | 在基地可自用一件夹板，或在「医疗服务 → 个人治疗」即时治好骨折。建议骨折处理加收 **45 货币**，既有缺血每点 3、轻度流血 30、重度流血 60 保持，付费治疗只扣货币。工坊用 **绷带 ×1、废旧零件 ×1** 制作夹板，每单需 **1 名工人、90 游戏分钟**，沿用现有生产效率、排队、完成和满仓规则。 |

夹板建议占 **1×1 格、300 克、单次使用、单格一件**，首版来源为医院和工坊。建议回收价 **10 货币**，低于两项原料的合计回收价 25。这个价格、重量、治疗费和扑击基础伤害是主控补齐的首版建议值，与上表一起确认。公共药柜和居民治疗资格沿用现有白名单。

骨折与流血分别记录，骨折最多一层。止血后，骨折仍可维持疼痛。现有止痛资格和动作时序沿用，单独骨折即可触发用药资格。奔跑、瞄准、负重、控制和正在执行的动作仍由各自的规则裁定，止痛只解除骨折限制。骨折独立产生的可见反馈使用现有伤势提示，出声沿用已有流血事件。轻度流血自然结束、医疗包回血和付费治疗后的剩余药效采用现行规则。

## 实施安排

1. **把遭遇接入医院现有位置。** assets/content/v1/core.json 中的医院室内已有四名感染者，急救区附近一名位于 (1940, 850)，对应掉落位是 hospital_emergency (2190, 850)。在 raid_lifecycle.cpp 仅为新开的医院普通对局冻结替换这一名感染者和这一处掉落，保留原数量、出入口与其他保底奖励。失物寻回和已有冻结对局沿用原状态。复用 enemy_attack、enemy_attack_contact、gameplay_world 的攻击、遮挡和命中消费，给低位扑击接入单独的腿部命中定义和现有攻击预兆呈现。起手锁定方向，出招时以实际接触和遮挡决定是否命中。击倒、错过、隔墙和保护时间抑制都不会产生骨折。复用现有感染者表现和医疗占位资源。
2. **先落伤势事实，再接药品和操作。** 在 profile_combat_domain.cpp 使用实际结算伤害检定。独立随机流只在符合条件的命中上消费一次，避免扰动流血、掉落和出生点。medical_types.h、medical_domain.cpp 分开处理骨折、流血和止痛计时。game_session_player_actions.cpp 在选择冲刺和瞄准等状态前应用骨折限制。raid_action.cpp 和现有医疗轮盘走合法持有、动作中断和完成时扣除，已授权的既有中断规则继续使用。沿用 ui_raid_hud_presentation 和中文本地化提示显示伤势及药效。
3. **把治疗和补给接回基地。** 工坊复用 base_manufacturing_domain 预留原料、单件产物与失败重试。基地自用夹板沿用现有个人药品的即时提交。base_medical_service_domain.cpp 在现有报价中新增骨折费用，保证满血骨折也能治疗。app_ui_base_medical.cpp 和 ui_base_medical_presentation.cpp 把该伤势加入报价和确认校验。夹板、工坊和付费治疗均走同一实例归属、实际耗用与保存成功后提交规则。
4. **补齐持久化和回退。** 当前格式/内容是 **71／89**，拟升级到 **72／90**。save_repository、profile_state 和现有玩家状态快照同时读写当前骨折、出击前骨折和本局冻结遭遇。旧档默认无骨折，旧冻结医院、原枪追踪、边境封路、药柜与工坊订单照旧恢复。正常撤离保留伤势。死亡和主动放弃按现有规则清空角色伤势并结算失物。异常退出恢复出击前的伤势、药效和物品，保留当前独立提交的救援等规则。使用旧主备档副本验证首次迁移和回读，保留原始备份。交付前保留候选及上一版可运行程序，回退时使用与版本匹配的存档副本。

范围限于单一医院遭遇、骨折、夹板及其回营整备。沿用现有地图与普通抓咬。内伤、分肢血量、敌人断肢、新地图、居民伤势扩展和正式美术音效属于后续范围。

## 一次联合验收

1. 用固定入口的隔离验收档，带止痛药进入「医院片区」。在「急救治疗区」观察一次扑击并侧移躲开，再承受一次合格命中。验收档选择可触发骨折的正常种子，不用额外按钮。
2. 验证骨折时步速和冲刺受限，止痛后暂时恢复。带伤撤离并重开，确认骨折保留，再从基地「个人治疗」处理。对照药品、公共药柜和货币变化。
3. 从同一隔离验收档的另一条路线，在急救区拾取夹板并使用。确认中断保留物品，完成后解除骨折。在工坊补做一件，领出并带入下一趟出击。

自动化覆盖侧躲/隔墙/死亡中断、实际扣血门槛、65% 随机边界和防双扣；骨折与流血共存、止痛到期、夹板中断及付费重试；多种子下的医院出入、原掉落与普通局边界；撤离、失败、异常恢复和历史档副本。保留主线全部 **3339 项**基线用例及 **14 项 3 ms** 检查、现有全部其他门槛。再测单一低位扑击场景和中英文伤势提示在现有窗口中的可读性。

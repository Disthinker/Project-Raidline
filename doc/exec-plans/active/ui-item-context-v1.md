## 玩家会看到的变化

1. **右键菜单成为完整浮层。** 顶部显示物品名称，下方显示已有操作；名称可以换行，菜单会避开窗口边缘。行内有悬停、按压反馈和轻微文字强调。
2. **停留后显示一张信息卡。** 同一物品悬停约0.4秒后出现；包含名称、等比图片、占格、数量、重量及已有类别状态。鼠标在同一物品占格内移动，不反复等待或让卡片来回漂移。
3. **武器信息合在一起。** 在装备枪械上悬停时，将物品摘要与现有供弹、开火和排障提示放进同一张卡，避免重复浮层；保留全部已有提示。
4. **减少菜单误触。** 在同一操作行内按下并松开才执行一次；点外部只关闭菜单。按Esc先关闭菜单，拖拽、翻页、切标签和关闭库存时清除临时浮层。

本次仅覆盖基地和突袭库存里的物品菜单与信息卡，包括装备槽、个人容器、仓库页、旧档待整理区和当前允许访问的外部容器。

悬停计时以稳定实例ID及当前可见容器为依据。同一物品占格内小幅移动不重计时，换物品重计时；打开菜单、开始拖拽、翻页、失焦或关闭库存立即隐藏。卡片只显示信息，不参与点击或拖放，不获得输入焦点。

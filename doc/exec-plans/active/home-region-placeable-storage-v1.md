# Home Region 可放置储物箱 v1 ExecPlan

状态：实现完成；Windows Debug 全目标构建与 1368/1368 CTest 已通过，等待 exact-head Windows/Ubuntu CI 和用户正常游玩验收。

## 目标与基线

依赖基线为用户已验收并合入的 PR #125，`origin/main@03028bb`。开发分支为 `codex/home-region-placeable-storage-v1`。

本切片加入一个使用代码图形和文字占位的基础储物箱。玩家可从基地固定供应购买，在基地板块内选择世界位置放置；储物箱放置后成为持久化的真实资产根、空间阻挡和可近距离打开的库存容器。它复用 PR #124/#125 的 BaseGround 与世界容器事务，不建立第二套设施库存。

## 内容与领域合同

- 新增稳定定义 `item.container.base_storage_crate`，提供一个通用连续格区、明确世界占地、固定供应价格和回收价格；content 升级到 v58，schema 保持 v39。
- `ItemDefinition` 增加可选的 `base_placement` 能力，声明世界占地、是否限制在基地板块以及是否阻挡移动/弹道。只有当前消费者所需字段，不建立通用建造或家具框架。
- 放置查询由 GameFlow 组合当前基地板块、设施/环境阻挡、玩家占位和已放置空间资产；领域层统一验证完整位于基地板块、无重叠、方向合法、来源可访问与 revision。
- 合法提交只把同一个资产根迁移到 `BaseGroundAssetLocation`；内容继续跟随容器。失败、保存失败、重复事务或过期 revision 均零修改。
- 空储物箱只能在仓库连接范围内收回 Stash；非空储物箱必须先清空再收回，避免大型固定容器被当作背包装备或整体随身携带。

## 客户端结果

- 将储物箱拖到“基地地面”后不立即落地，而是关闭库存进入鼠标放置模式。
- 鼠标控制储物箱中心，合法位置显示绿色占地框，非法位置显示红色；`R` 旋转、左键确认、`Esc` 取消。
- 放置模式冻结射击和其他模态入口，不修改资产直至左键成功提交。
- 已放置储物箱使用更接近真实占地的矩形和双语文字占位，并参与玩家移动与基地射击的阻挡。
- 靠近后继续复用 `E` 打开及统一双向拖拽界面；非空时“拾取容器”返回明确拒绝信息。

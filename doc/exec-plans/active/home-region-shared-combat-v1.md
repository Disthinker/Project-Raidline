# Home Region 共享战斗能力 v1

## 交付目标

让 Home Region 的世界操作与 Raid 使用同一套瞄准和射击能力：玩家在基地大地图中可以瞄准、切换已装备武器和开枪；准星、散布、后坐力、逻辑弹道、障碍命中、曳光、枪口反馈、轻微屏幕抖动和音频与 Raid 保持一致。基地射击消耗真实枪膛/弹匣弹药并推进耐久与故障，但不创建敌人、伤害居民、破坏设施或进入 Raid 生命周期。

本切片是 Home Region 主框架的第一个能力切片。装弹、医疗、统一库存和基地地面物品留给下一切片，由 Base 活动策略提供即时完成语义。

## 架构合同

- 新增 SDL-free `WorldShootingRuntime`，唯一拥有准星、散布、后坐力、逻辑弹道和只读表现投影；`GameplayWorld` 与 `BaseWorld` 组合该窄能力，不互相继承，也不共享完整活动运行时。
- `GameSession` 继续拥有 Profile、武器实例、弹药、耐久、故障和事务；World 只报告本帧是否成功产生一发模拟射击及空间命中结果。
- Base 与 Raid 复用相同 `WeaponUseDefinition`、开发调参覆盖和弹药穿透查询。App 只消费 Projection/HitResult，不推断命中或消耗。
- Base 高频射击先以领域事务提交内存 Profile，再标记现有原子存档检查点为 dirty；30 秒周期检查点、进入 Raid、返回主菜单和退出桌面会落盘，禁止每发同步写盘造成射击卡顿。
- Base 不创建 pending Raid、RaidResult、Settlement、失物记录、敌人或 Loot；设施和环境仅作为弹道阻挡。

## 实施步骤

1. 从 `GameplayWorld` 提取共享射击能力并保持现有 Raid 行为和测试。
2. `BaseWorld` 接入瞄准、射击、障碍命中和表现投影。
3. `GameSession` 编排 Base 武器选择、真实 FireWeapon 事务、穿透、故障和开发调参。
4. SDL Base 输入接入相对鼠标捕获、右键瞄准、1/2/3 切换与左键射击；渲染复用准星、曳光、火光、烟雾、粒子、抖动和音频。
5. 更新自动化、Windows Debug、全量 CTest 和双平台精确提交 CI，再交给用户正常游玩验收。
6. Base 的 Tab 仓库权限改由玩家是否完整位于基地板块内决定；离开板块后仍可整理、使用和快速装备随身物，但个人页不再显示或接受 Stash 目标。
7. Base 支持用 `M` 打开 Home Region 全静态地图，显示分区、地表、道路、环境物、基地板块、设施与玩家位置；地图不复用 Raid 情报、战争迷雾、目标或撤离状态。

## 自动化门禁

- Base 直接模拟可产生准星、逻辑弹道、曳光、枪口反馈、障碍/地面命中和粒子，且永不产生 Enemy 命中。
- GameSession Base 射击准确消耗一发真实弹药并降低武器耐久；拒绝或空仓不产生模拟射击。
- Base 切换武器不移动当前准星位置；F10 覆盖同时作用于 Base 和 Raid，且不写 ContentRegistry 或 Profile。
- Base 射击不创建 pending Raid、RaidResult、Settlement 或失物记录；周期/退出检查点后跨进程读取保持弹药和耐久。
- GameplayWorld 现有射击、命中、敌人移除、并行导航数组、表现与性能回归全部通过。
- BaseWorld 仓库连接查询在玩家完整位于基地板块时为真，离开后为假；玩家个人页模式不枚举、命中或提交 Stash 目标。
- Home Region 地图只读取现有确定性布局与玩家瞬态位置；打开地图不修改 Profile、布局、情报或存档。

## 用户正常游玩验收

1. 在基地大地图移动鼠标，确认准星与镜头同步；按住右键、移动/奔跑时散布与 Raid 一致。
2. 使用 1/2/3 切换已有武器，准星位置不跳变；左键单发/连发可听到枪声并看到曳光、枪口火光/烟雾、轻微抖动和障碍/地面命中。
3. 连续射击后打开库存，确认真实弹药与耐久减少；故障时可用既有鼠标清障手势恢复。
4. 打开 F10 修改当前武器参数与无限弹药，确认基地中立即生效；关闭无限弹药后恢复真实消耗。
5. 返回主菜单或退出并重进，确认已检查点保存的弹药与耐久保留；基地没有敌人、撤离点、高危或 Raid 结算。
6. 在基地板块内按 Tab，确认右侧显示仓库；走出基地边界后再次按 Tab，确认只显示个人装备与随身容器，仍可整理和快速装备，但无法看到或移动 Stash 物品。
7. 在基地地图任意位置按 `M`，确认能够查看完整 Home Region、基地板块和玩家位置；地图打开时可缓慢移动，不能射击或操作设施，`M`/Esc 可关闭。

## 回滚

本切片不修改 schema、content 或资源 Manifest。若共享能力造成 Raid 回归，可以整体回滚 `WorldShootingRuntime` 和 Base 消费者；Profile 与存档无需反向迁移。

## 明确延期

- Base 即时装弹、卸弹、安装弹匣、医疗和统一库存命令。
- BaseGround 物品放置、拾取、丢弃和持久化（转入后续 `home-region-ground-assets-v1.md`）。
- 居民/设施伤害、友军火力、基地死亡、实时守城、敌人或 Loot。
- 正式角色/武器射击动画、新美术、P1 音频与 Manifest 修改。

# 主角持枪动作与双手绘制 v1

**已通过人工验收。** 玩家在基地和对局中能看到自己正在持用的枪。走跑时身体保持原步幅，手跟枪走；换枪、举枪、放下时，双手按作者的顺序移动。方案编号为 `RL-AUTHORED-PLAYER-WEAPON-LAYER-v1`。

## 玩家会看到什么

| 操作 | 预期结果 |
|---|---|
| 空手或持枪走、跑、停 | 显示相应待机和移动动作；头部随躯干起伏。任一走步帧转跑都以当前承重脚开始。持枪从任一跑步帧减速，分别接走步第 1、3、4、5、7、8 帧。 |
| 在有装备的两个栏位之间切换 | 长枪从背后取出，手枪从下方取出。近手先抓，远手随后补握。遮挡正确，画面中始终只有一套双手。两枪即使共用同一轮廓，也按实际换枪动作播放一次。 |
| 举枪再放下，或在举枪途中松开右键 | 手和占位枪共同改变高度；中途反向从当前高度接续。脚步不停，既有瞄准、镜头和射击响应照常工作。 |
| 保持合法瞄准并切枪 | 目标武器直接接到瞄准位。若实际取消切换、改换目标、失去控制或不再瞄准，则按当前有效状态收束。 |

**枪型映射提案。** 当前内容表有手枪、步枪、紧凑卡宾枪、精确步枪和支援机枪。手枪使用小型占位和下方取枪；长枪使用背后取枪。为让第三种待机能在正常游玩中验证，建议让现有 5.45 紧凑卡宾枪采用源工程的冲锋枪待机姿态，保留原名称、分类和长枪取枪动作。站姿、占位大小和取枪方式分别配置。

## 实施与归属

1. **动作和美术。** 按源 clip ID、方向、体型及帧时长离线导出。空手身体保留双手；持枪身体用工作台的 `handVisible` 在烘焙副本中隐藏两手，导出独立手型、逐帧手部轨迹、武器锚点与抓握事件。固定脚底锚点 (32,60)，复验已有 16 个走转跑入口。美术主控独占新版本资源目录与清单；游戏运行时复用已加载的图集。
2. **合成一帧。** 主控在客户端依据装备实例和帧数据组合身体、远手、近手、枪。为大、小原创占位轮廓配置局部抓握点、朝向和身前／身后顺序；取枪前枪受躯干遮挡，抓取前的手跟作者轨迹，抓牢后的手与枪使用同一变换。测试每个已抓牢的手在举枪、转身和切换中跟随抓点，目标误差不超过 1 源像素。枪的绘制位置仅用于表现。
3. **切换时序。** 读取 `GameSession::activeAlphaWeapon()` 的实例及已获准的 `WeaponSwitchRaidAction` 的源槽、目标槽与进度。大型取枪共 7 帧（315 ms），第 3 帧近手抓取；小型 5 帧（210 ms），第 2 帧抓取；两者都是末帧远手补握。把作者时序映射到游戏已有的换枪耗时，取消时恢复实际有效实例；重新装备、自动回退和无枪状态同样由真实装备结果决定。
4. **瞄准与移动。** 举放枪各 4 帧，作者参考时长 100 ms，以原有瞄准进度驱动；基地补齐与对局等价的只读数据。切枪期间持续合法的瞄准意图决定是否使用直达瞄准轨迹，镜内暂时关闭不会触发腰位闪回。取枪或举枪只使用上半身及武器轨迹，移动时继续走脚下的步态。普通视图、视野重绘及镜内只读同一份姿态，配装静态预览按原方式等比显示。武装搜刮者、队友和感染者继续用各自原入口。
5. **隔离与交付。** 上一版移动动画已通过用户验收。其程序、图集、冻结补丁及未跟踪文件已核验，程序指纹 `891b8a5e88b0`，图集 `ea339b3585a5`。在独立工作树以已验收版本 b57408e 为基线构建联合候选，使用隔离试玩档。桌面 Project Raidline Debug 是唯一验收入口。上一版保留为回滚程序。

## 联合验收

1. 在基地空手走、跑、停，再装备手枪、紧凑卡宾枪及一把普通长枪。看四种待机，左右方向都没有重手、缺手或头身断开。
2. 持枪时在走步的前后半步分别按 Shift，再在跑步中松开 Shift。玩家立即变速，承重脚衔接连续；自动化另外遍历左右全部走转跑和跑转走入口。
3. 用已配装的主、副武器或手枪栏切换。比较长枪背后取、小枪下方取；慢走中切换时双脚继续走，按原规则取消后显示正确的枪。
4. 普通对局中举枪、半途松开、保持右键换枪，再在墙边、门口和镜内观察。上下斜瞄、急转、开背包及切回游戏后，手仍贴着枪；切完直接到目标高度，准星和原有开收镜手感稳定。

回归包括 SDL 离屏分层像素与抓点检查、全量 CTest、原 3 ms 和基地存档 8 ms 门槛。沿用原存档格式、装备与射击规则。仅产出本地可玩候选与简短清单。

# 野战照明弹与暗区搜索 · 联合验收

打开桌面 **Project Raidline Debug**，继续存档。准备已部署且有健康人员的工坊、铜线卷和损坏电子元件各一件，以及一件带空格的胸挂。

1. **制作并备装。** 在「工坊与生产」第 2 页选照明弹。推进面板显示的时间，领取两枚并放进胸挂。
2. **投出一枚。** 到「区医院内部」，关闭手电和夜视。按住 4 选择照明弹，松开后先右键取消一次。重新选中后左键投向昏暗通道，库存应只扣一枚。
3. **借光搜索。** 落点附近亮起并显示余时。朝向通道时可看清受照的目标，墙后目标和高倍镜圆外目标仍受遮挡与视野限制。在原交互距离内搜取物资。可以换房再回来检查剩余时间，或开启夜视近看光源，核对短暂的局部眩光。
4. **检查熄灭与保存。** 等照明熄灭，确认仅由它照出的目标重新隐藏。正常撤离并重开，核对剩余照明弹。也可在基地外围用同样操作，确认安全核心的投掷限制。

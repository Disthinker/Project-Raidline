# 专业小队远征 · 联合试玩

打开[开始联合试玩](<E:/RaidlineBuild/candidates/specialist-squad-expedition-v1/开始联合试玩.cmd>)，选「继续游戏」。这份独立试玩档位于基地出击口，仓库备有三种借枪、普通弹和药品，医疗所备有公共物资。两名专业干员需要亲自营救。

| 试玩 | 操作与预期 |
| --- | --- |
| 1. 救出支援干员 | 普通出击选**灰线仓库**，按 **F1** 进「远征编队」，点「本局营救」切到支援干员。到营救点完成交互。回营后应多一名居民，支援干员可以编入。 |
| 2. 在医院用药 | 给支援干员借一把手枪，医疗栏选绷带和医疗包，仓库留足 **30 发普通 9 毫米弹**。在医院受伤后与他会合。安全时先止血，生命低于 60 时才主动回血。也可在个人指令中选「立即救护」。观察治疗中断和完成时的药量。 |
| 3. 满编、分队与授权 | 在**边境交换站**用同样方式救出狙击干员。给他借 7.62 精确射手步枪，备 **20 发 7.62×51 普通弹**。再带火力队员和支援干员进医院。**F1** 管全队，**F2～F4** 按加入顺序选人。留一人在门外驻守，带其余人进楼，回来集合。让火力队员交出一份携行物资，收到的那件应进入背包。狙击干员报告大致方位；选「授权当前目标」仅允许一次射击，遮挡令授权失效。 |
| 4. 让伤员轮休 | 带生命低于 **50** 的存活队员回营。在医疗所「居民治疗」里点「指定伤员」，选择他并开始治疗。读档后应是同一份医嘱。可先少带一人，治疗完成后再编入。阵亡者经过 **72 游戏小时**开放继任者营救。 |

火力队员沿用每次出击 30 发普通 5.45 弹。距离、视线和空间都会影响救护或领取补给。

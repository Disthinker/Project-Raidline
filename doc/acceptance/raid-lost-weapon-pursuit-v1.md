# 河畔检查站失物追踪与原枪夺回 v1

在 Windows PowerShell 粘贴下面一行，打开隔离验收档。窗口标题末尾会显示 `Test Profile`。平时直接打开桌面 **Project Raidline Debug**，仍使用玩家档。

```powershell
& 'E:\CodexWorkspace\Temp\Raidline-raid-lost-weapon-pursuit-v1\Start-Pursuit-Playtest.ps1'
```

1. **接追踪。** 点击「继续游戏」。到基地「对局出击」入口按 `F`，打开「失物记录」，选唯一一条记录并点击「设为寻回目标」。确认记录中有一把制式 5.45 步枪和一件防弹衣，再进入「河畔检查站」。短卡宾枪、背包和胸挂已配好，`2` 号长枪槽留空。
2. **找准目标。** 按 `M` 看黄色「原枪搜索区」。在区内找到「携带原枪的感染者」，可长按 `4` 选声响诱饵，松开后左键投掷。击倒目标，靠近后按 `F`。搜尸面板应只显示那把原枪。拖到 `2` 号长枪槽或背包。
3. **带枪回营。** 留在常规撤离区直到进度条完成。回营核对原枪仍装着 1.5 倍镜、混装弹匣和枪膛弹，耐久为 78%。打开出击口的「失物记录」，防弹衣应留在同一记录中。
4. **整备再出击。** 在基地打开「仓储与配装」，把「武器维修工具」拖到原枪上，确认耐久上升。卸下弹匣，把背包中的 5.45 弹拖到弹匣补弹，再装回枪上。装备原枪再次出击，试射并撤离。

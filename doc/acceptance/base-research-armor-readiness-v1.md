# 工坊蓝图研究与防具整备 · 联合验收

打开桌面 **Project Raidline Debug**，继续存档。工坊需要 2 级和一名健康的工程师。若工坊仍为 1 级，先到「资源分配与需求」加工至少 6 单位建材，再到「工坊与生产 → 设施与岗位」升级。预留一份铜线卷和一份废旧零件用于制作。

1. **搜回蓝图。** 开一场灰烬工场普通对局，在地图南半部沿资源路线搜取地面上的「防具维修蓝图」。撤离后把蓝图移入仓库。
2. **完成研究。** 在「工坊与生产」翻到「防具维修研究」，点「开始研究」。先取消一次，确认原蓝图退回。重新开始后，到「宿舍与休息」推进足够的游戏时间。蓝图应消耗一次，工坊同一条目变成防具维修工具配方。重新进入游戏确认配方仍在。
3. **制作工具。** 用铜线卷和废旧零件各一件开始生产。时间到后，仓库应收到一件防具维修工具。若仓库已满，腾出空间再回工坊领取。
4. **出击维修。** 带工具和受损防具进入普通对局。打开背包，把工具拖到受损防具上，约 6 秒后检查防具当前耐久与工具用量。

候选 `RL-BASE-RESEARCH-ARMOR-READINESS-v1-local-1caaec01cc66`。Windows Debug 全量 3212/3212，13 项 3ms 检查通过。用户已完成实机验收。

# 边境交换站：尸体搜索 v1 验收清单

这次主要确认：**击杀守卫后能搜尸，物品不会凭空刷新，撤离只带回真正拿走的东西。**

**只在“边境交换站”验收。医院片区和战斗测试场不包含本次搜尸试点。**

“边境交换站”是当前中文界面中的地图名，英文模式称 Frontier Exchange。如果界面显示英文，请在设置的语言选项中切换到“简体中文”。

适用版本：**中文修正版 1（03f42d4333a9）**。用户已于2026-10-13明确验收，以下清单保留供回归使用。

桌面入口仍为 **Project Raidline Debug**。再次回归时，先检查三项中文变化，再体验完整搜尸流程。

## 本轮先检查这三项

1. **地图和路线名称：**出击面板能看到“边境交换站”和“医院片区”；地图说明、区域路线、设施和升级名称使用完整中文，不再出现把地名当成“工业紧固件”的文字。
2. **尸体面板：**在边境交换站击杀试点护甲守卫，靠近按F；顶部应为“尸体”，格子标题为“尸体 | 储物格 1”。字迹清楚，快速转移提示与标题不重叠。
3. **物品和既有操作：**背包与尸体里的物品短名称使用中文，不出现英文截断前缀或半个汉字。正常拿取、放回；打开关闭菜单、进出建筑后，准星仍保持之前验收的窗口位置。

按键、数字、枪械型号以及重量单位可以保留原标识。如果只检查了中文项，请注明范围；不要把后面尚未体验的搜尸项目写成已通过。

## 开始前

1. 双击桌面的 **Project Raidline Debug**。
2. 准备武器、弹药和背包，留出一些空格。
3. 在基地出击口打开出击面板，点击地图名称旁的 **< / >**。
4. 确认地图名称显示 **边境交换站**，再确认出击，开始新对局。已有存档可以继续用，不需要删档；旧版本遗留的对局不能用来检查新尸体功能。

本次只有三组资源守卫中的护甲成员能留下可搜索尸体。它们在工业、物流或路边服务区域；具体位置随本局生成变化，没有固定坐标。

**辨认方法：**敌人胸前有深色背心图形，上方显示“躯干护甲”；护甲破损后显示“背心已破损”。请按中文文字辨认。

普通巡逻敌人和后续来袭敌人没有这项掉落，不能据此判断功能失效。

## 一、击杀后能打开尸体

| 你做什么 | 应该看到什么 |
| --- | --- |
| 击杀资源点附近的护甲守卫。 | 敌人倒下的位置留下尸体；尸体不再攻击。 |
| 靠近尸体，看到“F：搜索尸体”后按 F。 | 打开有文字标题和物品格子的尸体面板，鼠标可以操作物品。 |
| 关闭面板，尝试穿过尸体所在位置。 | 尸体不阻挡移动。 |
| 找到另外两组资源守卫，击杀各自的护甲成员。 | 每名试点护甲守卫各留下一具可搜索尸体，本局最多三具。 |

尸体目前使用简单图形占位，不是正式美术；标题和搜索提示应当能读清楚。

## 二、拿取和放回不会丢物品

在同一具尸体上依次检查：

| 你做什么 | 应该看到什么 |
| --- | --- |
| 拖一件物品到背包空格。 | 背包出现这件物品，尸体里相应减少。 |
| 把它拖回尸体空格。 | 物品回到尸体，背包相应减少。 |
| 按现有格子操作交换两件物品，或旋转一件可旋转物品。 | 放得下才成功；放不下时，原物品不会消失。 |
| 如果有两堆相同物品，尝试合并。 | 数量只合并，不增加；装不下的部分仍保留。 |
| 取空尸体，按 Esc 关闭，再靠近按 F。 | 显示已搜空，面板仍能打开，不重新生成物品。 |
| 向搜空的尸体放回一件物品，再关闭、重开。 | 还能看到刚放回的物品。 |
| 背包没有可用格位时，再尝试拿取一件物品。 | 操作被拒绝；物品仍在尸体中，不消失、不复制。 |

如果这一局没有适合堆叠或旋转的物品，记录“本局未遇到”，不要写成已通过。

## 三、走远和进出建筑后，内容仍正确

| 你做什么 | 应该看到什么 |
| --- | --- |
| 打开尸体面板，按移动键走远。 | 超出搜索范围后，面板自动关闭。 |
| 正在拖物品时，用移动键走出搜索范围。 | 拖拽取消；未放下的物品仍在原处。 |
| 回到同一具尸体，再按 F。 | 仍是之前剩下的物品，没有刷新。 |
| 进入附近建筑，再出来搜索这具尸体。 | 尸体还在原来的倒地位置，内容没有变化。 |
| 周围还有敌人时，短暂打开尸体面板。 | 敌人和战斗继续运行，搜索不会暂停世界。 |
| 搜索时被敌人控制住，例如被抓住。 | 面板关闭、拖拽取消；未完成的移动不改变物品。 |

没有遇到控制攻击时，记录“未遇到”，无需为了这一项反复寻找敌人。

## 四、菜单和准星保持原来的手感

1. 把准星放在窗口边角附近，打开再关闭背包或菜单。**预期：**准星回到原来的窗口位置，点击界面不会误开枪。
2. 让玩家处在窗口中偏离中央的位置，将准星停在窗口内某一点，不移动鼠标，再进入和退出建筑。**预期：**准星在窗口里的位置不突然跳变，也不会跑出窗口。
3. 在建筑内正常打开原有固定箱。**预期：**文字、格子操作和物品拿取仍然正常。

## 五、撤离后只带回实际携带的物品

1. 从尸体取走部分物品，记下名称和数量，把另外一些留在尸体里。
2. 按正常流程成功撤离，查看带回物资，再重开程序。

**预期：**只保留实际带走的物品；留在尸体里的物品不会自动入仓，也不会在重开后重复发放。

## 六、另开对局检查失败和异常退出

这几项分开测试。死亡和主动退出会按既有规则处理装备，建议使用可以损失的装备。

| 场景 | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 死亡 | 拿取部分尸体物品，留下一部分，然后在本局死亡。 | 沿用原有失败处理；失物记录只涉及你当时携带的物品，留在尸体里的东西不算你的失物。 |
| 主动退出 | 另开一局，拿取部分尸体物品，再通过菜单主动退出对局。 | 同样沿用原有失败处理，尸体剩余物品不进入你的失物记录。 |
| 异常关闭 | 另开一局，先记下出击前物品；搜尸后直接结束游戏进程，再重开。 | 恢复到这局出击前的状态；本局拿到的尸体物品不保留，出击前装备不重复、不缺失。 |

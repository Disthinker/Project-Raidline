# 区医院图纸与粉笔路线 · 联合验收

打开桌面 **Project Raidline Debug**，继续现有存档。背包留一个空格，从「对局出击」进入新开的「医院片区」普通对局。

1. **找到图纸。** 进入「区医院内部」，从入口向左前方到「接诊 / 候诊区」。朝向地上的「区医院内部图纸」，走近按 **E** 拾取。留在楼内按 **M**，确认能看到墙体和房间布局。若以前已买过内部图，可直接检查拾取和画线。
2. **画路线。** 在楼内地图上按住右键拖出一条线。出楼后再打开地图，往迷雾里画一条室外路线。迷雾里只出现笔画。点击「撤销一笔」或「清除路线」，室内外各自保留另一处的路线。按 **M** 关图，松开右键再按可恢复原瞄准。
3. **带回再出击。** 正常撤离，在基地「供应与回收」查看图纸，基础回收价应为 **35**。重新进医院，进入建筑后仍能查看内部图，本局地图从空白路线开始。

候选 `RL-RAID-HOSPITAL-FLOORPLAN-ROUTES-v1-local-6925381e36f6`。Windows Debug 全量 3252/3252，14 项 3 ms 检查通过。2026-11-12 用户验收通过。

# 通行许可与凭证撤离 v1：试玩清单

**用户已验收通过，正在提交与合并。候选：`1d3fae52cc99`。** 本地2699项检查及原五项3ms门槛通过；准确PR双平台检查待完成。以下保留正常玩法步骤供回查。

入口仍是桌面 **Project Raidline Debug**。可沿用原存档；旧档默认尚未登记通行许可。

本次只验证**边境交换站**。许可不占背包，只有成功回营才登记，从下一次出击起生效。

| 操作 | 应看到的结果 |
| --- | --- |
| 出击边境交换站，找到“交易所办公室”入口，按 F 进入。 | 原有室内场景正常；长柜台上方可看到纸张形状的“通行资料”。 |
| 面向资料靠近，按住 F。中途松开，再重新按住2秒。 | 松开后进度清零；完成后提示“成功撤离后登记”，背包不增加钥匙。 |
| 使用原有出口成功撤离。 | 结果页显示“边境交换站通行许可已登记”，携带物品保留原栏位。 |
| 正常退出并重开，再次出击边境交换站。 | 出击页面的“行动简报”仍显示许可已登记，无需重复调查。 |
| 进入高危，携带超过22kg的物资前往凭证出口。 | 原轻装路线显示超重；凭证出口仍可连续等待6秒撤离，许可不消耗。 |

为方便找出口，出击前可在“情报”中选用**交通图**；进入地图后按 M 查看“凭”字标记。没有交通图时，仍需探索发现；许可不会自动揭开地图。

凭证出口只在高危开放。离开出口、受控或打开菜单会中断本次凭证读条。现有普通、信号、轻装撤离继续保留。

死亡、主动放弃、异常退出、保存失败和旧档兼容由隔离测试覆盖，无需为验收故意损失真实装备。

# 医院片区 · 联合验收

双击[启动医院联合验收](<E:/RaidlineBuild/candidates/proc-map-hospital-outdoor-v1/启动医院联合验收.cmd>)，按 **1、2 或 3** 选一份独立存档，再选「继续游戏」。角色已配装，站在基地出击口。每份存档各自保存进度。

| 试玩动作 | 应看到的结果 |
| --- | --- |
| ① 选样本 1，在出击口按 E，选「医院片区」普通出击。沿宽阔主路走到区医院。 | 从急救停车区出发能直达主楼。门前道路连续，建筑没有挡住门口。 |
| ② 换样本 2 或 3，从停车区转入较窄的服务街，沿街区绕往同一座主楼。 | 侧路更长，沿途掩体更多。商铺临街、小院有开口、后勤棚场有独立作业区。 |
| ③ 认出服务诊所和救护车保障站，再走到区医院门口按 F 进楼、出楼。 | 三处地标能区分。主楼沿用原有室内；返回街面后仍是本局布局。 |
| ④ 在街区补给（风险 1）和临床储备（风险 3）中选一处搜取，从普通撤离点带回基地，再继续这份存档。 | 撤离正常结算，带回的物资还在。 |

[三份样本的路线对照图](<E:/RaidlineBuild/candidates/proc-map-hospital-outdoor-v1/samples.html>)可按编号顺序查看。勾选「主路／绕行」能看到停车区和主楼入口。图中记录的是各验收档初始状态的普通出击；后续出击会按当时的存档状态重新生成。

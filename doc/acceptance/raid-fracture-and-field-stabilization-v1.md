# 重伤撤离与野战夹板 v1 联合验收

请先关闭正在运行的 Project Raidline。把下面一行粘贴到 Windows PowerShell。它使用桌面 **Project Raidline Debug** 指向的同一个程序，窗口标题会显示 **Test Profile**。

```powershell
& 'E:\CodexWorkspace\Temp\Raidline-raid-fracture-and-field-stabilization-v1\Start-Fracture-Playtest.ps1'
```

1. **看懂扑击。** 点「继续游戏」，到出击口按 F，选择「医院片区」。进入「区医院内部」，从接诊区右侧绕向「急救治疗区」。观察橙色箭头并侧移躲开一次，再承受一次有效命中。出现「骨折 · 禁冲刺」后，确认步速变慢且无法冲刺。隔离档校准了正常部署种子。若停留或移动改变了种子，一次命中可能只扣血，退开后再试一次。
2. **带伤撤离。** 长按 5，从胸挂轮盘用止痛药。确认可以冲刺，HUD 仍显示骨折与药效。常规撤离成功后回营，退出并通过同一条命令重开。在「医疗服务 → 个人治疗」确认骨折仍在。支付治疗后骨折消失，骨折部分加收 45 货币，个人药品与公共药柜余量一致。
3. **在现场用夹板。** 需要从头复验时，关闭游戏并在上述命令末尾加上 **-Reset**。到急救治疗区拿「野战夹板」，放进胸挂。骨折后长按 5 使用，先用冲刺打断一次，确认夹板还在。再完整使用 4 秒，确认只清除骨折，没有回血或止血。
4. **补做下一件。** 回基地打开「工坊生产」，在第二页找到「野战夹板」。投入绷带和废旧零件各一件，等订单完成后把成品带入下一次出击。

本地候选 e5b1b0def361。Windows 全量 3358/3358，全部 14 项 3 ms 检查及九组旧档迁移通过。已通过用户验收。

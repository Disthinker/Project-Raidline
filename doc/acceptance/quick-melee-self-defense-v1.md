# 快速近战与应急自卫：试玩清单

用户已于2026-10-16验收候选 **8fc7f4ddf1ea** 并要求提交与合并。下方保留为历史试玩步骤，无须重复验收；实际交付状态见[任务记录](../exec-plans/active/quick-melee-self-defense-v1.md)。

## 从这里开始

双击桌面 **Project Raidline Debug**。本次新增的是**通用工具刀**和 **V 快速近战**槽，三个枪械槽不变。

新程序可以读取旧档，旧档不会免费获得工具刀。新版保存后，旧程序不能读取新增的刀具状态；首次试玩前可自行备份日常存档。

## 测试场快速检查

在基地按 **F10**，选择“进入战斗测试场”。这里的装备和损耗只在测试场生效，退出后恢复原档案。

| 操作 | 应看到的结果 |
| --- | --- |
| 点击“替换并装备测试套装”。 | 获得枪械、弹药和用于存放补给的随身容器。 |
| 用“额外补给”两侧箭头选中“通用工具刀”，点击“发放所选补给”。 | 刀具进入背包。必须先发套装，再发补给；重新发套装会替换整套临时装备。 |
| 按Esc关闭面板，再按Tab打开背包。右键刀具，选择装备。 | 刀具进入左侧下方的“V 快速近战”槽，随身总重增加0.40公斤。 |
| 右键已装备的刀具，选择“近战详情”。 | 显示刀具耐久、伤害4、距离72、角度90和恢复0.65秒，不出现枪械改装或装电选项。 |
| 回到控制台，按F8打开面板，选择一个“普通感染者”并点击“重置敌人”。 | 敌人出现在所选固定刷新点。关闭面板后，走近该刷新点。 |
| 把准星指向贴身敌人，按一下V。 | 出现短促挥动，当前枪械保持装备；一次最多伤一个目标。每次有效接触耐久减少0.5。 |
| 每次松开V并稍等，再攻击同一个无甲普通感染者。 | 三次有效命中可击倒满血普通感染者。敌人仍会反击，挥刀没有无敌或连续硬直。 |
| 面朝空处按V，再按住V。 | 空挥不扣耐久；按住不会连续挥刀。每次挥动后约0.65秒不能再次攻击。 |
| 在墙另一侧、敌人背向准星或明显超出贴身范围时尝试挥刀。 | 不隔墙、不向背后自动转向追击，也不远距离命中。 |
| 改选“躯干护甲感染者”，再正常攻击。 | 护甲会减伤，需要更多次命中；有效接触仍会磨损刀具。 |

## 动作与原有操作

| 操作 | 应看到的结果 |
| --- | --- |
| 同时按V和射击，再一直按住射击。 | 这次只执行近战；恢复结束后不会突然补射。松开射击并重按后才正常开枪。 |
| 冲刺时按V。 | 结束冲刺并挥刀，恢复期可以普通移动。 |
| 换弹过程中按V。 | 取消尚未完成的换弹并尝试挥刀；已装入的弹药不会复制或退回。 |
| 治疗或维修过程中按V。 | 第一次只取消原动作。释放V后再按，才会尝试挥刀。 |
| 打开背包、详情、地图或菜单时按V。 | 不会在界面背后挥刀。开关界面后，鼠标和准星继续保持已验收的行为。 |
| 在局内完成一次挥刀后立刻切枪或开关背包。 | 不能借此跳过恢复期，也不会自动补发一次挥刀。 |

在控制台选择“退出测试场并恢复基地”。原档案、原装备与原有耐久应恢复，临时工具刀不会带出来。

## 日常游戏确认

1. 到基地的**供应与回收**购买一把**通用工具刀**，价格120。装备到快速近战槽后，正常出击；不需要把枪切成刀。
2. 在**边境交换站**或**医院片区**正常战斗，并进出建筑。确认窗口准星、菜单、室内外视野及手电开关和耗电保持原样；M地图信息权限不扩大。
3. 在边境交换站击倒已有资源点的护甲守卫后，正常搜尸。刀击击倒的守卫也应留下原有可搜索内容；挥刀时不能同时继续搜索。
4. 成功撤离后，记下刀具耐久，退出再继续游戏。应保留同一把刀及真实耐久。
5. 把磨损的刀具放进仓库，在“供应与回收”右侧第一行选中它，再点“开始全面维护”。刀具在这份列表中优先显示。按界面报价扣款后立即恢复100耐久，不产生等待队列。零耐久完整维修价格为70。

零耐久、死亡和主动退出失物、两种寻回、异常退出恢复及保存失败已做自动检查，无须为了这份清单故意损失装备，也不用刻意挥刀200次。

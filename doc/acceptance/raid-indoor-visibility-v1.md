本次检查：墙后的敌人和物资不再提前显示，走到能看见的位置后才出现。墙体、地面、房间标识和出口仍应清楚。

## 从哪里开始

打开桌面 **Project Raidline Debug**，在设置中使用“简体中文”。快捷方式已核对为本次室内视野候选，不需要去原仓库寻找旧程序。

已有存档可以继续用，不需要删档。建议带少量普通装备和补给，从基地出击口开始新对局。

先选 **边境交换站**，分别进入 **交易所办公室**、**货运装卸间**；再开一局 **医院片区**，进入 **区医院内部**。靠近建筑入口，看见名称后的“F 进入”时按 **F**。入口位置随本局地图变化，以界面提示为准。

办公室和装卸间检查箱子；医院检查地面物资。医院不包含之前的护甲守卫搜尸试点。

## 先看墙角显隐

下面四步在三个室内各走一遍即可。

| 操作 | 应当看到 |
| --- | --- |
| 刚进入建筑，先站住看周围。 | 地面、墙体、静态标识和出口仍可辨认。遮挡区域稍暗，不能整片黑掉。 |
| 沿墙走到门口或拐角。 | 能看见的敌人和物资才出现；目标只露出一部分时，画面也只显示这一部分。 |
| 退回墙后，再探出来一次。 | 对象及时隐藏、重新出现；墙后没有敌人文字、攻击预警或上次位置残影。 |
| 在医院走过会移动画面的长走廊。 | 显隐随墙体和玩家位置变化，准星仍留在窗口中的原位置；墙角没有明显闪烁、漏光或黑边。 |

室内常驻统计显示“可见敌人”和“可见地面物资”。它们只反映当前画面中能观察到的对象，不提示墙后或屏幕外的总数。

## 再检查取物

| 操作 | 应当发生 |
| --- | --- |
| 在物资或箱子的墙另一侧靠近，按 F。 | 不能隔墙拾取或开箱。若当前房间找不到这种近距离位置，记为未测即可。 |
| 绕到物资或箱子可见的一侧，靠近后按 F。 | 医院地面物资可以正常拾取；办公室和装卸间的箱子可以正常打开。 |
| 打开箱子，拖起一件物品；保持鼠标按下，用移动键退到墙后，再松开鼠标。 | 失去访问资格时箱子面板关闭，未完成的拖拽取消。回到箱子前检查，原物品还在，没有丢失或复制。 |
| 重新打开箱子，正常完成一次取物。 | 物品正确进入背包。先前已经取走的物品不会因之后失去视线而回到箱内。 |

箱子原有的距离限制仍然生效。若当前摆放无法做到“仍很近但完全被墙挡住”，不要刻意卡墙；可以检查普通离开后关闭面板，并把单独的视线项目标为未测。这种边界已有自动检查覆盖。

## 最后确认原来的操作

| 操作 | 应当发生 |
| --- | --- |
| 与可见敌人交战，再退到墙后。 | 敌人仍会行动，墙仍挡子弹；隐藏画面不会暂停敌人。 |
| 回到出口，在“F 离开”提示处按 F。 | 正常返回室外，出口不会因视野遮挡而失效。 |
| 进出建筑后，分别打开和关闭 Tab 背包、Esc 菜单。 | 鼠标和准星没有突然跳到窗口中心，菜单点击与返回战斗正常。 |
| 在室内按 M。 | 未买内部图时，仍只显示当前位置周围；已买过时，仍可查看完整静态内部图。视野遮罩不会替你购买或取消地图权限。只测了其中一种存档状态时请注明。 |
| 在边境交换站室外，击杀原试点护甲守卫，靠近尸体按 F。 | 仍可按原方式搜尸。医院和战斗测试场不新增搜尸试点。 |
| 正常撤离并返回基地，再重新打开游戏。 | 已合法带回的物品和原有地图情报正常保留，没有重复发放。 |

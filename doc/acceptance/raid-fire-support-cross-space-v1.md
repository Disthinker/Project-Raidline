# 火力队友跨地图与室内协同 · 联合验收

双击[启动联合验收](<E:/RaidlineBuild/candidates/raid-fire-support-cross-space-v1/启动联合验收.cmd>)，点「继续」。这是基地出击口的独立测试档：一名可出击的战斗居民、两把可借的制式 5.45 步枪、两只实装备用弹匣、150 发准备弹。工业郊区仍走原桌面入口。

| 步骤 | 操作与预期 |
| --- | --- |
| 1．医院分头行动 | 普通出击选「医院片区」，从「单人出击」切到「带火力队友」，选借枪和备用弹匣。到区医院门口按 F2 选「原地掩护」，自己进楼。应看不到队友，也不能取他的弹匣；返身出楼，他还在原地。 |
| 2．一起进楼 | 在队友旁按 F2 选「跟随」，等他贴近同一扇门再进。带他离开门口，切「停火／自由射击」观察遇敌反应；墙会挡住射击。贴近队友按 F 取备用弹匣，只能领一次。正常撤离后检查借枪已归仓。 |
| 3．换图再试 | 普通出击选「边境交换站」，重新带队。依次带他进出「交易所办公室」和「货运装卸间」。每次应只有一个队友，过门前后的生命和命令一致，上一间屋子的敌人不会被带过来。 |
| 4．核对阵亡与失物 | 在独立测试档让队友在室内阵亡；回到他倒下的房间，靠近按 F 搜取一件借装，留下另一件再撤离。主角仍算成功；带回的原件仅一份，未带回的借装列入「队友阵亡失物」。 |

与队友分开时，只模拟玩家所在空间。距离门太远、在掩护状态或门边没有第二人落脚处时，他会留下；不会把玩家卡在门口。后续寻回仍使用既有的同图寻回地点。

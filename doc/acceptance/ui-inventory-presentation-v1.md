# 库存展示 v1 验收

**入口：桌面「Project Raidline 库存验收」**。候选编号 **bfb2bd6823e8**，当前待你试玩确认。

进入游戏后，沿用原来的方式打开基地「仓储」。可以继续使用原存档；本次没有迁移、扩容或自动整理物品。旧的三个程序与快捷方式保留。

| 操作 | 应看到的结果 |
| --- | --- |
| 依次浏览仓库六页，再回到第一页 | 每页8×8格，共384格；原物品的位置、数量不变。 |
| 切换「装备／胸挂／背包」，悬停物品 | 大格子与文字可读；口袋完整可达，长名称可查看全文，枪械图片不变形。 |
| 点击一件跨页长物品，再点「返回原页」 | 先定位看到整件，再回到原页；点击任何可见占格都操作同一件物品。原存档没有跨页物品时，可先将长枪放到页边缘。 |
| 拖拽物品时按PageUp／PageDown，或悬停个人标签 | 能跨页、跨标签放到合法空位；旋转及Ctrl／Shift数量选择仍有效。按Esc取消时，物品不变且背包仍打开。 |
| 按F快捷转移，然后点击右下角定位按钮 | 能使用其他页或隐藏随身容器的空位；按钮显示实际容器与页码，点击可找到物品。满仓或非法落点清楚拒绝。 |
| 在可用的大窗口下查看，再打开Raid箱子／尸体 | 图片保持比例；搜尸、菜单与准星行为正常，Raid不能访问基地仓库。 |

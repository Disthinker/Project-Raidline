# 医院夜间行动与供电整备 · 联合验收

打开桌面 **Project Raidline Debug**，继续现有存档。可预备一顶基础头盔和两节通用电池。已有枪械手电的步枪便于检查双设备操作。

1. **搜获。** 从「对局出击」进入「医院片区」。进「区医院」，到后勤走廊拾取地面的「头戴夜视仪」，正常撤离。
2. **整备。** 在基地打开背包，右键「基础头盔」进入「头盔详情」。安装夜视仪，再把一节通用电池拖进电池槽。戴上头盔，在「对局出击」核对预计抵达为夜间。需要时去「宿舍与休息」推进时间。
3. **夜间出击。** 在医院室外和后勤走廊比较夜视开关。暗处能看得更远，墙后仍遮挡。手电和夜视都装好时，长按 **U**，向左选手电、向右选夜视，松开切换。短按 **U** 切换上次选中的设备。两件同时开启时，各自耗电。带回一件医疗物资。
4. **重开。** 正常撤离，退出到主菜单再继续。核对头盔上的夜视仪、电池位置与剩余电量。

候选 `RL-RAID-HOSPITAL-NIGHT-OPERATIONS-v1-local-849df0f58fe0`。Windows Debug 全量 3172/3172，原 12 项 3ms 检查通过，用户已完成实机验收。

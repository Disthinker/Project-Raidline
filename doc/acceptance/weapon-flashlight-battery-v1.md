## 出击使用

到**边境交换站**或**医院片区**。室内较容易看清开灯差异，夜间室外也可以测试。

| 操作 | 应看到的结果 |
| --- | --- |
| 短按并松开 **U**。 | 当前步枪的灯开关一次，状态和电量显示在画面左下。 |
| 按住 **U** 超过0.35秒再松开。 | 出现短按提示，灯不会误切换。 |
| 开灯照向前方，再照向墙体或转身背向敌人、物资。 | 前方范围扩大；墙后和背后目标仍不能显示或取物。白天开灯不会缩小原视野。 |
| 切到备用武器，再切回步枪。 | 原枪灯停止输出、停止耗电；切回按原开关状态恢复。 |
| 打开、关闭菜单，并进出建筑。 | 鼠标与准星继续按已验收的窗口锚定方式工作；菜单鼠标不会转动光束。 |
| 局内打开“枪械详情”，用备用电池替换仍有电的旧电池。 | 新电池投入使用；旧电池保留真实余电并单独存放。随身容器都放不下时，旧电池才会落在脚边，可按F拾回。 |
| 拖动另一节电池后按Esc取消。 | 安装电池和备用数量均不改变，不误射击。 |

## 续航与保存

完整输出约需10分钟；约8分钟进入20%低电量。期间关灯、切枪或暂停会延后耗尽。

低电量时累计输出25秒会发生一次短暂闪断并停灯。请在战斗画面中往返晃动鼠标恢复：灯应重新亮起，电量不增加。枪械本身没有故障时也能这样恢复；在菜单里晃动鼠标不能恢复。未实际遇到这一情形，可以反馈“低电量尚未测试”。

成功撤离后记下余电，再退出并重新进入程序：安装的手电、电池余电及开关状态应保留。死亡、主动退出和异常退出沿用原规则，设备没有额外保底；这些边界已做自动检查，无须为本次清单故意损失装备。

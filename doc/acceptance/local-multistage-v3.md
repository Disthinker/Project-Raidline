# 十六项玩法联合试玩

双击同目录的 **开始联合试玩.cmd**，在主菜单点 **继续**。这是独立中文试玩档。角色已带工具刀、上膛的卡宾枪，胸挂里有两枚烟雾弹、一枚燃烧瓶和一台警戒器，仓库另备两把空步枪、电子元件和工坊材料。

| 去哪里 | 怎么试 | 应看到什么 |
| --- | --- | --- |
| **基地 · 工坊** | 先在「枪械拆解」选耐久约 25% 的空步枪，返回一次，再确认拆解。用废旧零件和铜线开一单声响诱饵，再点「工单加急」，选仓库里的损坏电子元件，查看预览后确认。 | 拆解得一件废旧零件。加急消耗所选元件一份，剩余工时减半并向上取整。重新进游戏后仍按新时间交货，有空位时两枚诱饵自动入库；满仓时可腾格后领取。取消已加急工单只退原配方投入。 |
| **基地 · 宿舍和医疗** | 在宿舍「居民与扩建」按 **R**，用 **1 / 2** 对照口粮，两档选定后按 **Enter**。在医疗服务「个人治疗 → 药品余量整合」把 **1/3** 的医疗包并入 **2/3** 的同型包。 | 试玩档初始九名居民，节约时每天耗粮从 9 降到 7，跨午夜后可看账本，士气最高为「稳定」。药品合成一包 **3/3**，原来源格腾空，可带去救队友。 |
| **医院 · 两栋建筑和幸存者** | 普通出击，在区医院、救护车保障站门口按 **F** 进出，各取一件再返回。要画路线，出发前先在「出击准备 → 情报 → 永久建筑内部图」买两张图（210、120），进楼后按 **M**，按住右键画线。黄色菱形处按 **F** 接应幸存者，带到绿色交接区，安全时按住 **F** 两秒。 | 主楼偏医疗物资，保障站偏工坊材料。折返能看到原搜取和击倒结果，两栋楼的粉笔线各自保留。进楼时幸存者在街面等待，安全交接后基地接纳一名受伤居民。 |
| **普通医院或边境出击 · 近战与队友** | 装工具刀后点 **V** 轻击，再按住 **Alt + V**，分别试提前松开和蓄满。出击前可把仓库里另一把空的 5.45 步枪借给火力队友。队友受伤后靠近他，按 **F2 → 5**，用方向键选随身医疗包，再按 **Enter** 开始治疗。 | 轻击立即出手。重击提前松开会取消，蓄满只挥一次，收招更慢。治疗时队友停火，约五秒恢复最多 30 点生命，中途跑开可取消。 |
| **医院或边境交换站 · 场地与投掷物** | 先把工坊产出或河畔换来的声响诱饵移入胸挂。按住 **4** 选取，松开后左键投掷或放置。依次试诱饵、烟雾弹、燃烧瓶和警戒器。还可从远处射击保障站外或边境货运区路旁带浅色横条的红桶。 | 诱饵吸引尚未发现你的感染者；烟雾遮住隔烟目标约八秒；火区持续约六秒；附近敌人经过警戒器只报警一次。油桶引爆后只留残骸，进楼折返也不会复原。 |
| **河畔检查站 · 文件、密藏与追击** | 带电子元件和废旧零件到安全的情报联络点按 **E**，各换一次。搜到原始情报文件后，右键「解读密藏线索」，按 **M** 找箱标，到现场按 **F**。碰到两名持枪拾荒者时，可追赶重伤或弹尽的一个，或让他沿退路离开。 | 电子元件换 12 发增强普通弹，废旧零件换一枚诱饵。读文件只标箱子，满包可回来再取；文件也可照旧出售或带回。追上击倒能取得原枪和剩余弹药，放走则没有尸体或击杀收益。 |

第一轮可先试 **工坊加急** 和 **河畔追击**。想复验另一种选择，可以另开一局河畔，或再开一张工单。

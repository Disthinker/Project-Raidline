## 原验收五项（已通过）

1. **窗口与文字**  
   在开始菜单打开“设置”，切换可用的“窗口尺寸”。预期：页面和按钮完整，文字清楚，鼠标能准确点中看到的选项。再切一次语言，长提示不越界。

2. **按钮反馈**  
   把鼠标停在按钮上，再移开、点按。预期：立即高亮并轻微放大，停留后出现说明；旁边的按钮不移动，点击不需要等待动效。没有存档时，“继续游戏”不可执行，并说明原因。

3. **暂停和背包**  
   继续游戏后按Esc，在暂停页进入设置，再返回游戏。预期：菜单样式一致，准星不跳动、不误射。按Tab打开背包，点击物品和右键菜单，位置应与鼠标一致。本轮背包布局仍是原样。

4. **建筑和轮盘**  
   正常进入一次Raid，进出一处建筑。预期：准星保持在窗口同一位置。装备允许时，按4或5打开相应轮盘再取消，选择方向准确，没有误射或意外使用物品。

5. **记住设置**  
   回到基地，退出并重新打开UI验收程序。预期：窗口尺寸和语言都保留；设置两项时不会互相覆盖。

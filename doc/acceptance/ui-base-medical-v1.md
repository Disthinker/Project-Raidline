先看页面是否分为“个人治疗／居民医疗”。不符合你当前存档条件的项目，注明“本档未测”即可，不必清空仓库或制造新伤员。

| 操作 | 应看到的结果 |
| --- | --- |
| 带伤返营，打开“个人治疗”。 | 生命与伤势清楚；能看到总价，按钮旁也有金额；注明只扣货币、不消耗个人药品。 |
| 点击“支付并治疗”。 | 只支付显示的费用，治疗立即完成；个人药品数量不变。 |
| 健康或货币不足时查看同一页。 | 按钮不可用，完整说明“无需治疗”或“货币不足”，不会误扣款。 |
| 有伤员、人员和已授权物资时打开“居民医疗”。 | 显示本次治疗1人、物资名称及数量、耗时。未授权的药品不会自动纳入。 |
| 开始一次居民治疗。 | 物资只扣一次，进入治疗中；伤员不会立即恢复，也不能反复开始同一任务。 |
| 关闭医疗页，在宿舍按原规则休息后返回。 | 治疗按世界时间完成；关页不取消、不额外扣料。已有进行中存档也能正确显示。 |
| 展开“设施与岗位”。 | 原分配／撤下人员、升级／取消升级仍可使用；进行中任务需要的人员不能被撤下。 |
| 按住操作按钮后移出、滚动、切标签或切出窗口，再松开。 | 不执行旧按压、不重复扣款／扣料，关闭后也不会误射击。 |
| 换三档窗口与中英文，查看明细和不可用原因。 | 关键文字完整；长内容可滚动；打开／关闭医疗页时准星不跳位。 |

重点反馈：是否看得清费用和耗材、有没有误扣或重复操作、是否有文字缺失。正常游玩由你完成；自动化通过不代表已经验收。

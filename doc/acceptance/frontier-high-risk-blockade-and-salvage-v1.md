# 边境交换站高危封路与重型搜运 v1

打开桌面 **Project Raidline Debug**。带至少一组「破拆楔组」，在背包留出 **2×2 格**。缺楔组可在工坊用 2 份废旧零件、1 份工业紧固件制作。从基地「对局出击」进入「边境交换站」。

1. **先看撤离路线。** 出击前选择「交通图」，进图按 `M` 核对撤离点。找到「高危控制装置」并按住 `F` 启动。路障正常在预警 **5 秒**后封闭。有人占路时最多再等 **5 秒**，到期仍占用会取消封路。看见路障后，`M` 地图才会标记。若这局没有封路警示，按原路线撤离，再开一局。
2. **绕路拿重货。** 遇到路障后从侧面绕行，在危机目标处拾取「机修工具组」。它占 **2×2 格**、重 **3.2 kg**。
3. **破拆开路。** 回到路障旁，朝向路障并长按 `F`。先松手一次，应取消读条、保留楔组。重新长按 **3 秒**，应只扣一组，原路恢复通行，地图标记更新为道路已打开。
4. **带回基地。** 到「信号撤离」点按 `F`，守到撤离。回基地确认工具组仍在随身物品中。可在既有界面用作 **5 建材**、提交为 **16 点安全资源**，或移入仓库后回收 **55**。

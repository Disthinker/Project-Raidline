# 5.45 弹药工坊与混装战术 · 联合验收

打开桌面 **Project Raidline Debug**，继续现有存档。准备制式5.45步枪、两个兼容弹匣和标准普通弹、增强普通弹各若干。

1. **搜集与制造。** 从边境交换站带回精密组件，也可使用已有库存。放进仓库，在「工坊与生产」第二页开始扩张弹生产。完成后得到 18 发。
2. **混装与换匣。** 把标准弹和扩张弹压入同一弹匣，再准备一个备用匣。让膛弹和备用匣的匣顶不同。检视可看供弹顺序，长按 **R** 可区分「顶」和「膛」。换匣后，第一发仍是原膛弹。
3. **观察实战差异。** 用同一把枪，在有效射程内比较普通感染者和护甲感染者的躯干命中。扩张弹打无甲目标更省弹。面对完好胸甲，用增强普通弹更有效。
4. **撤离与回读。** 正常撤离，退出到主菜单再继续。仓库余量、匣内顺序和膛弹应与撤离时一致。

本地候选 `RL-RAID-5-45-AMMO-LOOP-v1-local-c4a7f6c4fcd0`。Windows Debug 全量 3155/3155，原 12 项 3ms 检查全部通过。用户已完成实机验收。

准备一把现有支持改装的枪械，例如列表里的“5.45步枪”。预览可使用已有组件，或对已经安装组件的武器选择“恢复默认结构”。没有相应物品的项目请注明未测，不需要专门清空仓库或寻找稀有物品。

| 操作 | 应看到的结果 |
| --- | --- |
| 打开“供应与回收”，点击“武器改装”。 | 显示统一的三栏页面；当前装配清楚，“确认改装”起初不可用。 |
| 返回后，在背包／仓库右键枪械，点击“改装”。 | 预选刚才点击的那把枪；“返回背包”能回到原浏览位置。 |
| 切换枪管、护木、握把或武器手电；有多页时翻页。 | 只浏览，不自动拆件或安装。选择组件或“恢复默认结构”后，右侧才显示本次预览。 |
| 查看一次改装预览，再点击“确认改装”。 | 六项属性变化清楚；只执行一次，成功后显示新装配，不因长按或再次松开而重复处理。 |
| 对已装导轨护木的武器预览“恢复默认结构”，查看后直接返回。 | 明确列出会连带拆下的握把／手电和返还位置；未确认就返回，实际装配不变。没有这些已装组件时，此项可注明未测。 |
| 在设置中切换三档窗口和中英文。 | 图片等比，关键文字可读；长详情可滚动查看。原菜单鼠标、准星和库存操作正常。 |

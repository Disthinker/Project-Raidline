# 声响诱饵性能修复 v2：复验清单

**候选：e970acbc3d71；当前：双平台CI验证中，尚未人工复验。** CI通过后，主控会通知你使用桌面 **Project Raidline Debug** 复验；复验前不合并。

本次只优化敌群计算，操作和玩法应与此前相同。自动检查覆盖原场景和全部既有测试；正常游玩用于确认移动、追击与操作体验。

## 准备

在“供应与回收”买3个**声响诱饵**，放入已装备胸挂的普通格。选择白天正式出击**边境交换站**，便于观察；战斗测试场和特殊任务不启用诱饵。

## 1. 取消一次

按住4、松开，再按右键取消；也可另试一次Esc。

**应看到：** 中文提示正常，数量仍为3，不误射，准星和鼠标不跳。

## 2. 引开一组敌人

从掩体后向尚未发现你的感染者附近投第1枚，选择无遮挡落点。

**应看到：** 数量变2；合格敌人前往落点调查，移动与彼此避让正常。你换位置时，它们不能凭诱饵声音跟随你。发声结束后，未发现你的敌人恢复原路线或岗位。

## 3. 检查追击

让敌人真正发现并追击你，再投第2枚。

**应看到：** 数量变1；追击不会立刻解除，敌人仍会靠近并攻击。新诱饵落地后替代旧声源；声音不穿墙或跨室内外传播。留意发声、敌人聚集和返回岗位时有无明显停顿。

## 4. 原操作与撤离

按原习惯试一次建筑进出、菜单、搜尸、V近战、U手电和M地图，再带最后1枚正常撤离。

**应看到：** 窗口准星、鼠标、其他操作和地图权限保持此前行为；剩余1枚，不复制、不补发。

# 医院救援与公共医疗储备 · 联合验收

打开桌面 **Project Raidline Debug**。准备能进入「医院片区」的存档，并在基地安排一名健康居民负责医疗。

1. **救人。** 普通出击到「医院片区」，在「救护车停车区」附近找到救援点，靠近后长按 **F** 约 2 秒。看到已转移提示后，基地会接纳这名受伤居民。
2. **带药回基地。** 进「区医院内部」，在「药房 / 医疗储备」搜到急救物资并正常撤离。若要连续验证分装，再带回一份急救物资。
3. **给居民用药。** 打开「医疗服务」，切到「居民医疗」。从仓库选中一份急救物资，转入公共药柜，仓库留一份。查看预览后开始治疗。推进游戏时间，确认只扣柜内药品。康复后可把这名医疗专业居民安排到岗位。
4. **为下一趟整备。** 在工坊把仓库剩下的急救物资分装成基础医疗包或绷带卷，装入胸挂再出击。重进医院时，药房仍能搜到物资，已转移的居民不会再次出现。

候选 `RL-HOSPITAL-RESCUE-AND-MEDICAL-RESERVE-v1-local-f2b2da563d9b`。Windows Debug 全量 3295/3295，14 项 3 ms 检查通过。2026-11-13 用户验收通过。

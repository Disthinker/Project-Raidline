# 跨图后勤钥匙与封存补给 · 联合验收

打开桌面 **Project Raidline Debug**，继续现有存档。从「对局出击」选择普通对局。

1. **找钥匙。** 到「河畔检查站」，沿中央线路搜索，拾取「货运器材箱钥匙」并正常撤离。
2. **开箱。** 带钥匙去「边境交换站」的「货运装卸间」。确认原开放箱仍可短按打开。靠近并看向「封存器材箱」，按住 **F**。中途松手一次，确认进度清零，再连续按住约 2 秒打开。
3. **带回材料。** 拿走「精密组件」，重开箱子确认已取空、钥匙仍在身上。正常撤离后把组件放入仓库，在「工坊与生产」启动「5.45×39扩张弹批次」。
4. **核对保存。** 重开游戏，确认钥匙和生产订单还在。订单满 120 游戏分钟后可领取 18 发。

候选 `RL-RAID-CROSS-MAP-FREIGHT-ACCESS-v1-local-e359892b5d99`。Windows Debug 全量 3187/3187，13 项 3ms 检查通过，用户已完成实机验收。

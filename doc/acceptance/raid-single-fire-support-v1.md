# 单名火力队友出击 v1 联合验收

桌面打开 **Project Raidline Debug**，选择「继续」。隔离档从基地出击口开始。仓库已备好两把制式 5.45 步枪、准备弹和两个实装弹匣。

1. **招募与借装。** 去「边境交换站」，在救援点长按 **F** 接纳战斗居民。回营，在「对局出击 → 灰线仓库」选火力队友、空膛未装匣的制式步枪和备用弹匣。确认出击扣 30 发仓库标准弹，备用弹匣仍保留原弹数。
2. **局内指挥。** 按 **F2** 切换跟随、原地掩护、停火和自由射击。确认掩体及主角挡在枪线时队友会停火。靠近队友按 **F** 可拿原弹匣。背包满时弹匣仍留在队友处。
3. **核对归队。** 成功撤离后看原枪回仓。再带队出击，保留备用弹匣，在队友存活时主动放弃。回营应收到两件原借装，已扣的准备弹不返还。
4. **核对阵亡。** 让队友阵亡后靠近遗体，按 **F** 查看原借装。留下一件再撤离，结算仍显示主角成功，并生成独立的「队友阵亡失物」。战斗居民归零时，满 72 游戏小时后可在边境交换站接纳一名替补。

候选 e71b443eb59b。Windows 全量 3393/3393，原有 14 项 3 ms 检查全部通过。该候选已通过用户游玩验收。

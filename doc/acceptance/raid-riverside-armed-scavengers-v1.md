# 河畔检查站 · 四步联合验收

双击[启动河畔联合验收](<E:/RaidlineBuild/candidates/raid-riverside-armed-scavengers-v1/启动联合验收.cmd>)，选「继续游戏」。测试角色在基地出击口，身上有防弹衣、5.45 卡宾枪、备用弹匣和医疗包。

1. **绕行。** 在出击口按 E，选「河畔检查站」普通出击。简报会提示南侧巴士有枪手。沿外围到交易员或救援点，再从普通出口撤离，无需清场。
2. **交火。** 再进河畔，到南侧巴士附近观察。枪手举枪约 0.8 秒才开火，墙能挡住子弹。第一匣用尽后会停约 2.5 秒换匣；附近的感染者听到枪声会靠近，接触后可与枪手互相伤害。
3. **搜取。** 让一名枪手开几枪，再击倒并靠近按 F。核对手枪里的膛内弹、装着的弹匣和备用匣，总余弹应为 12 减去这名枪手开过的枪数。取走后重开遗体，物品只能取一次。
4. **带回。** 把手枪和弹匣装进随身空间，正常撤离。重开游戏核对枪和余弹，补弹后把同一把枪带进下一局。

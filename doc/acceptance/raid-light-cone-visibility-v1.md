## 先在边境交换站检查

| 操作 | 应该看到什么 |
| --- | --- |
| 白天出击，在室外站住，向前、侧面和背后转动准星。 | 视野随实际准星立即转动；身后敌人和物资隐藏。道路、墙体仍可辨认，主角和准星完整显示。 |
| 沿墙边、车辆和墙角走动。 | 墙后目标隐藏，露出一部分时只显示那一部分；看不到的敌人仍会行动和攻击。 |
| 进入交易所办公室、货运装卸间，再走回室外。 | 室内视野比白天室外窄、短；切换空间立即换用正确范围。准星在窗口中的位置不突然跳变。 |
| 打开背包或按M打开地图，移动界面鼠标，再关闭界面。 | 视野不跟随界面鼠标扫描；关闭后接续世界准星，无跳位或误射。菜单允许的走动照常生效。 |
| 面向物资按F拾取；在箱子或尸体旁隔一个身位，背向它，再按F。 | 看得见且够近时操作正常；完全退出视野后不能拾取、开箱或搜尸。搜尸只在边境交换站试点，医院没有这组守卫。 |
| 开外部容器后开始拖动物品，继续走动直到离目标太远或被墙挡住。 | 外部面板关闭，尚未提交的拖拽取消；物品留在原处，已经完成的合法转移保留。 |

在基地的**宿舍与休息**调整出发时刻。查看出击简报中**抵达**后的时间：18:00至次日05:59是夜间，06:00至17:59是白天。尚未建立主基地时，可等正常游戏时间推进。

| 操作 | 应该看到什么 |
| --- | --- |
| 夜间进入同一张地图，重复原地转向；遇到昼夜交界时观察变化。 | 夜间室外范围小于白天；交界约半秒平滑变化。背景与撤离导航仍可辨认。 |
| 到医院片区，在室外转向，再进入区医院内部并返回。 | 医院室内外同样遵守扇形与墙体遮挡；窗口准星不跳位，主角完整显示。 |
| 按M查看地图，再正常撤离。 | 原有地图情报权限保持；地图不会显示隐藏敌人的实时位置。带回物品与正常结算一致。 |

# 对局视角对齐 v4 · 四步复验

打开桌面 **Project Raidline Debug**，继续现有存档，带装有瞄具的制式 5.45 步枪进入普通对局。两款镜可分开试。

1. **1.5 倍镜。** 在有车辆或地标的位置按住右键再松开。试一次短按和一次完整开镜。画面应平滑回到普通视角，地标和视野边缘没有重影。
2. **4 倍镜。** 开镜扫向车辆，再按 **Esc** 开关菜单。松开右键后，普通视角应对齐，准星留在原窗口位置。
3. **建筑门口。** 使用 1.5 倍镜进出建筑。确认视野正确切换，准星不跳，门口和墙边没有双层轮廓。
4. **HUD。** 用 1920×1080 窗口查看完整游戏画面。生命、武器和右侧的本局提示应在窗口内，开收镜前后位置一致。

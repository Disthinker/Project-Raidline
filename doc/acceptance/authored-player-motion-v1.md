# 主角走跑动画试玩

双击桌面的 **Project Raidline Debug**，在主菜单选「继续游戏」。试玩档在基地出击口附近，使用独立存档。建议先找一段平直空地，把鼠标放在人物一侧，看清两脚。

| 怎么试 | 看什么 |
|---|---|
| **走、跑、停。** 左右行走，再从站立按住 Shift 和方向键冲刺，途中松键。 | 走路与跑步节奏有别。起跑第一步就移动，松键立即停。人物双脚回到地面。 |
| **换两只脚起跑。** 从站立开始走，第一次约 0.4 秒按 Shift；停稳重试，第二次约 0.85 秒按 Shift。把鼠标换到另一侧再试。 | 两次用不同的脚起跑。即使走到这半步的末尾，踩地的脚也能在原地交接，身体高度自然。 |
| **边走边改朝向。** 把准星从人物左侧移到右侧，再试倒退、斜走和跑中松开 Shift。 | 人物跟随准星转身，步子继续向前播放；减速和停步都响应按键。 |
| **进入普通对局。** 重试上述切换，到建筑门口试一次进出，有瞄具时开收镜，再按 Tab 看配装。 | 世界和镜中看到同一只脚落地，门口和准星位置稳定。配装页显示等比站姿。 |
